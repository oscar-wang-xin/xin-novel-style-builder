# Xin Novel Style Builder (小说写作风格Skill构建器)

## Overview

接收小说正文内容（文件路径或粘贴文本），自动清洗并提取前20章纯净正文，从十个维度深度萃取写作风格，按标准Skill格式生成文风锁定Skill，并打包为可导入使用的zip压缩包。这是一个端到端的文风分析与技能构建工具——从原始小说内容到可分发的Skill包，一步到位。

## When to Use

Trigger this skill when the user:

- 提供小说正文内容并希望生成可导入使用的写作风格Skill
- 说"生成小说风格skill"、"构建文风技能"、"打包小说文风"、"novel style builder"
- 想从某本小说中提取写作风格并封装为标准Skill包供他人使用
- 提供了小说文件（txt/md/docx等）或粘贴的小说文本，要求生成风格模仿的写作技能
- 需要为团队或社区创建可分发的文风锁定Skill

## Input Format

使用者可通过以下方式提交输入：

**方式一：指定文件 + 可选自定义名称**
```
文件：/path/to/novel.txt
名称：my-custom-style（可选，不填则自动生成）
```

**方式二：粘贴文本 + 可选自定义名称**
```
名称：my-custom-style（可选）
内容：
[粘贴小说正文]
```

**方式三：仅提供小说内容（名称自动生成）**
```
[直接粘贴或指定小说文件]
```

**命名规则：**
- 若使用者指定了Skill名称，直接使用该名称（需符合hyphen-case格式：仅小写字母、数字、连字符）
- 若使用者未指定名称，自动生成：`xin-novel-style-[关键词]`
  - 从小说标题或内容中提取关键词（不超过10个字符）
  - 中文名称需转换为拼音或英文（如"三体"→"santi"，"斗破苍穹"→"doupo"或"dpcq"）
  - 关键词须为纯小写字母/数字，不含空格或特殊字符
  - 最终格式示例：`xin-novel-style-santi`、`xin-novel-style-doupo`
- 若自动生成的名称已被占用，追加数字后缀（如`xin-novel-style-santi2`）

## Workflow

### Step 1: 输入收集与命名确认

确认以下信息：
1. **小说来源**：文件路径或粘贴的文本
2. **Skill名称**：用户指定的名称，或自动生成的`xin-novel-style-[关键词]`

**命名处理流程：**
- 若用户提供了名称：验证格式（hyphen-case），不符合则转换并告知用户
- 若用户未提供名称：从小说标题或内容首段提取关键词，中文名转拼音，生成`xin-novel-style-[关键词]`
- 向用户确认最终名称

**输出目录确定：**
- 默认输出到使用者当前工作目录下的`output`文件夹
- 生成的Skill目录结构：`output/[skill-name]/`
- 最终zip包：`output/[skill-name].zip`

### Step 2: 内容提取与清洗

从文件或粘贴文本中提取小说正文，执行以下清洗操作：

**文件读取：**
- txt/md文件：直接读取文本内容
- docx文件：使用python-docx库提取纯文本
- 其他格式：提示用户转为txt/md

**正文清洗规则（严格执行）：**

**推荐做法：先跑脚本，再人工复核。**

一键提取：

```bash
[PYTHON] scripts/extract_chapters.py <小说文件路径> <输出txt路径> [章节数，默认20]
```

脚本已内置：编码探测（utf-8 → gbk → gb18030 → utf-16 → big5）、站点声明与分隔线剥离、书名/作者/简介行剔除、章节编号解析（中文与阿拉伯数字混排）、过短章节（<500字）跳过。输出格式为每章 `## 第X章 标题` 独占一行开头，段间空一行。

**脚本兜不住的情况，人工按以下规则处理：**

1. **识别章节标记**：匹配以下模式的行作为章节标题：
   - `第[一二三四五六七八九十百千零\d]+[章节回]`（中文章节标记）
   - `Chapter\s*\d+`（英文章节标记）
   - `第\d+节`、`卷[一二三四五六七八九十\d]+`
   - 纯数字行（如单独一行的`1`、`02`）且前后为空行
   - 带序号的标题（如`1.`、`一、`开头且独占一行）

2. **提取前20章**：
   - 从第一个章节标记开始，提取连续20章内容
   - 若不足20章，取全部可用章节
   - 若无章节标记，按自然分段提取前20000-50000字作为样本
   - **【必踩的坑】章节结束位置必须取"下一章标记的起点"，绝不能用 `起始位置 + 固定长度`**。否则被提取的最后一章会把后续所有章节吞进来
   - **【必踩的坑】末章会吞入"后记 + 附录 + 站点声明"**：当提取章数 ≥ 全书总章数时，末章的 `end` 只能取 `len(text)`，于是文末附带的后记、附录、评传甚至另一本书会整块算进末章。实例：《碧血剑》共二十回，第二十回被吃到 **94,598 字**（真实正文仅 21,266 字），因为文末附了 476 字"后记" + 约 7.5 万字《袁崇焕评传》——一个末章使总字数虚增 45%，段长分布、对话占比、章末钩子三项统计全线失真。`extract_chapters.py` 已内置 `strip_tail_appendix()` 自动截断（匹配 后记/附录/跋/外篇/全书完，且只认距末尾 30% 以内的标记），并对超过中位数 2.5 倍的章打印警告。**跑完脚本仍要扫一眼各章字数是否落在同一量级**，量级异常就人工复核该章尾部
   - **【必踩的坑】尾部附录标记必须分"起始型/终结型"两类处理，不能一律取最后一个匹配**：`后记/附录/跋/外篇/写在后面` 是**起始型**——它后面还有几千字附录正文，必须截到它**之前**（取最靠前的一个）；`全书完/大结局` 是**终结型**——它后面只剩站点声明，取最靠后的一个即可。实例：《雪山飞狐》文末顺序是 `后记` →（约 2,000 字出版说明与李自成考据）→`（全书完）`→ 站点声明，旧逻辑 `last[-1]` 取到"（全书完）"，把整段后记留在第 10 章内，后记末句被误采成"章末钩子"。已按 `TAIL_START_PAT`(取最早) / `TAIL_END_PAT`(取最晚) 两级匹配修复，补了 4 条单测（起始型优先、仅终结型、无标记、标记在中段不触发）
     - **子坑：后记标记带标题/冒号时会漏网**。旧 `TAIL_START_PAT` 要求标记**独占一行**（`^[ \t　]*(?:后记|附录|…)[ \t　]*$`），而出版书常写成 **`后记：天下难容`**（冒号+标题）。实例：《杀人者唐斩》文末即为此格式，末章第 15 章因此多吞 **2,600 字作者后记**（第 15 章字数 5,785 → 真实 4,960），后记里的"稿于一九八四年""校于一九八七年"与致谢段落全部进了正文。已放宽为允许 `[:：]` + ≤20 字标题（`(?:[ \t　]*[:：][ \t　]*\S{0,20})?`），并补 9 条单测（带冒号标题、半角冒号、裸标记、带空格、附录带标题、正文含"后记"一词不误伤、冒号后超长不误伤、终结型不被 START 匹配等，8/9 通过，未通过那条"写在后面的话"属放宽前的既有边界、非回归）。**放宽后仍需人工扫一眼末章尾部**，因为"写在后面的话""附：xx"这类无冒号后缀的标记仍不覆盖
   - **【必踩的坑】别用终端肉眼判断源文件编码（Windows 尤其致命）**：`head`/`tail`/`cat` 的输出由终端代码页决定，Windows 控制台默认 936(GBK)，于是 **GB18030 源文件显示正常、而 Python 以 UTF-8 打印的清洗结果反而显示成乱码**（"雪山飞狐"会显示成"闆�灞遍�炵嫄"）。本次险些据此误判"脚本编码探测出错"。**正确做法**：信脚本打印的 `[编码] xxx 字符数 N` 行，或用 Python `raw.decode(enc)` 逐个 strict 试；检查清洗结果一律用 `python -c "..."` 并显式 `sys.stdout.reconfigure(encoding='utf-8')`，不要用 `head`/`tail` 肉眼验收
   - **【必踩的坑】编号只从章节标记的前缀取**（`第(\d+)章`），不要把整行标题里的中文数字算进去。例：`第02章 江南七怪` 若整行提数字，会被解析成"02七"而错位
   - **【必踩的坑】"免费"不能当站点水印关键词裸用**：`SITE_KEY`/`SITE_STRONG` 里的 `免费` 是超高频日常词——"天下没有免费的午餐""免费的冰激凌""免费公园""免费提供帮助"。实例：《异兽迷城》全书 33 条"站点水印"命中**全部是正文**，零条真水印，其中 2 条落在前 20 章：一条是第 07 章末句（"天下可没有免费的午餐……这顿麻辣烫除外。"）被整段抹掉，直接把该章**章末钩子**抹成错误结论；另一条是【】包裹的系统面板整行抹掉。已收窄为 `免费(?:下载|阅读|小说|电子书|TXT)` 等站点语境组合。**校验方法**：脚本打印 `[清洗] 剔除站点水印 N 处` 后，务必抽查这 N 条是否真是广告——若 N 较大而书是正经出版物/正版网文，几乎肯定是误删
   - **【必踩的坑】章首的"章节更新时间：2025-01-14 16:33"行必须清干净**：番茄/网抓 txt 每章一条，正好卡在章首，会被 `analyze_style.py` 采进"开篇 120 字"，把时间戳误判成一种开篇句式。`extract_chapters.py` 的 `strip_webnovel_meta()` 已处理（`章节更新时间|更新时间`）。**校验方法**：提取完先 `grep -c "章节更新时间" 样本.txt`，不为 0 就手工剔除后再跑统计
   - 若小说分卷且卷内重新编号，章号会重复：重复章号只保留首次出现，或按卷分段提取
   - **【必踩的坑】`楔子`／`引子`／`序章`／`卷首` 会被静默丢弃，而它常常正是全书第一章**：`CHAPTER_PAT` 只认 `第[CN]+[章节回]`，楔子类标记一条都进不去，脚本**不报错、只少一章**。后果分两层：①章数少 1、字数少几万，看起来只是"少了一章"；②**更致命的是「维度10 开篇习惯」整个失真**——楔子通常就是全书开篇（词、引子、叙述框架都在那里），丢了它，开篇统计是从"第1回"算起的，得出的"开篇习惯"根本不是这本书的开篇。实例：梁羽生《龙虎斗京华》全书 `楔子 + 12 回 = 13 章`，脚本只识别到 **12 章**（第1–12回），把 4,222 字的楔子整块丢掉；而本书的开篇习惯恰恰全在楔子里（以词开路 `——调寄踏莎行` + `列位看官` 呼告听众 + `笔者` 第一人称自述），丢了它就会把第1回的开法误当成全书开法。**处理**：跑完脚本先 `grep -nE '^[ \t　]*(楔子|引子|序章|卷首|序)[ \t　]' 原文件` 扫一遍，命中就手工把它补成 `## 楔子 ……` 段插到样本最前（标注"样本即全本"时也要把它算进章数）。**判定楔子是不是正文**：若楔子里有人物、有情节、有对白（哪怕是叙述框架），就是正文必须收；只有纯考据、纯目录、纯版权声明才剔
   - **【必踩的坑】分卷标记 `第X卷第Y章` 会一个都识别不到**：黄易、网络小说普遍用 `第1卷第1章 时空机器` 这种卷+章双层编号。旧正则 `第\s*[CN]+\s*[章节回节]` 读完"第1"后紧接的是"卷"，不在 `[章节回节]` 里，整条分支直接失败；`卷\s*[CN]+` 又要求"卷"在行首。实例：《寻秦记》291 个章标记**零命中**，脚本报"未识别到任何章节标记"。`extract_chapters.py` 已新增 `VOL_CHAPTER_PAT` 与 CHAPTER_PAT/NUM_PAT 的分卷分支，并自动判定"分卷体"（分卷标记占比 >50%）后**按出现顺序取前 N 章**——因为分卷书每卷都从第1章起，`setdefault` 式的"章号唯一"索引会把第2卷之后整卷丢掉。**写分卷正则时第二个 `第` 别忘了**：`第\s*[CN]+\s*卷\s*第?\s*[CN]+\s*[章节回节]`（漏写会静默零命中，正则本身不报错，极难排查）；卷号还不能捕获，否则 `main()` 取"第一个非空分组"时会把卷号当成章号
   - **【必踩的坑】"第N章 + `<h2>第M回</h2>`"两行式双层结构，会被切成一锅粥**。温瑞安作品（及部分港台单行本）普遍是：`第四章 带怒拔箭` 独占一行，下一行才是 `<h2>第一回 雪地伤狐</h2>`，**章内回号从"第一回"重新起算**；"回"才是真正的叙事单元。实例：《刀丛里的诗》全书 14 章 / 71 回，`extract_chapters.py` 按"章号唯一"索引时，"第四回"与"第四章"数字撞车，前者先把 `四` 占掉，于是章头行与后续裸回行被 setdefault 连续丢弃，**切点一路错位到下一处未占用的数字**——最终输出 14 章的字数是 3,059 / 2,754 / 1,363 / **38,140** / 2,585 / **26,384** / **50,405**…（正常约 3,000 字），"第四回"一口吞下 3.8 万字，且第二章、第三章的章头段整块并进前一章。
     - **处理办法**：此类书必须自写切分——①`第N章 章名` 行与紧随其后的 `<h2>第M回 回名</h2>` **合并为一个单元**，标题写成"章名 · 回名"；②其余裸 `第M回 回名` 各成单元；③一律**按出现顺序**取前 N 单元（回号每章重置，不能按号码去重）。
     - **子坑：合并单元时正文起点必须取 h2 行的下一行**。若从 `第N章` 行的下一行开始截，h2 那行的文字会残留进正文首段，被 `analyze_style.py` 采进"开篇 120 字"——表现为开篇首句莫名多出一个"第一回 xxx"标题。**校验**：提取后 `grep -nE '^第[一二三四五六七八九十百零两0-9]+(章|回)' 样本.txt` 必须为 0。
     - **顺带**：这类书还有一个"章末题记"坑——正文末尾的"稿于一九八八年十二月""校于……"两行会挂在末回之内，应与"后记"一并剔除（可用 `^(稿于|校于)` 行过滤）
   - **【必踩的坑】站点水印会转成全角规避过滤**：关键词判定前必须先做全角→半角归一化。实例：《寻秦记》有 18 处水印写作 `［ｗｕｘｉａｓｈｕｋｕ．ｃｏｍ］`（全角字母），半角关键词 `shuku` 一条都匹配不到。已在 `strip_inline_watermark()` 加 `to_halfwidth()` 处理。**校验方法**：清洗后同时搜半角与全角两种写法的域名（可用 `''.join(chr(ord(c)+0xFEE0) if '!'<=c<='~' else c for c in s)` 把关键词转全角再 count），两者都必须为 0
   - **【必踩的坑】水印不只有"独立成行"一种，还有"嵌在正文句子中间"的短标签版，必须删串而非删行**。实例：《弹指惊雷》62 处站点水印分两型——①独立成行 `（武侠书库 wuxiashuku.com 免费武侠小说下载）`（每回末一处，删行即可）；②**嵌在句子正中间**的 `［武侠书库TXT］`（全角方括号）与 `（wuxiashuku.com）`（全角圆括号），如"有另一种能祛`［武侠书库TXT］`邪去毒的奇花""他不由自己又惊`［武侠书库TXT］`又喜""你忘记`（wuxiashuku.com）`了我有一个古怪的嗜好"。**这类必须用 `re.sub` 把括号块整体删掉、让前后文自动拼回通顺原句**（删完逐条复读验证），一旦按"整行含关键词就删行"处理，会连带删掉整段正文。正则写法：`[［\[（(【][^］\]）)】]{0,60}(?:武侠书库|wuxiashuku|书库)[^］\]）)】]{0,60}[］\]）)】]`（注意先做繁简归一，否则"武俠書庫"匹配不到）。**校验方法**：清洗后搜 `wuxiashuku` 与 `武侠书库` 均为 0，再抽查几处原位置，读通顺即对
   - **【必踩的坑】繁体样本必须先看缺字占位符「囗」**：网抓转码时把显示不出的字统一替换成 `囗`（U+56D7）。实例：《寻秦记》前 20 章 **117 处**，全部对应「口」（入口、伤口、一口凉气、哑口无言）。不处理会被当成作者用词抄进 SKILL.md。脚本已打印 `[提醒] 样本含缺字占位符"囗" N 处`，确认其全部对应同一字后可在范例中批量还原
   - **【必踩的坑】清洗完必须再 grep 一次水印，别信脚本的"已剔除 N 处"**：脚本自身可能被并发会话改写（实例：同一份《大剑师传奇》，15:10 的半写完版本只剥 398 处，完整版剥 527 处，20 条全角水印漏进前 20 章正文，其中一条正好卡在角色对白中间、被 `analyze_style.py` 采进"多发言标签段示例"）。**校验方法**：提取后再搜一遍半角与全角两种写法（`s.count('wuxiashuku')` 与 `s.count(''.join(chr(ord(c)+0xFEE0) if '!'<=c<='~' else c for c in 'wuxiashuku'))`），**两者都必须为 0**；不为 0 就先补一道清洗再跑统计，否则统计与引文全脏
   - **【必踩的坑】繁体样本古今用词对照会得出假 ∞ 比值**：`word_pairs.py` 内置 PAIRS 全是简体，拿"繁体古体 vs 简体现代体"对比，字符集不同导致现代体恒为 0，于是任何古体都被判成 A 类硬规则。实例：《寻秦记》`未曾 1 : 没有 0` 被判"只用未曾"，而正确的繁体对比是 `未曾 1 : 沒有 163`（B 类，用"没有"）——**同一对词结论完全相反**。脚本已加 `is_traditional()` 自动检测 + `to_trad()` 整体转繁（只映射 CJK，正则元字符不受影响），转繁后还会对重复词对去重，避免同一对词同时被打进 A/B 两类。**若补充自己的对照词表，务必两侧同为繁体或同为简体**
   - **【必踩的坑】整章丢失段落分隔**：部分 txt 的个别章节在源文件里就没有换行，多人对话被并成一个巨块。特征是**"段数异常少但字数正常"**——用 `每章字数 ÷ 每章段数` 扫一遍即可定位（实例：《笑傲江湖》第10、20章为 57 段/23,399 字、70 段/21,470 字 ≈ 400 字/段，其余 18 章均为约 110 字/段）。这类章节会**严重污染段长分布、对话占比、段落构成三项统计**，必须在 Step 3 剔除后重算，并在 SKILL.md 的句式维度注明"该版本部分章节段落分隔丢失，属版本缺陷"，**不得把 400 字长段写成作者风格**
     - **怎么区分"粘连块"与"作者本来就写长段"**（这一步不能靠肉眼看字数）：数该段内的**引号对数量**与**相邻引号粘连数**（`len(re.findall(r'”\s*“', seg))`）。粘连块的特征是引号对极多且大量背靠背——实例：《刀丛里的诗》第 10 回有一行 **4,809 字、106 个引号对、41 处 `”“` 相邻**，铁证是拼接的对话块；而同书另有 684 字、501 字、480 字的段落，引号对分别只有 18 / 2 / 0 个、相邻粘连 2 / 0 / 0 处，那就是作者本人写的长叙述段或长台词段，**必须保留，不得当缺陷删掉**。**判定线**：引号对 ≥50 且相邻粘连 ≥10 即为粘连块；引号对个位数、无相邻粘连的，是正常长段。
     - **通用兜底**：全书扫一遍 `len(行) > 1500`，正常排版下应为 0；不为 0 的基本都是粘连块（《刀丛里的诗》全本 22 万字仅此 1 处），单独剔掉即可，不必整章丢弃
   - **【必踩的坑】`楔 子`／`引 子` 中间带空格会静默丢失**（上一条楔子坑的加强版）：港台网抓版常写成 **`楔 子 一阕词来……`**（字间插半角或全角空格），`^[ \t　]*(楔子|引子)` 一条都匹配不到。实例：《七剑下天山》源本正是 `楔 子 一阕詞來……`，若按旧正则扫，楔子（6,206 汉字）连同**卷首词《八声甘州》**一起丢掉——而本书的"开篇习惯"与"破折号用法"两大结论（词牌注 `——调寄八声甘州` 是全书破折号唯一高频用法）**全靠这一章**。处理：正则放宽为 `^[ \t\u3000]*楔[ \t\u3000]*子[ \t\u3000]*(.*)$`，与回标记合并后**按位置排序**再取前 N 个单元。**校验**：`grep -nE '^[ \t　]*楔[ \t　]*子' 原文件` 必须命中；且取完样本后单元数必须等于"楔子数 + 回数"
   - **【必踩的坑】取前 N 章时，末章的 end 必须用"全量 marks 的下一个标记"，不能用已切片后的 sel**：典型错误写法是 `sel = marks[:N]` 然后在循环里取 `sel[k+1][1] if k+1 < len(sel) else len(raw)`——此时 `len(sel) == N`，最后一章的 `k+1` 恰好等于 N，条件为假，**end 直接取 `len(raw)`，末章一口吞掉全书剩余部分**。实例：《七剑下天山》取前 21 单元时，第 20 回被吃到 **130,338 字**（真实仅 11,150 字，同量级章约 9,000–15,000），段长分布、对话占比、章末钩子三项统计全线失真。**正确写法**：`nxt = marks[k + 1][1] if k + 1 < len(marks) else len(raw)`——**marks 用全量，sel 只用于遍历**。**校验方法**（与上一条"末章吞后记"通用）：跑完打印每章字数，**必须落在同一量级**；出现 10 倍以上的离群值，先查末章 end 是不是取了 `len(raw)`
   - **【必踩的坑】源本用全角 `＃`／`＝` 顶替丢字，必须按语义逐处补全**：港台老书转码版常把识别不出的标点与汉字替换成 `＃`（少数用 `＝`），形式是**一个符号顶替"标点 + 下一字"**。实例：《七剑下天山》10 处 `＃` ＋ 2 处 `＝`：`名头可大哩＃荷藏回疆`（实为 `名头可大哩！西藏、回疆`）、`看错了＃瑚告公子`（实为 `看错了。明告公子`）、`选择＝个石人`（实为 `选择一个石人`）。**这类不能删、不能保留**，只能逐条查上下文按语义补字。**校验方法**：清洗后 `s.count('＃')` 与 `s.count('＝')` 必须均为 0；非 0 就先 `re.finditer(r'.{15}[＃＝].{15}')` 把上下文全打出来再逐条补
   - **【必踩的坑】`著→着` 会把「拙著」误改成「拙着」**：上一条"保护词表用子串匹配会误保护"讲的是**保护过多**，这里是**保护不足**——保护词表若只收了 `著名／著作／名著／原著` 之类常用实词，会漏掉作者自称著作的 **`拙著`**。实例：《七剑下天山》3 处 `（详见拙著《塞外奇侠传》一书）` 全被改成"拙着"，而"跨书互文"恰恰是本书写入 SKILL.md 的招牌体例，引文里出现"拙着"极难看。**做法**：做「著→着」替换前，保护词表至少覆盖 `著名 / 名著 / 著作 / 原著 / 著者 / 编著 / 著称 / 论著 / 遗著 / 专著 / 著述 / 拙著`；替换后**同时**打印残留 `著` 的上下文（应全为 zhù 义）**和**可疑 `着` 组合（`拙着|着作|着名|着述|着者`）的全量命中，两头都清干净才算完
   - **【必踩的坑】段末无终止标点，绝大多数是"源本硬断行"而不是作者风格**：部分网抓版在段落中间插换行、下一段以全角空格缩进，于是切出 `……一瓣瓣零落地`／`……飞身脱出水牢`／`……也分不清楚` 这类**无尾段**。实例：《七剑下天山》1,692 段里有 **26 段**段末不是 `。”！？：…—）`，逐条查后确认 12 段是断行截断（补句号收口），14 段是**诗词行与词牌注**（`——调寄八声甘州`、纳兰词逐句成段、哈萨克牧歌逐句成段）——**后者是正常排版，绝不能补句号**。**判定方法**：段末字符是普通汉字**且**下一段不是诗行/词行，即为截断；若该段本身押韵或处于引号内的唱词块，则为正常。**校验**：修完后剩余"段末无终止标点"的段应只剩个位数，且能逐条指出是诗词行
   - **【必踩的坑】全本对照必须先转简再 count，否则繁体源本会给出"0 处"的假结论**：拿简体样本的词去繁体原文件里 `count`，字符集不同必然恒为 0。实例：做《七剑下天山》全本对照时直接 `raw.count('请听下回分解')` → **0 处**，差点据此误判"全本无此套语、样本是孤例"；`zhconv.convert(raw, 'zh-hans')` 后再数 → **23 处**，结论完全反转（请看 5 : 请听 23 才是全本真值）。同理 `擡` 全本 67 处、样本 0 处（已转 `抬`），不转简就看不出这是"版本差异"还是"作者风格"。**做法**：凡涉及"样本 vs 全本"的对照（回末套语、破折号密度、古今用词、异体字），**一律先把全本转成与样本同一字符集（通常 zh-hans）再统计**；转简用 `zh-hans` 而非 `zh-cn`（后者会把港台词现代化，污染古今用词统计）
   - **【必踩的坑】"哲学辞典碎片"有两种插入形态，劈句型比整段型难十倍，自动切分基本不可用**：外来词典文本混进正文时，形态①是**整段插入**（《冰河洗剑录》，碎片独占若干行，锚点 65 条即可）；形态②是**劈进句子中间**（《萍踪侠影录》，268 处），格式为 `正文A【碎片]  ，正文B`——碎片后 **100% 紧跟"双空格＋逗号"（268/268）**，碎片起点却毫无规律，可能落在一个词的正中间。**自动切分试过：按"标点／虚词／句读"判据切，准确率不够**，268 条只能逐条人工判读锚点、再按锚点批量剥离（本书删 6,876 字符）。**流程**：先 `re.finditer(r'  ')` 把全部双空格上下文导出（每次 90 条左右分页读），人工在每条里标出"碎片起点字"，写进锚点表 → `clean_*.py` 里 `for anchor in ANCHORS: assert anchor in s` 逐条断言命中，跑完打印"命中 268/268"。**校验**：清洗后 `s.count('  ')` 必须为 0，且抽查几处原位置读起来通顺
   - **【必踩的坑】缺字占位符有两个：`囗`(U+56D7) 和 `□`(U+25A1)，只扫一个会漏**：前面那条坑记的是 `囗`（网抓转码显示不出的字），《萍踪侠影录》用的是 **白方块 `□`（U+25A1）**，95 处，形态是"一个 □ 顶替一个汉字"。`s.count('囗')` 对它恒为 0。**做法**：清洗后两个都数，任一非 0 就打上下文分类还原。本书 95 处里绝大多数对应 **「厮/廝」**（这厮 25、那厮 5、厮杀 8、厮拼 11、厮斗 2、厮熟 2、耳鬓厮磨 3），其余是马缰 6、靦（靦颜/靦腆）3、乒乓 2、噼啪 3、当啷 6、叱吒 2、螳螂 1 等——**先按左右邻字聚类，再逐类定字**，比逐条看快得多。另有一本书同现 `*` 缺字 2 处（痉挛、迷药），也一并扫
   - **【必踩的坑】"全书用得一致"不等于"这是作者用法"，史实／专有名词必须联网核实**：OCR 会把某个字系统性误植成另一个形近字，于是全书几百处**全部**是错写法、正确写法一处都没有——这种内部高度一致反而最有欺骗性，脚本的"异写聚类"查不出来（因为根本没有异写）。实例：《萍踪侠影录》全书 **331 处 `瓦刺`**（正字 `瓦剌`，明代蒙古部族）与 **145 处 `祈镇`**（正字 `祁镇`，明英宗朱祁镇），**正确写法零出现**；同批还误植了 `朱无璋`→朱元璋、`沙无岂`→沙无忌、`盘距`→盘踞、`招书`→诏书。**做法**：凡是历史人名、地名、民族、年号、官职，**先挑出来查一遍再决定是否保留源本写法**，别默认"全书一致＝作者原样"
   - **【必踩的坑】引号错位两型，都会被 `analyze_style.py` 当成正常台词采进去**：①**左引号跑到句尾**——`低声说道：大哥，我相信你！“`（实为 `低声说道：“大哥，我相信你！”`），特征是 `道：` 后不跟左引号、而段末出现孤立的 `“`；②**双冒号**——`笑道：：“`。**扫描正则**：`(?:说道|道|叫道|笑道|喝道|问道|答道)：[^“‘]` 与 `：：“`，命中即修。**校验**：修完 `s.count('“') - s.count('”')` 应收敛到 0 或 1（长唱词跨段会天然差几个，差 30 以上就要查跨段排版是否本就如此）。另：段末用半角 `.` 的句子（源本转码残留）也要一并换成 `。`
   - **【必踩的坑】引号错位还有第三、四型（书名化人名前缀，正则要带人名表）**：③**段首游离引号**——段首出现 `“` 后**紧跟"人名道："**（如 `“檀羽冲道：“妈妈……`），实为上段台词收尾的 `”` 被 OCR 成 `“` 或孤立残留，修法是**删掉游离的 `“`**；④**行内反向引号**——`……吧？“张炎道：“……`，`？` 后的 `“` 应为 `”`，修法是**改方向**。两者共用正则 `“((?:人名1|人名2|…)道：)`，按 `“` 前一个字符分流：段首（`(?m)^`）删除、行内（前为 `。！？，；`）替换为 `”`。实例：《武林天骄》段首型 5 处＋行内型 6 处
   - **【必踩的坑】人名批量替换前必须先查"书内改名/化姓"情节，OCR 错字表可能把作者设定当错字**：实例：《武林天骄》檀家隐居时**化姓"谭"**（第 1 回全书用"谭道成/谭公直"，第 2 回末"你不是汉人；第二，你也不是姓谭！"揭穿后才恢复檀姓；钟灵秀等后识之人全书仍称"谭大哥"）。若按"譚→檀 OCR 误植"批量回滚，会把化姓期的正确用名全改错。**做法**：替换前先按章统计两写法分布（第 1-2 回谭多、之后檀多＝化姓；全书混杂无规律＝OCR），再看有没有"你是姓 X 不是姓 Y"之类的揭示台词。**校验**：修正后正字占比应与章节剧情线吻合，叙述者与台词分别抽查
   - **【必踩的坑】半角拉丁归零不等于干净，还要扫全角拉丁与杂符**：`[A-Za-z]` 为 0 后，`ｄ`(口)、`ｘｘｘ`（转录者分场标记）、`＼＼ｘ`、`ｌ` 这类**全角残留**仍在（实例：《武林天骄》6 处：`这种ｄ吻`→口吻、`不忍说出ｄ来`→说不出口、`ｘｘｘ檀公直在喘气` 分场标记删、`檀羽冲ｌ亲手` 删 `ｌ`）。**做法**：收尾体检用 `re.findall(r'[ａ-ｚＡ-Ｚ]', s)`，非 0 就打上下文逐个定性（口字替身→补字、分场标记→删、杂符→删）
   - **【必踩的坑】顿号被 OCR 当句号：`、”` → `。”`**：源本里句末 `，”`/`？”` 位置出现 `、”`（顿号＋右引号），实例《武林天骄》14 处（`死掉、”`、`问他吧、”`、`醒了没有、”`）。批量 `s.replace('、”', '。”')` 安全（顿号后直接闭引号的合法搭配几乎不存在），修完抽查

  - **【必踩的坑】空本体 + `.crswap`/`.crdownload`/`.part` 崩溃恢复文件**：用户给的 `.txt` 若是 0 字节（下载中断），同目录常有下载器的临时交换文件（扩展名 `.crswap` 等）含真实内容（实例：《剑来》`剑来.txt` 本体 0 字节，`剑来.txt.crswap` 约 19.7MB 用 GB18030 解出 1006 万字）。处理：用 `gb18030` 试解该临时文件（GBK 可能失败），先 `errors='replace'` 解成 utf-8 副本；再查**前 N 章区域**的 U+FFFD 替换符数——为 0 即前 N 章完好可用（全书尾部截断不影响）。`extract_chapters.py` 的 utf-8 探测用 `errors='ignore'`，对这类崩溃文件会误判"utf-8 成功"实则吞掉全部多字节正文、识别不到章节，必须从 `gb18030` 干净副本抽取
  - **【必踩的坑】"逐字拉开间距"的站点水印脚本抓不到，且清洗正则绝不可跨换行**：部分 txt 把水印写成 `八 零 电 子 书  w w w . 8  0 8 0 t x t . c  o m`（每字间插半角空格），`extract_chapters.py` 的普通水印正则只命中未拉开的版本、漏掉这 57 处，会污染每一章的"开篇 120 字"。**清洗必须按行精确删**（删含 `八 零`/`电 子 书`/`8 0 8 0 t x t` 等子串的行），且**正则禁用 `[\s\S]`+`\s*` 桥接**——实例：用 `八\s*零\s*电\s*子\s*书[\s\S]{0,80}?c\s*o\s*m` 删水印时，`\s*` 跨了换行，某章水印字符稍缺就从正文"八"桥接到远处"零电子书"，把中间所有章节连引号一起吞掉（引号 791→16，样本报废）。务必逐行 `if any(tok in ln for tok in wm): drop` 处理，删完复校引号平衡与字数
     - **变体：`重要提示`+`书友们`+`备用域名` 型**。实例：《杀人者唐斩》主体文本夹了一处 `(   重要提示：如果书友们打不开t x t 8 0. c o m 老域名，可以通过访问t x t 8 0. c c 备用域名访问本站。   )`——同样是逐字拉开间距，**半角域名检索（`txt80`）与全角域名检索（`ｔｘｔ８０`）都抓不到**（因为字间插了空格），而 `grep "txt80"` 也失效。**识别办法**：把行内空白全部剥掉再匹配（`re.sub(r'[\s\u3000]','',行)` 后查 `txt80`/`重要提示`/`书友们`/`备用域名`），命中即整行删。全书只此 1 处，用关键词一次扫净，删完复校
   - **【必踩的坑】水印嵌在句子正中间（`（wuxiashuku.com）` 型），整行删除法完全无效**：站点水印不只有"整行页边"和"逐字拉开间距"两种形态，还有一种**把域名整块塞进句子中间**的——`连长（wuxiashuku.com）衫也不脱`、`倏然变（wuxiashuku.com）色`、`就凭一双肉掌和老师傅（wuxiashuku.com）玩玩吧`、`眼睛裏含着晶莹（wuxiashuku.com）的泪珠`。**特征**：全角括号包裹的半角域名，前后是紧邻的汉字，**把它删掉句子立刻自动复原成通顺原句**（连长衫、倏然变色、老师傅玩玩、晶莹的泪珠）——所以直接删 token 即可，不需要补字。**为什么难发现**：①它是"行内"的，`extract_chapters.py` 的整行水印逻辑和 `SITE_STRONG` 都抓不到；②字数只少十来个，肉眼扫不出来；③它会被 `analyze_style.py` 采进所在的段落，污染段长与词汇统计；④若落在段落开头（如 `（wuxiashuku.com）　　娄无畏问道`）还会污染"开篇 120 字"。**处理**：清洗后必跑一次 `re.findall(r'[（(]\s*wuxiashuku\.com\s*[)）]', s, flags=re.I)`（换个站就换成对应域名）确认归零，再 `re.sub` 整体删掉 token。实例：《龙虎斗京华》全书此类 **13 处**，与 13 行整行页边水印、13 处章内标记「［武侠书库TXT］」并存，三类水印共 39 处，只用一种逻辑必然漏
  - **【必踩的坑】引号总数不平衡 ≠ 版本缺陷——"长台词跨段"是原书排版特征，不要当 bug 去"修复"**：部分武侠/通俗小说的原书排版把**单条过长台词拆成两段**，前段引号不闭合、后段以 `”` 收束（`……道：“他妈的，金贼也逼人太甚了。` ⏎ `放着一个皇帝干什么的，咱们大宋官民都要被逼得无路可走了！”`）。后果：**全书 `count('“')` 与 `count('”')` 天然不等，且逐段扫描会出现一批"引号不配对段"**。实例：温瑞安《落日大旗》全书 20 章 **65 / 2591 段引号不配对（2.5%）**，总数 1239 vs 1242。**判定方法（关键）**：看这些不配对段的形态是否规则——若一律是「前段只有 `“`、后段以 `”` 收尾」且两段语义连贯成一句话，即为原书跨段排版，**属作者/排版风格，必须原样保留并写进 SKILL.md 的句式维度**（它同时抬高"含引号段落占比"、影响"纯对话独立成段"统计）；反之若两端引号出现位置杂乱无章、句子语义跨段不连贯，才是真缺陷。**为什么这个坑危险**：①若照搬"修复后务必校验 `count('“') == count('”')`"的通则去强行配对，会把 65 处原书特征段全部合并，直接抹掉一条可写的风格项；②若误判为"段落分隔丢失"而重切段，段长分布、对话占比、段落构成三项统计会一起失真。**正确处理**：先跑形态判定，确认是跨段排版就在「样本说明」里点名"引号跨段为原书排版特征，全书 N 处"，并在句式维度写明；`style_examples.md` 的引文保持拆段原貌，不要手工合并
  - **【必踩的坑】"作者有话说"位置不固定，截断别无脑全切**：PS/作者按不一定在全书末——实例《剑来》的 `ps1/ps2/ps3 微信公众号求关注` 紧接**第一章末**（非全书末）。若用 `s=s[:ps位置]` 全切会误删后 19 章。正确：定位到具体章节标记，只删 `ps1:` 到下一章标题之间的块
  - **【必踩的坑】章节分隔符"————"（≥3 连横线）会被当成破折号，制造"破折号高频"假象**：部分 txt 用 **4 连 em dash `————`**（或 `────`，U+2500）作章间/场景分隔符。`analyze_style.py` 与 `str.count('—')` 会把它计入破折号。实例：《玄鉴仙族》样本首测"破折号 107 次（2.4/千字）"，一眼像是作者爱用破折号；实际剔掉 23 处 `————` 分隔符后只剩 7 处真破折号，全本 `————` 多达 **325 段**，剔除后真破折号全本仅 **79 次 = 0.046/千字**（几乎绝迹），结论与"高频"完全相反。**处理**：清洗时对分隔符**整行删除**——`re.fullmatch(r'[—\-─]{3,}', 行.strip())`；统计破折号时只数"恰好 2 连"的真破折号——`len(re.findall(r'(?<!—)——(?!—)', raw))`，不要用 `str.count('\u2014')`。**判定**：某行若只有横线字符且长度 ≥3，即分隔符，非正文。此坑与"双字符标点按标点单位计数"（Step 3）叠加时更隐蔽：`————` 会被 re 当作 2 个 `——` 计入 53 次里的绝大部分
  - **【必踩的坑】繁转简必须用 `zh-hans`，绝不能用 `zh-cn`——后者带"地区词替换"，会凭空改写作者用词**：`zhconv.convert(text,'zh-cn')` 不只换字形，还会把港台用词换成大陆用词，等于把仿写对象从"作者当年的用词"改成"现代大陆用语"。实例：梁羽生《云海玉弓缘》（1961 年香港《新晚报》连载）用 `zh-cn` 转出「第31回 隔物传功败掌门 **导弹**闭穴惊妖孽」——原书写的是武侠暗器「**飛彈**」（飞弹），被当成台港用语换成了现代军事词；同批被改的还有 `身分→身份`、`軟體→软件`、`雷射→激光`。正确写法 `zhconv.convert(text,'zh-hans')`（纯字形），转完 `飛彈→飞弹`、`身分→身分` 原样保留。**校验方法**：转简后 count 一批"会被现代化"的可疑词——`导弹/身份/软件/激光/硬碟/资讯`，若命中数违和（武侠书里冒出「导弹」），即是误用了 `zh-cn`。注意 `身分/身份` 这类"两版都通"的词对，用 `zh-hans` 会把源本原貌保留下来，反而更忠实
  - **【必踩的坑】繁体源本里的站点水印是繁体字形，在"转简之前"用简体关键词去删必然打空**：水印文案写作「**熾天使書店**http://welcome.to/silencer」「**回應人**:highking**回應時間**:10/12/98」，而清洗脚本里的关键词是简体「炽天使书店」「回应人」——若这一步排在 `zhconv.convert()` **之前**，正则一条都匹配不到，水印整条留进正文，还会被 `analyze_style.py` 采进统计与开篇 120 字。实例：《云海玉弓缘》源本除武侠书库 4 类水印（整行 52 + 行内 52 + 方括号 52 + 全角网址 52 = 208 处）外，还叠着 1998 年第三方站点「炽天使书店」4 处 + BBS 回应残留 1 处共 5 处，第一轮把前者清光了、后者**零命中**（残留检查里正是这两组报非 0）。**处理**：水印清除要**两面都做**——繁体面（用繁体关键词）留一道，转简后再补一道（用简体关键词），两侧幂等、重复执行无副作用。**校验**：转简后 count 一批繁简两版关键词（`炽天使/熾天使`、`回应人/回應人`），全部为 0 才算过；`welcome.to/silencer` 这类**纯 ASCII 域名**是最好用的锚点，繁简两面都能命中，优先搜它
  - **【必踩的坑】劣质繁体老的标点是"误替"而非"缺失"，可按主导用法批量归一**：1998 年前后 BBS／书店打包的老电子书经多次转码后，会成片出现全角标点被换成形近符号——`．`（全角句点）替 `，`、`｜`（全角竖线）替 `！`、单个半角 `-` 随机插在汉字之间当杂符。实例：《云海玉弓缘》`．` 171 处（"念完之后．曹锦儿将名单一卷"）、`｜` 14 处（"快来救命呀｜．"）、孤立 `-` 45 处（"心中一想-。"），另有私用区乱码字符 15 个（U+E000 区，如 `\ue20d` 夹在"取X了"中）与带调拼音残留（`chún`→唇 32 处、`rǔ`→乳 6 处）。**判定与处理**：先统计该符号的位置与后继字符分布——若压倒性出现在"该用逗号/感叹号/破折号"的位置，就 `re.sub` 按主导用法统一替换（`．`→`，`、`｜(?=[．]?\s*”)`→`！`、`--`→`——`、其余孤立 `-` 删、PUA 直接删），**不要逐处人工判断**（171 处的量级不允许）。**注意别误伤正文**：`.to/silencer` 里的是**半角**句点属正文，只换**全角** `．`；`(chrysotile)` 这类带括号的矿物学/专业英文属正文，只删"夹在汉字之间"的孤立字母。**顺带**：形近字损坏（着→看、脸→睑、刺→剌、荡→汤、上→士、人→入、晴→睛、未→末）**不做批量修复**——无法可靠穷举，且修复会引入新错，正确做法是"标注为版本缺陷 + 引文避开脏段"
  - **【必踩的坑】章回体小说的"回末套语缺失率"不能直接当结论报**：章回体（梁羽生、还珠楼主、王度庐）每回末固定为「`正是：七言对句。` + `欲知后事如何？请听下回分解。`」，但老电子书的水印往往正好压在这一段上，把套语整段替换掉。实例：《云海玉弓缘》52 回中只有 39 回能检出「下回分解」、50 回能检出「正是」，缺的 13 回（第10–16、21、22、31、37、49、52 回）集中在被站点水印侵蚀的区段。**若照实写进 SKILL.md"本书仅 74% 的回有套语"，就是把版本缺陷写成了作者风格。** 判定：按回逐段扫"末三段"，若某些回整块缺套语而同一区段又检出过水印，即为水印侵蚀，应写成"每回必有，本样本 N 回因源本水印缺失"。**统计项要用对口径**：回末对句形制（7+7 占比）、套语三变体（请听/请转/请看）这类**形制结论不受影响**，只有"出现率"这一项需要标注口径
  - **【必踩的坑】zhconv 转简后仍会残留港台异体字，必须补一道"异体字表逐个 count"的校验**：zhconv 覆盖的是"繁简"映射，不覆盖部分**港台习用异体字**。实例：梁羽生《幻剑灵旗》转简后「**擡**」**37 处原封不动**（擡眼望天／擡出爹爹的牌子／擡杠／擡头），而「抬」为 0——不补这一刀，"抬眼望天"这类句子在样本里全是错字，且会污染高频词与引文（范例引文回验时就是靠这一条暴露的）。**做法**：转简后对一张异体字候选表逐个 `count()`，非 0 即补替换。候选表（本书实测残留/为零，但别默认 zhconv 全覆盖）：`擡→抬、祗→只、儘→尽、甦→苏、纔→才、妳→你、牠→它、蹟→迹、盃→杯、汙→污、啟→启、牀→床、祢→你、讎→仇、喫→吃`。**顺带**：本书另修 1 处 OCR 错字「花桥→花轿」（"坐着徐家的花桥给擡进徐家大门"），说明**异体字扫描要同时留意形近错字**，可用"以 `擡/抬` 为锚点抽上下文复读"的方式发现
  - **【必踩的坑】回内小节标记写成 HTML `<center><b>小节名</b></center>`，且约七成不是独占一行**（`<center>` 剥除与校验的完整做法见下方同题条目，此处只补两条**新增子坑**）：① **不只有 `<center><b>` 一种写法，还有裸 `<b>`**——《幻剑灵旗》42 处小节标记里有 5 处形如 `<b>（一）</b>`，正则需 `r'<center>\s*<b>(.*?)</b>\s*</center>|<b>(.*?)</b>'` 同时覆盖带与不带 `<center>` 两种，只写第一种会漏；② **小节标记常残缺不全，绝不能拿它当统计单元**——本书第 4 回只有"（一）（四）（五）"（缺二、三），部分回用"一、二、三 + 名字"（`一、慢性中毒`）、部分回用裸"（一）（二）"，若按小节切分会出现单元数错乱、字数参差（本书 42 处标记 ÷ 12 回 = 3.5，看着整齐，实际分布 3–6 个不等）。**判定**：先数每回小节标记个数是否均匀，不均匀就**以回/章为统计单元**，小节名只作叙事结构说明写进 SKILL.md
  - **【必踩的坑】敏感字拼音替换会跨书复现，且可能叠加"OCR 错字 → 拼音"的连环污染**：`chún`（唇）这一条已在《时空浪族》《幻剑灵旗》两本书上各现一次（后者 12 处：嘴唇／朱唇／尽唇舌／反唇相稽／唇边）。**但其中混着一句连环坑**：`‘学无前chún，达者为师’` ——它不是"唇"，而是原文「**後**」先被 OCR 误成「唇」、再被站点转成拼音，正确还原是「**学无前后**」。**识别办法**：其余 11 处上下文都有"嘴／朱／尽／反／边"等强搭配可直判为「唇」，唯独这一处搭配不通；此时**联网比对其他版本**（如 zhuyinlibrary 等站点同一段落）可确认是"前唇"这个已被全网复制的 OCR 产物，按谚语正字还原为「学无前后」。**通用校验**：清洗后 `re.findall(r'[a-zA-ZÀ-ÿ]{2,}', 样本)` 必须为空；**注意区间要放宽到 `[A-Za-z\u00C0-\u024F\u1E00-\u1EFF]{1,8}`**——`À-ÿ` 只到 U+00FF，漏掉扩展拉丁区的 `ǎ/ě/ǔ/ǐ/ǒ`（详见下方「扫带调拼音会漏字」条目）
  - **【必踩的坑】"样本即全本"不止于短篇，长篇也可能只有十几回**：判定依据**只能看 txt 自身的章数**，不能按篇幅或外部目录推断。实例：《幻剑灵旗》全书仅 **12 回、31.8 万字**——按"网文 200 章"的习惯会以为前 20 章只是全书一小半，实际提取前 20 章就是全本。梁羽生作品普遍 12–20 回，温瑞安中篇 15–20 章也常见。**做法**：先扫章标记总数，若 ≤20 就直接取全部，并在「样本说明」写明"本书仅 N 章，样本即全本，所有结论基于全书统计"，**同时把 readme 模板里"前 20 章样本"的措辞一并改掉**（照抄模板就是错的）。附带好处：全本即样本时**不需要再跑"样本 vs 全本"对照**校验，但小样本（数千至数万字符）里**凡计数 <10 次的对照项都不能立为硬规则**

   - 内容简介、内容简介、故事梗概、作品简介
   - 书评、读者评论、推荐语、媒体推荐
   - 作者的话、后记、前言、序言、楔子（若非正文章节）
   - meta信息（HTML标签、Markdown元数据、文件头信息）
   - 广告、版权声明、免责声明
   - 空行过多的连续空行（压缩为单个空行）
   - 章节内的页码、水印文字
   - **作者考据自注（金庸作品特有）**：章末或章中常插"注：……"的史实考据段落。`extract_chapters.py` 已内置 `strip_author_notes()` 自动剔除（光杆"注："段整块删到下一章标记；"注：xxx"段往下吞掉不含对话标记的续段）。**脚本兜不住时须手工复核**：用 `grep -n '^注：' 样本.txt` 扫一遍，尤其是章末那几条——注释混在章末会被 analyze_style.py 当成"章末 120 字"采进钩子统计，把一条注释误判成一种钩子句式。注意**"原注："（诗文内部原作者自注）属正文，不能删**
   - **段尾游离 ASCII 冒号**：部分网抓版把 `？！……` 删掉后在段尾留下一个 `:`，一并清理（脚本已处理）
   - **【必踩的坑】网文 txt 的"更新时间行 + 图片占位 + 章末作者按 + 颜文字"**：番茄/起点类网抓 txt 每章章首都有一行 `章节更新时间：2023-09-28 16:33`，部分章首还插一张 CDN 配图 `[[IMG:https://p3-novel.byteimg.com/xxx~tplv-noop.image]]`；章末常附作者按与读者互动内容（`ps：根据建议，暂时将本书更新时间调整到下午三点，各位读者……`、`求月票`/`推荐票`/`催更`）以及只剩颜文字的排版残片（`玲珑宗宗主：(͡°͜ʖ͡°)✧`）。
     - 更新时间行会被 analyze_style.py 当成"开篇 120 字"采进开篇习惯统计（《不死帝师》20 章**全部中招**）
     - 图片占位会被当成一段正文，**段数虚增 1 段、字数虚增约 130 字**
     - 章末作者按与颜文字会被当成"章末 120 字"采进钩子统计（《不死帝师》第 20 章末的 `ps：……` 一度被当成该章钩子）
     - `extract_chapters.py` 的 `strip_webnovel_meta()` 已覆盖全部四类。注意图片占位**不能指望 `BRACKET_PAT` 兜底**，它有 `{0,40}` 长度上限，几十上百字符的 CDN 长链会整条漏网，必须单独按整行匹配（已补 7 条单测：`[[IMG:url]]`/`[IMG:url]`/`![](url)`/`<img>`/更新时间行命中剔除，`【审判】`/普通对白不误删）
   - **【必踩的坑】网文清洗的两个反向失误：误删正文 与 作者按残留**（《诡舍》实测）。清洗规则既要防漏删，更要防**误删正文**——后者无声无息，比漏删更致命：
     - **误删正文**：`pat_misc`（求月票/推荐票/`各位读者`/催更/加更）原本对整行 `search()` 无条件删除，结果正文台词 `"村子招待所隔壁有免费的食堂，各位吃饱喝足之后，可以到处逛逛……"` 只因含"各位"就被整行删除。**弱特征词（各位、免费、加更）不能单独定罪**。现加双重保护：`len(s) <= 40 且不含台词引号 “ ”`，宁可漏删也不误删正文
     - **作者按跨多行**：`PS：……` 之后常跟着 `新书每天6000字起步。`、`晚安！` 等独立短行，只删 PS 首行会把它们留在样本里。现改为**状态机**：命中 PS 行后向下吞到下一个章节标记（`CHAPTER_PAT`）为止，`MAX_PS_LINES = 12` 兜底防止吃掉整章
     - **验收方法**：清洗后把脚本输出与"手工清理基准版"逐行 diff，`set(行)` 应完全相等。本次两处 bug 就是靠 diff 暴露的——单看字数只差 75 字（0.15%），肉眼绝不会发现
   - **【必踩的坑】`strip_author_notes()` 的 NARR 判据对网文会失效**：该函数删除金庸式"注：……"考据时，会往下吞掉"不含对话标记"的续段，靠 `NARR = (道|说|问|答|喝|叫)[:：]?[“"]` 判定何时停。但**网文大量台词独立成段且不带说话人标签**，且 `宁秋水道：` 后跟换行（台词在下一行）也不匹配，命中率会暴跌（《诡舍》实测仅 **11/2468 = 0.4%**）。一旦正文里出现"注："开头的段落，后续整片纯台词会被吞光。已补分支 `(道|说|问|答|笑)[:：]\s*$` 覆盖"标签段 + 台词另起段"格式
   - **清洗后必查**：`grep -c '章节更新时间' 样本.txt`、`grep -c 'IMG' 样本.txt`、`grep -cn '^ps[:：]' 样本.txt` 均应为 0。若不为 0，先用正则手工清掉再进 Step 3，否则开篇习惯与章末钩子两个维度必然失真
   - **【必踩的坑】水印关键词里不能有弱特征词**：`SITE_KEY` 曾包含裸 `整理`，结果《不死帝师》正文"整理遗容""整理得长乐帮""整理一下衣衫"被整行当水印删掉（第 6 章从 83 段掉到 80 段，2 段正文凭空消失，段长与对话占比统计跟着失真）。**弱特征词（整理、提供）单独出现不能定罪**：现拆为 `SITE_KEY`（仅用于有包裹语境的括号块）与 `SITE_STRONG`（独立成行时必须命中强特征：书库/shuku/.com/下载/TXT/由…整理）。改完已回归验证：倚天、侠客行两本残留命中仅为正常行文，无真实水印漏网
   - **【必踩的坑】外来书籍碎片混进正文——最隐蔽的数据污染源**：网抓 txt 有时会把**另一本书的片段直接拼进句子中间**（OCR 拼接／转码错位），内容类型与本书毫无关系，读起来像"作者突然跑题"，极易被当成风格或被引进范例。实例：《时空浪族》前 20 章混入 6 处**哲学／政治类书籍**碎片，全部卡在句子中间——`你有手有腳的【這些思想被教會斥爲“異端”。主要著作有《論自然的區  】，要到那裏就到那裏`、`公司還上了市【主義代替革命的辯證法。認爲“存在決定意識”是“獨斷主  】，賺到盤滿缽滿時`、`我每天都看財經報章和雜志【驗，闡明了人民民主專政的性質和職能……  】，很快可以奉上計劃書`。**判定方法（关键）**：这类混入片段**结尾必定带连续两个半角空格**，是拼接残留标记，可直接用 `re.search(r'  +', line)` 全局扫描定位（实测 6/6 全中，零漏零误）。**修复**：把「混入起点 → 两个空格」整段删掉，前后文自动拼回通顺原句（删完逐条复读验证）。**危害**：①污染段长分布与词汇统计；②混入片段常带成对引号，会**打破引号平衡**，修复后务必校验 `count('“') == count('”')`（该书修复前 1454/1453，修复后 1450/1450）。**混入内容类型无法预判**，除半角空格外再补扫一遍 `異端|辯證|專政|絕對精神|道統|主義|定律|宇宙|哲學` 这类与题材不符的学术词，命中后逐条查上下文
     - **这个坑的量级可以远超预期——一本 20 万字中篇里可能藏四五十处，且"混入起点"必须逐处人工判定**。实例：梁羽生《龙虎斗京华》全书 **48 行命中双空格，其中 46 处是真混入**（另 2 处是全角缩进行里混了 ASCII 空格，如 `　　　  　——调寄采桑子`，误报）。混入内容统一是**马克思主义哲学史／哲学辞典**（马克思、恩格斯、黑格尔、费尔巴哈、列宁、柏拉图、亚里士多德、斯宾诺莎、王守仁、王引之、孙武、犬儒学派、逻辑经验主义），共 1,148 字，密度约每 4,500 字一处——**几乎每回都有**。
       - **难点在于切点**：混入段结尾的双空格好定位，但"混入从哪里开始"没有标记，只能读语义。可用的规律：①**混入段常以残缺词开头**（`克思主義創始人…` 是被砍掉"马"字的"马克思主义创始人"、`4卷在恩格斯逝世後…` 是页码残留），残缺即起点；②混入段结尾接的正文后半段**往往以「，」开头**（`…肯定  ，燭光在…`），因为原句是"前半句，后半句"被切开；③**删掉后前后文必须能拼回通顺原句**——拼不通说明切点选错了。**务必逐处复读验证**，不要图快批量按标点切。
       - **修复前先把"接缝"显式打出来**：对每处命中行做 `before, after = re.split(r'  +', line, maxsplit=1)`，打印 `before[-50:]` 与 `after[:30]`，再据语义定切点、写成 `(行号, 保留到哪个锚点)` 的清单交给脚本批处理。**不要一边看一边手改**，46 处手改必漏必错。
       - **危害不止统计**：混入段里含 `——`（会把破折号密度算高）、含 `《》`（书名号）、含 `（）`（括号）、含拉丁串（被判成"英文串插入缺陷"）、含成对引号（打乱引号平衡）。所以它**同时污染维度2 标点、维度5 词汇、维度8 环境**，一处不清就是整份报告失真。修复后要复扫：双空格归零 + 题材不符学术词归零（`馬克思|恩格斯|黑格爾|柏拉圖|亞裏士多德|辯證|唯物主義|邏輯經驗主義|列甯`）+ 引号／括号／书名号重新计数
     - **这个坑还会"连片爆发"——不是散点，是整段整段地中招**。实例：梁羽生《冰河洗剑录》（wuxiashuku 同源本）全书 **161 行命中双空格，样本区（前 20 回）70 处、剥离 1,792 字**，混入内容同样是一本**哲学辞典／马克思主义哲学史**（马克思、恩格斯、黑格尔、费尔巴哈、柏拉图、亚里士多德、波普尔、笛卡尔、邹衍、王守仁、孙中山、普列汉诺夫，还带拉丁文 `rheinischezeitung·organderdemokratie`、`lnlsagogenporphyrii`、`aristoteles`、`ibnfrushd`）。**判定"是否连片"的方法**：把命中行号打出来看间距——**行号呈等差数列（如 280/283/286/289/292…每 3 行一处）即说明污染段是连续多段、每段各插一处**（正常排版是"段、空行、段"，故间距恰好 3）。连片区的典型规模是一次 5–10 段全中。**这意味着"每 N 千字一处"的密度估算会严重低估**：本书样本区 70 处 / 22.8 万字 ≈ 每 3,200 字一处，但集中区里密度高 5 倍。
     - **切点规律（比《龙虎斗京华》更硬）**：①碎片是**插入**而非替换——**双空格右侧紧接的字符一律是「，」**，且这个逗号就是原句被挤到右边的那个逗号，删掉碎片后前后自动拼回通顺原句（实测 70/70 全中，可作 sanity check：若某处 `after` 不以「，」开头，先怀疑切点或该处非本类污染）；②**碎片长度毫无规律（2–40 字跨度）**，所以"固定回退 N 字"的办法完全不可用，**只能逐处读语义定切点**；③碎片常**把紧邻的标点一并吃掉**——本书有 3 处 `”` 被碎片吞掉，导致清洗后出现 `“丘兄，你怎么了？翼仲牟粗通医理`（台词缺收尾引号）。**所以切完必须扫一遍引号配对，把"因碎片丢标点"的段落单独列出**，别当成原书特征。
     - **操作方式（70 处规模下已验证）**：把每处命中行裁成"双空格前 150 字 + `␣␣` + 后 80 字"导出成清单文件，一次性通读、逐条写下 `(行号, 保留到哪个锚点)`，再交脚本按"在 PRE 里 `rfind(锚点)` 之后到双空格整段删除"批处理。**切完必须把 70 处接缝重新打印出来逐条回读**——本次靠这一步确认 70/70 都拼回了通顺原句
   - **【必踩的坑】敏感字的拼音替换（与「囗」占位符同类的另一种缺字）**：网抓 txt 常把情色／敏感字替换成**带声调的拼音**混排在中文里。实例：《时空浪族》「唇」→`chún`（23 处）、「乳」→`rǔ`（1 处），形式为 `香chún`、`紅chún`、`rǔ房`。**扫描时 `re.finditer(r'[a-zA-Z]{2,6}')` 会零命中**，因为 `ú`/`ǔ` 不在 `a-zA-Z` 区间。危害同「囗」：会被当成作者用词抄进 SKILL.md；**范例摘录若不避开，会把拼音混排当成风格示范**。处理：范例一律选用不含拼音替换的段落，并在 SKILL.md「样本说明」里点名这是版本缺陷，仿写时正常写原字
    - **子坑：`[a-zA-ZÀ-ÿ]` 仍然会漏字，必须用 `[A-Za-z\u00C0-\u024F\u1E00-\u1EFF]`**。`À-ÿ` 只覆盖 U+00C0–U+00FF，而带调拼音里 **`ǔ`=U+01D4、`ǎ`=U+01CE、`ě`=U+011B、`ǚ`=U+01DA** 全在 U+0100 以上的扩展拉丁区，一律漏网。实例：《弹指惊雷》同一本书里「唇」→`chún`（29 处，`ú`=U+00FA 在 `À-ÿ` 内，**抓到了**）与「乳」→`rǔ`（12 处，`ǔ`=U+01D4 在区间外，**一条没抓到**）并存——只扫到一半，会误判"已清理干净"。**校验方法**：清洗后跑 `re.findall(r'[A-Za-z\u00C0-\u024F\u1E00-\u1EFF]{1,8}', 样本)` 必须为空；该正则同时能兜住"英文串凭空插入"（兄弟坑）
   - **【必踩的坑】直角引号「」会让 analyze_style.py 崩溃**：部分书（如《赤心巡天》）用日文直角引号「」(U+300C/300D) 而非全角" "。analyze_style.py 第70行的引号字符集只列了" "「'」'」等，不含「」，对话检测 `withq=0`、纯对话独立成段统计触发 `ZeroDivisionError`，后续所有维度都不输出。处理：抽取清洗后生成一份「」→" " 的副本（仅用于 analyze 统计），范例摘录与 SKILL.md 规范一律还原为原书「」；word_pairs.py 不依赖引号，直接跑原文件即可。
   - **【必踩的坑】英文串凭空插入型转码缺陷（拼音替换坑的兄弟类型）**：网抓 txt 除把缺字替换成带调拼音（chún/rǔ）外，还会把敏感／缺字替换成**凭空插入的英文数字串**。实例：《亵渎》强`uushop`者→强者、祭`uushop`祀袍→祭祀袍、赤`xiao2`裸→赤裸、阿喀`yes2boy`琉斯→阿喀琉斯——这些串夹在相邻汉字之间、删掉即还原正确字，**不是正文英文**。判定：`re.findall(r'[a-zA-ZÀ-ÿ]{2,}')` 扫出拉丁串后，凡夹在中文之间、删之能拼回正常词的，一律直接删除（不必还原原字，删串即得正字）。区分真英文（如「1KM」「yes」）：真英文前后有空格／数字／标点，凭空插入串前后是紧邻汉字。`www.txt80.com` 类站点广告整行删。
   - **【必踩的坑】没有"第X章"标记的书：温瑞安"部名 + 小标题"双层章法**。温瑞安《四大名捕》系列（如《少年追命》）的 txt **一个"第X章"都没有**，全书只有"非缩进行"充当标题——段首一律缩进两格全角空格，标题行不缩进。形态是**部名独占一行、下一行才是章名**（`小相公` ⏎ `洒开大步`）。识别办法：把所有"非缩进、非空、非水印、非文件头"的行取出，**若某行的下一个候选标题行与本行相邻（间隔 ≤2 行）则判为部名（BU），否则判为章名（CH）**；随后以 CH 为切点、以 BU 更新当前部。实例：《少年追命》40 行非缩进行 = 4 行文件头 + 5 个部名 + 20 个章名 + 10 行水印 + 1 行 `=已完结=`，切出 20 节、30.4 万字，逐章字数 11,300–17,700（同量级，校验通过）。**坑点**：部名与章名可能同名（本书"小相公"既是部名也是章名），**不能按字符串去重**，只能按位置判定。
   - **【必踩的坑】回内的 HTML 小节标题会"粘在正文段尾"，不剥就等于往正文里掺标题**。梁羽生等港台单行本的网抓 txt 常在回内用 `<center><b>小节名</b></center>` 标记场景小节，且**极少独占一行，绝大多数直接挂在上一段正文末尾**。实例：《弹指惊雷》60 处，形态如 `齐世杰沉吟半晌，说道：“奇怪，奇怪！” <center><b>冷若冰霜的少女</b></center>`、`她怀着怅惘的心情离开了魔鬼城……的。   <center><b>陷身冰窟</b></center>`，其中 1 处还是无 `<b>` 的裸写法 `<center>小妖女回来了</center>`。**若整行保留**，这些行会带着标签进样本（污染段长、把标题算成句子）；**若整行删掉**，会连带删掉一段正文。正确做法：对每行先 `re.sub(r'<center>.*?</center>', '', 行, flags=re.I|re.S)` 抠掉标题块，**再把剩余文本 strip 后非空者留作正文段**，最后用 `</?(?:b|center|br|p|div|i|font)[^>]*>` 兜底清残留标签。**校验方法**：清洗后 `grep -c "<center>" 样本.txt` 与 `grep -c "<b>" 样本.txt` 必须为 0；再看该回段数有没有莫名少掉几十段
   - **顺带：同书可能混入"场景分隔符"与"网友批注"**。《弹指惊雷》另有 7 处 `※※※※※※※※※※※※※※※※※※※※※※※※`（24–34 个 ※ 独占一行，是场景切换符，须整行删），以及 1 处**第三方读者批注** `（youth按：羽生真是想当然，此时在世杰心中此少年还是生死之敌呀……）` 混在正文段尾——**注意区分"作者自注"与"网友批注"**：同书内梁羽生本人的 `（按：龙叶上人是比桂华生高一辈的武学大师……事详拙著《冰魄寒光剑》。）` 是**跨书互文的自注，属正文必须保留**，而 `（xxx按：……）` 里的署名是网友 ID（youth），是论坛转录残留，必删。**判定诀**：看"按"字前是"作者自述口径"还是"带引号吐槽第二人称评价"
     - **子坑·第三种变体：部名与章名「同行」，且每部重新起算章号**。实例：温瑞安《游侠纳兰》的标题行长这样 —— `古之伤心人 第一章 歌中山` ⏎ `纳兰一敌 第一章 马上上马` ⏎ `此情可待成追忆 第一章 此情可待成追忆`。它既不是变体一的"部名独占一行"，也不是变体二的"第N章 + `<h2>第M回</h2>`"，而是**部名 + 第X章 + 章名挤在同一行**。两个后果：①章标记不在行首，`CHAPTER_PAT` 的 `^[ \t　]*第` 直接失败，脚本报 `[错误] 未识别到任何章节标记`（全书 26 章零命中）；②三个部各自从"第一章"重新起算，所以**连"按出现顺序取前 N 章"也救不了**——按号码去重会让第 2、3 部整体丢掉。
       - **处理办法**：在 Step 2 之前加一道预处理，把标题行规范化为行首的**全书连续编号**：`^[ \t　]*(部名)[ \t　]+第(CN+)章[ \t　]*(标题)$` → 改写为 `第N章 标题`（N 顺序递增，不做去重）。部名另存一张 `章节映射.tsv` 备查，**不写进样本**（写进去会污染标题行统计）。规范化后再喂 `extract_chapters.py` 即 26 章全中、字数同量级。
       - **校验方法**：规范化后打印章标题条数，与人工扫一遍源文件数出的条数对齐（本书 26 条）；提取后确认 `grep -c '^## 第'` 等于该条数，且逐章字数落在同一量级（本书 3,700–8,700 字）。
   - **【必踩的坑】逐字拉开间距的水印还有"下划线 + 错位字符"变体，归一化必须删掉一切非 CJK／字母数字字符**。第八十条只讲了"字间插空格"型，但《少年追命》实测有更狠的写法：`八_ 零_电 _子_书_w_ w_  w_.t _x_t _0_ 2. c_o_m`、`㈧_ ○_電_芓 _書_Ｗ_ w_ ω_.Τ_ Χ_t_零_ 2.c_o _m`——**空格 + 下划线 + 全角字母 + 希腊字母（ω/Τ/Χ）+ 圈号（⑧/㈧）+ 异体字（芓/耔/孑）**混排。第一版只做 `to_halfwidth()` + 去空白，漏掉 3 处（其中 2 处被误判成章标题），**直接导致切出 23 节而非 20 节、两节字数骤降到 1,584 / 5,515（正常 15,000）**。正确做法是先 `to_halfwidth()`，再 **`re.sub(r'[^0-9a-z\u4e00-\u9fff]', '', 转小写)`** 把一切标点／下划线／圈号／希腊字母全部剥掉，最后在纯化串上查 `电子书`/`電子書`/`电孑書`/`耔書`/`奇书网`/`宝书网`/`txt02`/`qishu`/`baoshu`/`重要提示`/`备用域名`/`防止失联`，并补两条兜底（含 `com` 且含 `t`+`x`/`w`；含 `www`）。**校验方法**：清洗完 `grep -c "电子书\|txt02\|qishu\|baoshu" 样本.txt` 必须为 0；再看切出的节数是否与预期一致、各节字数是否同量级——**节数或字数异常，第一个要查的就是水印漏网**。
   - **【必踩的坑】文末 `=已完结=` 是"单等号包裹"标记，`^[=＝]{3,}` 抓不到**。第八十条的 `re.fullmatch(r'[—\-─]{3,}')` 与 `^[=＝]{3,}.*$` 都要求 3 个以上符号，而 `=已完结=` 只有单等号 + 汉字。后果：它会被算作末章的最后一个正文段，**末章章末钩子直接被污染成 `=已完结=`**（本书第 20 章末句因此失真）。处理：单独加一条 `re.sub(r'^[=＝]{1,3}已?完[结本][=＝]{0,3}$', '', s)`，并用 `if s in ('=已完结=', '已完结')` 兜底。**校验方法**：提取后 `grep -c "已完结" 样本.txt` 必须为 0。
  - **【必踩的坑】`re.sub(pat, rep, s, flags)` 的第 4 个位置参数是 `count`，不是 `flags`——`re.M` 的值是 8，会被当成"只替换前 8 处"**。这是本次流水线里**最危险的一条**：它不报错、不警告（Python 3.13 只给一条 `DeprecationWarning: 'count' is passed as positional argument`，一闪而过），报告里 `re.findall(pat, s, flags)` 又是正确计数（findall 第 3 参就是 flags），于是**日志打印"处理 48 处"而实际只替换了 8 处**，剩下的 40 处原样留在正文里。实例：《广陵剑》独立成行的页边水印 48 处，正则写 `re.sub(r'^[　 ]*（武俠書庫.*）[　 ]*$', '', body, re.M)`，跑完日志说 48，实测残留 51 行水印——因为 `count=8` 只砍掉了前 8 个。**唯一正确写法**：`re.sub(pat, rep, s, flags=flags)` 关键字传参；或者干脆把 `flags` 编进正则（如 `(?m)`）。**自检方法**：凡是 `re.sub` 带 `re.M`/`re.I`/`re.S` 的，一律全局搜一遍确认是关键字传参；并在每步 `sub` 后立刻打残留计数（`len(re.findall(pat, s, flags))` 应为 0），**"处理了 N 处"这个数字不能自证成功**。
  - **【必踩的坑】繁体正文里会混着简体字形的块，水印清除必须繁简两面各做一道**。第八十条说"先做繁简归一，否则繁体字形匹配不到"，但《广陵剑》是**反过来**的：正文通篇繁体，而**结尾块是简体**（`TXT电子书由【武侠书库 wuxiashuku.com】…`、`武侠书库网址：…`、`梁羽生所有武侠小说：…`），用繁体正则 `^TXT電子書由【武俠書庫.*$` 一条都打不中。**正确做法**：所有水印/头尾块正则里的关键词写成繁简兼容式（`TXT[电電]子[书書]由【武[侠俠][书書][库庫]`、`梁羽生所有武[侠俠]小[说說]`、`全[书書]完`），或者在繁转简**之前**和**之后**各跑一遍清除。**校验方法**：清洗后同时搜 `wuxiashuku`／`武俠書庫`／`武侠书库`／`熾天使`／`俠客居` 五个词，必须全为 0——只搜其中一个是查不出来的。
  - **【必踩的坑】PUA 私用区缺字不要一律删，先统计码位再按语境补回**。第八十条给的处置是"PUA 直接删"，但《广陵剑》实测 **17 处 PUA 全部是 GBK 转码时丢失的实义字**，删掉会留下"賀蘭健薩天照""身形搖，"这种断句。**正确做法**：先 `Counter(re.findall(r'[\ue000-\uf8ff]', t))` 看码位分布——本书只有 7 个不同码位（U+E1A4/E19A/E203/E224/E1EE/E1D7/E20D），**码位少且集中说明是系统性缺字，可以逐码位按语境补回**：把每个码位的全部上下文打出来（`.{0,32}码位.{0,32}`），7 个码位一共 17 条，人工通读一遍即可定字（本书定为 和/好/晃/夥/還/虎/回），补完再验证句子读得通。**判断标准**：码位种类 ≤ 10 就值得补；若散到几十上百种（真乱码而非缺字）才按删除处理。
  - **【必踩的坑】回目与回末对句是两套完全不同的七言，萃取时极易张冠李戴**。章回体小说里"回首七言对仗回目"和"回末 `正是：` 后的七言对句"是**两个独立的集合，内容毫无关联**——同一回里两句七言各说各的。实例：《广陵剑》第44回回目是「豺虎未除腾剑气 龙蛇混杂入京华」，而它回末的对句是「中华自有能人在，岂容胡虏任嚣张？」。我在写 SKILL.md「回目形态」举例时直接抄了回末对句当回目，靠**引文反向回验**（`if 行 not in 样本: 报错`）才暴露出来——肉眼看完全没破绽，两句都是工整七言。**防错方法**：①回目一律用 `re.findall(r'^## (第\d+回 .*)$', 样本, re.M)` 从样本标题行直接提取，绝不从正文里摘；②回末对句一律按"找到 `正是：` 所在段 → 取其**下一段**"取，绝不跨回混用；③**两者都要写进 SKILL.md 时，标题必须分别标明「回目全集」与「回末对句全集」**，并在正文里加一句显式防错提示（"仿写时必须各写各的，别把回目抄进章末"）。
   - **【必踩的坑】"样本即全本"不能按外部目录／书评页推断章节数，只能看 txt 自身**。印刷版目录与网抓合并本可能差一个数量级：《少年追命》印刷版每部下另有十几个小标题（"故事原来是这样开始的""万岁万岁万万不能睡""在太阳底下晾晒的腌肉""他用的武器亘常是一个问号"），而**网抓 txt 已把这些小标题并入正文**，只剩 5 部 × 4 节 = 20 节。若据 kongfz/百度百科的目录页判断，会误以为"前 20 章只是全书一小半"而白跑一遍全本校验。**正确做法**：读 txt 开头的 `『内容简介:…』`，用其中列出的篇名数与实际切出的节数对齐；再核对印刷版小标题在 txt 中是否只作为普通正文行出现（`s.count('万岁万岁万万不能睡')` = 1 即正文行，若为 0 则是真小标题、需重新设计切分）。
   - **【必踩的坑】行内站点水印有两套全角括号，且和"真夹注"长得一模一样**。梁羽生这批港台网抓本的句内水印是 `［武俠書庫TXT］`（**全角方括号**）与 `（wuxiashuku.com）`（**全角圆括号**）。三个坑叠在一起：① 只写半角 `\(` 正则会全盘漏网；② 剔水印必须用字符类 `[（(]…[）)]` 同时覆盖全角半角；③ 但 `（wuxiashuku.com）` 与梁羽生本人的真夹注 **`（中宫方位）`／`（即今河北）`／`（事详《冰川天女传》）` 形态完全相同**，按"括号内容像网址就删"会误伤。**做法**：命中条件收紧为"**括号内必须含 `wuxiashuku` / `武俠書庫` / `TXT` 才删**"。实例：《风雷震九州》行内水印 41 处全删、真夹注 5 处全保，零误伤。**校验**：清洗后 `s.lower().count('wuxiashuku')`、`s.count('TXT')` 必须为 0，同时 `s.count('（')` 应等于人工数出的真夹注数（本书 5）。
   - **【必踩的坑】"哲学辞典混入片段"不是孤例，同一批次的 txt 要预设有这个病**。前一条目记的《龙虎斗京华》46 处混入（马克思主义哲学史／哲学辞典碎片、以双空格收尾、后续以「，」起头）在**同批网抓书里照样有**：《风雷震九州》回 1–20 内实测 **56 处**（全书双空格行 96），内容同源（卢梭／皮尔士／卢卡奇／普纽玛／modus），切点规律也一致。**做法**：拿到一本新书先跑 `len([l for l in lines if re.search(r'  +', l)])`，非 0 就别当成"排版小瑕"，一律按混入处理；**修完必须回扫双空格归零 + 题材不符学术词归零 + 引号／括号／书名号重新计数**（混入段同时污染段长、标点、词汇、引号四项）。
   - **【必踩的坑】转简之后必须"重建回目标题行"，否则统计脚本会崩**。清洗脚本把回目标题写成 `## 第N回 标题` 独占一行、正文另起；**转简时若只 `zhconv.convert()` 正文而漏掉标题行，样本里就没有 `## 第N回` 了**——后果不是"少一行标题"这么轻：① 按 `re.split(r'^## ', s)` 分章的统计脚本会把 20 回算成 0 段并抛 `ZeroDivisionError`；② 即使不崩，"逐章字数"与"回末钩子"两项全部作废。**做法**：转简时把标题行拼进同一个文档再整体转换（`TRAD_DOC = '\n'.join(sum([['## 第%s回 %s' % (h['no'], h['title'])] + h['paras'] + [''] for h in hui], []))`），**并且因为回目本身也是对仗七言两句（如 `第1回 四海翻腾云水怒 百年淬厉电光开`），它会一并被转简，这正是想要的**。**校验**：`grep -c '^## 第' 样本.txt` 必须等于该书的回数。
   - **【必踩的坑】`己`／`已` 混用是网抓繁体 txt 的新一类量大错字，且不可全局替换**。《风雷震九州》回 1–20 实测 **约 40 处**把「已」写成「己」（`根基己固`／`己是朝着彭洪`／`己给李文成一刀`／`己被`／`己有`／`己在`），而**同一份样本里 `自己`／`知己`／`舍己为人`／`身不由己` 是正确的**——所以**全局 `己→已` 会把正确用法一起改坏**，`zhconv` 也不处理。**处理**：归入"源文件录入错字"清单供识别，**不在样本里修**（不影响语感统计，只影响引文可读性，引文必须逐条标注）。**发现方法**：`re.findall(r'.{5}己(?=[是经在把被知有再将先和向给]).{5}', s)`——只在「己」后接动词／副词时告警，命中率高于裸计 `s.count('己')`（后者会被"自己"淹没：本书 `己` 240 次，其中真错约 40 次）。
   - **【必踩的坑】复姓被削掉部首，是"人名系统性错字"，会在高频词表里露头**。《风雷震九州》把 **`宇文雄`（宇文为复姓）写成 `字文雄`，样本 58 处、正确写法仅 7 处，全书 167 处**——这是本书量最大的录入错误，而它**恰好排进 TOP60 高频词组**，所以"把 TOP60 逐条肉眼过一遍"是最省事的发现办法（`字文雄` 一眼可疑：中文没有"字"姓开头的三字人名搭配）。同类要留意的还有 `析圣因`→`祈圣因`、`萧忐远`→`萧志远`、`时凌风`→`叶凌风`、`武上`→`武士`、`虎抓`→`虎爪`（后者 17 处，属"形近字量大项"）。**做法**：把高频人名逐条与联网人物表核对，错的一并写进 SKILL.md 第四节。
   - **【必踩的坑】文件名里的书名常常是错字，写进 SKILL.md 前必须联网核对**。本次源文件名为 `风雷震九洲@wuxiashuku_com.txt`，而梁羽生该书的正式书名是 **《风雷震九州》——「州」不是「洲」**。**做法**：拿作者创作年表（如梁羽生 35 部作品年表）核对书名用字与连载年份／报纸，把**正式书名写进 SKILL.md 的 `display_name` / `description` / 标题**，同时**技能名（skill name）仍按用户给的名字原样使用，不要擅自改**；文件名的差异在「样本说明」里点一句即可。年份也要核：《还剑奇情录》常被误记为 1961，实为 **1959.11–1960.5（香港商报·谈风）**——同一作者多本横向对照表里年份错了，整条演变轴就不可信。

  - **【必踩的坑】"章内整块自重复"——同一回正文被复制两遍，章节数与字数校验全部不会报警**：源文件某些回存在**回内部**的整块重复（不是跨章重复），切分与统计都照常通过，唯一露馅的是**这一回的段数约等于同书其他回的两倍**。实例：《侠骨丹心》第 7 回 244 段，后 122 段是前 122 段的逐字复制——修掉后第 7 回 122 段，与其余 19 回（约 116–131 段）同量级。**检测办法**：对每回求最小 `o>0` 使 `ps[o:] == ps[:len(ps)-o]`，命中即判为整块重复，保留 `ps[o:]`（**注意切点必须取 `ps[o:]` 不是 `ps[o-1:]`，多留一段会把重复的最后一段留在开头**）。**校验办法**：打印各回段数，出现「某回≈其余两倍」立刻查这一回的中段。
  - **【必踩的坑】"两个连续半角空格"是外来书籍碎片最可靠的锚点，但"切点在哪"必须逐处人工判定**：这类碎片（哲学／思想史／政治类书籍片段）被拼进句子中间，**结尾必定带连续两个及以上半角空格**，可直接 `re.search(r'  +', line)` 全局定位。实例：《侠骨丹心》全书 **38 处**（约 1.9 处/回，无回不有）。**做法**：①先对每处 `before, after = re.split(r'  +', line, maxsplit=1)`，打印 `before[-50:]` 与 `after[:30]`；②据语义在 `before` 里挑一个「正文锚点」（碎片之前最后一串正常文字），写成 `[(回号, 段号, 锚点), …]` 清单；③交脚本批处理 `before[:i+len(a)] + after`；④删完逐条复读，**前后文必须能拼回通顺原句**，拼不通说明切点选错。**不要一边看一边手改**（38–46 处手改必漏必错）。**校验**：双空格残留归零 + 引号／括号／书名号重新计数（碎片常含成对引号，会打破引号平衡）+ 题材不符学术词归零（`馬克思|恩格斯|黑格爾|柏拉圖|辯證|唯物主義|哲學`）。
  - **【必踩的坑】说话标签后的引号左右颠倒共有四型，后三型只能靠"占比检测器"筛出来**：① `道。”` → `道：“`（可直接用正则＋**黑名单**处理，黑名单是「知／八／路／同／穴／厚」这类会正当收尾在「道」字上的实词结尾，如「难道」「难道」「八道」）；② `心想。”` → `心想：“`；③ `暗笑。”` → `暗笑：“`；④ `道。“` → `道：“`。**②③④ 三型没有固定词表可循**，用占比检测器自动筛：分别 `Counter(re.findall(r'([\u4e00-\u9fff]{2})：“', raw))` 与 `.")`，凡某标签的 `。”` 型占比 **≥95%** 即判为缺陷（实例：《侠骨丹心》筛出 心想／暗笑 两型，`道。“` 11 处）。**修复后必须复扫**「标签 + `”：“`」这类组合归零。
  - **【必踩的坑】源文件用异体字时，对全本 `str.count()` 会得到假的"零出现"，从而把作者习惯误判成版本插入**：实例：《侠骨丹心》回末源文件写作「**慾**知后事如何？請聽下回分解」，于是 `raw.count('欲知')` = **0**，而样本（经 zhconv 转简）有 20 处「欲知」——单看这个 0 会得出"「欲知」是样本独有的版本插入"的错误结论。同类还有 zhconv **一律不转**的港台异体字：「**擡**」（抬）、「**汙**」（污）、「**騒**」（骚）。**做法**：全本对照**必须先把全本整体 `zhconv` 转简再计数**，不要直接对繁体原文 count。
  - **【必踩的坑】都/部、士/土 这两组形近字会整批讹变，且"低频 bigram 扫描"会被跨词边界噪音彻底淹没**：`Counter(某字 + 下一个字)` 是定位它们的好工具，但**必须逐组看上下文，不能按比值定罪**。实例：《侠骨丹心》「部」共 30 处，其中 `部的 4／部位 4／部分 2／部落／部通／部吸／部变／部带／部打` 全是合法的「全部／面部／部位」用法，只有 `部来 2／部用 2／部已／部没／部是／部不／部很` 这 9 处才是「都」的讹字；「士／土」同理，`道土→道士 5／尘士→尘土 3／张土诚→张士诚／卫土道→卫士道／隐土→隐士` 要改，而 `面如土色／泥土／国土／撮土为香` 不能碰。**校验**：改完对该字再跑一次 `Counter`，确认剩下的后继组合全部都讲得通。
  - **【经验】回末定式的"一个字之差"就是同作者的分本标记，绝不能照抄上一本**：同为梁羽生——1954《龙虎斗京华》用「欲知……**请看**下回分解」；1967–69《侠骨丹心》用「欲知后事如何？**请听**下回分解」（51 处中 49 处）；1975《弹指惊雷》与 1976–80《幻剑灵旗》又回到「**请看**」。拿到新书先 `grep` 一下「下回分解」前的十个字，把「请听／请看／且听／且看／请看下回」如实写进 SKILL.md，**这一条是仿写时最容易错、也最容易暴露的门面**。
  - **【经验】"标签＋逗号带台词"是与冒号式并行的一种合法写法，必须单独统计**：实例：《侠骨丹心》`道，“` **14 处**（`仲长统哈哈笑道，“不错，你刚刚回来，是该独自闯荡江湖……`、`怔了一怔，问道，“那武当派的秦少侠呢？”`），与 `道：` 2,395 处混用。若只按 `道：` 统计，既漏掉这一型的频次，也会漏掉 SKILL.md 里该写的那条规范。统计时把 `道[，,]“` 与 `道：“` 分开数。
  - **【经验】"回内小节标记"不是通则，别把上一本的结论搬过来**：《幻剑灵旗》《弹指惊雷》用 `<center><b>小节名</b></center>` 把每回分成 3–6 节，于是可以从"回内小节"这一级去分析叙事结构；《侠骨丹心》**全篇一个都没有**（只在全书末出现过一次 `<center>——————全書完——————</center>`）。构建新书时先 `raw.count('<center>')` 与 `raw.count('<b>')` 各数一遍，再决定要不要把"回内小节"写进叙事节奏维度。

  - **【经验】"摘引文"是发现残留错字的最后一道、也是最灵的一道网，别把它当复制粘贴**：按维度铺好要引的 10 段原文后**逐段复读**，凡读不通的地方就是错字。实例：《侠骨丹心》的「江海大→江海天」「好环→好坏」「萍水相理→萍水相逢」「凶光偷地→凶光倏地」「步步后道→步步后退」「摇摇晃晃←摇摇晃灵」「离官→离宫」「王候住宅→王侯住宅」**全部是在摘引文这一步才暴露的**，前面的计数扫描一处都没抓到。**正确顺序**：先摘引文并复读 → 汇总错字清单 → 批量修 → **重跑 `analyze_style.py` 与 `word_pairs.py`**（样本变了，统计数字会微变，SKILL.md 引用的数必须与最终样本一致）→ 最后跑一次「引文回验」（把 SKILL.md 与 style_examples.md 里所有引文片段逐个 `in 样本` 断言，命中率必须 100%；不命中的要么是错字，要么是从别的书模板里抄来的假引文——后者极容易发生，务必查）。

  - **【必踩的坑】"双半角空格"有两种完全不同的病因，必须先分类再动手——一类是外来碎片接缝，一类是单字缺失占位**。《冰河洗剑录》条目立的规矩是"双空格右侧紧接的字符一律是「，」"、删掉即拼回原句；**这条规律不是通则**。实例：梁羽生《白发魔女传》（wuxiashuku 同源本）全书正文双空格组 **220 处**，按接缝形态分成两类——
    - **A 类·外来碎片（58 处）**：判据是「**双空格前 60 字内含学术词**（哲学／唯物／唯心／辩证／主义／范畴／认识论／阶级／专政／马克思／恩格斯／黑格尔／列宁／萨特／谭嗣同／geulincx／metaphysica…）**且双空格后首字符是「，」**」。与《冰河洗剑录》同型，按既有办法逐处定锚点切除。
    - **B 类·单字缺失占位（约 162 处）**：**前无学术词、后不接「，」**，是转码时被吃掉的汉字留下的空格（3 个空格 = 1–2 个汉字）。实例：`千拱列`→`千岩拱列`、`短栽花`→`短锄栽花`、`老于海`→`老于宦海`、`万马脱`→`万马脱缰`、`长眉人鬓`→`长眉入鬓`。
    - **更狠的子坑：半角"单"空格也是单字占位**（`镜明 师`→`镜明禅师`、`青 道人`→`青蓑道人`、`杨 家`→`杨涟家`）。所以**正文行内所有半角空格一律删除**（标题行的回目分隔空格除外），《白发魔女传》此一项就删了 719 字符。**A/B 混在一起时，若照抄"右侧必是，「"的老规矩，162 处缺字会被当成碎片整块切掉，正文直接被打穿**
    - **B 类的处理原则**：**不要试图全部补回**——无法可靠穷举。只按上下文与外部校对本补**高置信项**（专名、成语、回目、章末对句，本书补回约 40 处），其余标注为版本缺陷、引文避开。
  - **【必踩的坑】样本里某项计数为 0 或极低时，必须跑"样本 vs 全本"对照才能定性，否则会把版本缺陷写成作者风格（反向也会救回真风格）**。实例：《白发魔女传》前 20 回破折号 **0 处**、省略号 0.2‰、分号 0.0‰。若照写"梁羽生不用破折号"就是错的——**全本 32 回也只有 33 处**，比值 0.00，说明是 txt 转码整体丢掉了破折号，属版本缺陷，应在 SKILL.md 明写"仿写时慎用，但不要据此断言作者不用"。**同一轮对照还救回了真风格**：`什么 381 : 甚么 1`、`知道 274 : 知晓 3`、`立刻 23 : 登时 0` 在全本同样成立，确认"现代白话骨架压倒"是作者真实笔法而非版本现代化。**做法**：凡涉及抽样敏感项（破折号、省略号、回末定式、古今用词比），一律对**转简后的全本**再 count 一次，两个口径对上才下结论（全本转简后再 count，繁体原文会得出假 0，见《侠骨丹心》条目）。
  - **【必踩的坑】编辑注被塞进人物台词里，形态是"全角引号包住的短注"，与作者自注必须区分**。实例：《白发魔女传》4 处——`客氏道：“哎唷，由哥儿，“注、熹宗名朱由校”这会给人笑话的…`、何萼华台词中的 `“按：即汉孝武皇帝之后”`、叙述中的 `“‘天启’是由校年号”`。**与梁羽生本人真夹注的差别**：作者自注用**圆括号**（`（中宫方位）`、`（事详《冰川天女传》）`），编辑注用**弯引号且夹在台词/叙述中间**，一读就不通顺。**识别办法**：`re.finditer(r'“[^”]{1,20}”', s)` 取所有短引号块，筛含 `注／校／按／年号／即／原作／应作` 的，逐条看是否在人物台词内，命中即整块删（删完句子自动复原）。**危害**：它会被 `analyze_style.py` 采进"对话体系"与"多发言标签段"示例，把"在台词里插注"误判成一种写法
  - **【必踩的坑】回目讹字没有任何频率信号，只能外部核对；但字数可当自动校验线**。回目只出现一次，`count()` 与 bigram 扫描全部抓不到。实例：《白发魔女传》4 处回目讹字——`恨意朱全消`→`恨意未全消`、`蜩塘`→`蜩螗`、`历劫腾新愁`→`历劫剩新愁`、第 17 回五言被排成 `珠宝招强／人荒林恶／斗神威折／魔女群盗倾心`（应为 `珠宝招强人 荒林恶斗 神威折魔女 群盗倾心`），**全部靠联网比对 wikipedia／百度百科／图书馆目录才确认**。**自动校验线**：章回体回目若是对仗体，先数上下联字数，本书实测 **上下联各 9 字、句内切 4+5 或 5+4、上下联切点一致（20/20 回只有这两种切法）**——字数或切法对不上的，必是讹字或被断开，优先查它
  - **【必踩的坑】批量 `著→着` 加保护词会误保护，保护词必须带边界**。《白发魔女传》全书 `著→着` 470 处，为保护实词加了白名单「著名／著书」，结果 `扶著书` 被当成"著书"保下来（正确是"扶着书"）。**做法**：保护词要么带左右边界（如只保护 `著名` 不保护 `著书`），要么改完单独扫一遍"保护词出现在非词位置"的组合并逐条修。**同类**：`汤→荡` 的批量替换也要先保护 `赴汤／参汤／落汤／汤里火里`（本书 30 处"汤"里 23 处是"荡"的讹字，7 处是真"汤"）
  - **【必踩的坑】人名系统性讹字的量级可以大到 500+，只有"高频词组 TOP 榜"能一眼看见**。《白发魔女传》把主角 **岳鸣珂** 全书写成 `岳呜珂` **515 处**（正确写法仅个位数）——"呜"与"鸣"形近，转码批量讹变。**发现办法与"复姓被削部首"条目同源**：把 TOP60 高频词组逐条肉眼过一遍，`呜珂` 这种"不像中文人名"的搭配一眼可疑；再补一道 `Counter(字 + 下一字)` 扫同形近组（`人／入` 30 处、`一驾／一惊` 5 处、`收抬／收拾` 6 处、`名宇／名字` 7 处、`愣／怔` 15 处）。**修完必须重跑统计并做引文回验**，因为这些字同时出现在高频词表、范例引文与 SKILL.md 正文里
  - **【经验】摘引文这一步的产出量远超预期，别嫌它慢**：《白发魔女传》按维度铺好 10 段范例后逐段复读，**一口气又抓出 6 处计数扫描全漏的错字**——`嫁祸插脏→嫁祸栽赃`、`好些宇→好些字`、`圜首乏刑→圜首之刑`、`霎忽使到→霎忽便到`、`长眉人鬓→长眉入鬓`、`持蜓闯宫→持梃闯宫`。加上此前扫描抓到的，全书订正 8 类 530+ 处。**这些错字全部落在"读起来别扭但不报错"的位置**，只有通读整句才会发现，所以**范例必须选长段、逐段读，不能只 grep 关键词**
  - **【必踩的坑】哲学碎片污染规模可达全书 400+ 处，启发式覆盖率只有 ~65%，最终仍要靠"分批读接缝 + 建锚点清单"的笨办法**。实例：梁羽生《散花女侠》（wuxiashuku 同源本）**全书 423 处、样本区 270 处**，是梁羽生系列里污染最大的一本。试过两条自动路线都不够——①启发式（前 60 字含学术词 + 双空格后首字符是「，」）覆盖 65%；②用本书未污染正文建 bigram 词频表找"最低频切点"，提升有限。**最终有效流程**：`re.finditer(r'  +')` 列出全部接缝行号 → 按 60 条一批打印 `行号 + 双空格前 52 字 + 后 12 字` → 人工判读每处切点 → 写成 `(行号, 锚点字符串)` 清单 → **用验证脚本自检**：对每行取 `bf.rfind(锚点)`，要求 `0 < sp - cut < 90`，不满足就打印 WARN 立刻改锚点（本书 269 条锚点 5 批全部一次命中）。**锚点要选切点左侧最后一段"只可能出现一次"的原文**，越靠近切点越安全
  - **【必踩的坑】源文件是繁体时，"欲知后事如何"可能写成异体「慾知」（心字底），用简体字去搜会得 0 命中，然后误判"本书没有章末套语"**。实例：《散花女侠》源 txt `欲知` 计数 **0**、`請聽` 33、`請看` 4、`分解` 36——因为全书写作 `慾知後事如何`。**做法**：统计章末套语这类关键词时，先用正则只搜**不变形的部分**（`分解`、`正是`），或同时搜繁简两种形态（`欲知｜慾知`、`请看｜請看`、`请听｜請聽`），再回读上下文确认形态。**同理**：`analyze_style.py` 的各类词表也应先确认底本是繁是简
  - **【必踩的坑】章末套语可能在同一本书内部切换用字，必须逐回统计全本，抽样下结论必错**。实例：《散花女侠》前 20 回里**第 1、2 回用「请看」，第 3 回起全书改用「请听」**；跑完全本 36 回才发现「请看」又在第 24、34 回各冒出一次（**请看 4 回 / 请听 31 回 / 末回无套语**）。而《白发魔女传》是全书 20/20 统一「请看」。**做法**：给每行的"所属回"打标（`owner[行号] = 回号`），再 `re.search(r'欲知[^\n]{0,40}?(請看|請聽|且聽)')` 逐回抓，输出 36 行清单 + 计数分布。**顺带能抓出套语变体**：《散花女侠》第 12 回 `請聽第四集分解`（分集连载）、第 15/17 回问号变逗号、第 13/21/28 回讹字（`後一事／後募／後享`）
  - **【必踩的坑】禁忌词扫描的计数会被相邻字误匹配污染，必须逐条看上下文再下结论**。实例：《散花女侠》`analyze_style.py` 报 `觉醒 2`，看着像网文水词，逐条一看是 **`一觉醒来` 里相邻的"觉""醒"两字被当成词**——本书根本没有"觉醒"这个动词。同批的 `境界 8`、`丹田 1`、`筑基 1` 经核查全是正当用法（武学修为／穴位／修墓）。**做法**：维度9 的禁忌词清单**必须逐条 `finditer` 打印上下文**，计数 > 0 不等于真的用了这个词；确认是误计后要在 SKILL.md「版本缺陷说明」里写明"此项为脚本误计"，否则使用者会照着禁用一个正常词
  - **【经验】"全书只出现 1 次的汉字"是找单字 OCR 错字最高效的一张网**。《散花女侠》样本 21.3 万汉字里不同字 3237 个，**只出现 1 次的有 446 个**，把它们一次性打印出来（`''.join(once)`），肉眼扫一遍就能挑出 `誊`（包誊→包着）、`瑶`（玛瑶→玛瑙）、`祆`（棉祆→棉袄）、`炔`（一炔岩石→一块）、`烯`（烯烂→稀烂）、`硼`（硼个正着→碰个）、`铬`（铬住→格住）、`撚`（熟撚→熟稔）、`裣`（裣在→裣衽）等。**注意假阳性**：`玫瑰／麒麟／葡萄／傀儡／褴褛／槟榔／鞑靼／腼腆` 这类连绵词与成语里的字天然低频，扫到就跳过，别改
  - **【经验】回目形制校验越严越值钱——本书 36/36 全中，等于一条免费的自动校验线**。做法：对每回回目 `re.sub(r'^第X回\s*','')` 后按空格切 4 段，算 `len(a)+len(b)` 与 `len(c)+len(d)`。《散花女侠》实测 **上下联各 9 字、句内切 4+5 或 5+4、上下联切点一致，36/36 无一例外**（比《白发魔女传》的 20 回样本更硬）。**字数对不上的回目必是讹字或断行，优先查它**。本书据此 + 外部三家目录（百度百科／中文百科／海宁市图书馆）订正 7 处回目讹字：`去道山村→古道山村`、`好人戏义士→奸人戕义士`、`大棒寨旗→大棒搴旗`、`正气凛强粱→正气凛强梁`、`方堡奇情→古堡奇情`、`忠臣爱香火→忠臣受香火`、`正气属峨嵋→正气属娥眉`
  - **【必踩的坑】开篇词与引诗同样是 OCR 重灾区，且底本自己会互相打架，要靠"几家权威版本投票"**。实例：《散花女侠》第 1 回开篇词，《浣溪纱》一句源 txt 作 `白草新词消滞酒`，学巴书馆／99csw／掌阅三家均作 **`自草新词消滞酒`**（"自草新词"与下句"消滞酒"对得上，"白草"不通），而 qb5 与源 txt 同族——**同源的水印本不能当第二证据**，必须找不同来源。同批修的还有第 8 回引宋人谢驿诗 `谁把苏杭曲子诓？荷花十里挂三秋。那知卉木无情韧` → **`谁把苏杭曲子讴？荷花十里桂三秋。那知卉木无情物`**。**做法**：遇到诗词一律先联网核，且至少取两个不同站点
  - **【经验】"全本对照"两个方向都可能翻盘，别只往"版本缺陷"一边想**。《白发魔女传》破折号样本 0 / 全本 33 → 判为**版本缺陷**；而《散花女侠》破折号样本 17 / 全本 27（按样本占比**预估样本应有 14**）→ 两者吻合，判为**真实笔法（只是极少，0.1‰）**。**判据是"实测值 vs 按字数比例预估的值"是否吻合**，不是看绝对值大小。本书还顺带确认了破折号的具体用法分布：**A 类台词中断约 11 处**（`道：“我爹，——”`）、**B 类叙述引出解释约 5 处**、C 类词牌署名 1 处——**这种"极少但形态高度集中"的用法最值得写进 SKILL.md，是仿写时唯一敢下手的依据**
  - **【经验】引文回验必须用"逐行比对"，整段比对会在多行块上假失败**。多行引文（开篇、章末三件套）在 md 里被拆成多个 `> ` 行，用 `整段 in md` 判断会误报 MISS。**正确做法**：`for line in 整段.split('\n')` 逐行断言 `line in 样本` 且 `('> '+line) in md`。**同时要过滤注文**：md 里自己写的说明行也以 `> ` 开头，会被 `startswith('> ')` 一起抓进来，用 `**`、`订正`、`→` 等标记排除，或直接按 json 结构逐行校验（例文用 json 中转生成时最省事）
  - **【必踩的坑】HTML 标签结构是连载真实排版，要保留；但水印会钻进标签里拼错位**。《飞凤潜龙》有 65 个 `<center><b>…</b></center>` 小节标题（1966 年连载的分段钩子），**清洗时必须抽出来保留成独立段**（建议加 `◆` 前缀便于统计时剔除），不是缺陷。水印形态也更刁：全角假名式 `［ｗｕｘｉａｓｈｕｋｕ．ｃｏｍ］`、`<cen（wuxiashuku.com）ter>`（水印插进标签中间把标签切断）——**水印剔除要在标签处理前后各跑一遍**，只跑一遍必漏
  - **【必踩的坑】完结标记可能和结尾正文粘在同一行，整行判水印会误删结局**。《飞凤潜龙》最后一行是 `……倒在她的怀中————（完）————`，结局段和 `————（完）————` 同行，按"含（完）即丢行"的规则会把全书结局删掉（本书结局是三人殉情，删了等于毁样本）。**正确做法**：先把行内 `—+（完）—+` 剥掉再判整行，或只剥标记不删行
  - **【经验】短中篇可能整体无回末套语，小节标题自身也会有 OCR 讹字**。《飞凤潜龙》（1966）7 回全部以叙事悬念收尾，无"正是/欲知"——**1966 年连载文体已现代化，别把说书套语硬塞回去**。回目也从 9|9 对仗退化成 4–7 字短语，**没有形制校验线时，外部核对是唯一手段，且小节标题同样要核**（本书一个标题作 `难道他们育什么私情`，"育"是"有"的 OCR 错字，藏在 66 个标题里只出现一次）
  - **【经验】样本=全本时（短中篇）跳过全本对照，所有统计都是真值**。《飞凤潜龙》全书 5.97 万字符，清洗后样本即全本，破折号 19 处、套语 0 等定性结论**无需再跑"实测 vs 预估"**——这是唯一省一步的特例；长篇（>20 万字符）仍必须做
  - **【必踩的坑】碎片插入会把原文连标点一起吃掉，接缝修复后必须扫异常标点对**。《飞凤潜龙》碎片切除后出现 `。，`（碎片连"等课题。"五个字一起吞了，联网核对补回"给那老车夫用布袋蒙着他的头"）。**每处接缝修复后都要扫 `。，／，。／。。` 三种异常对**，有就回头核原文
  - **【经验】SKILL.md 里的引文必须与样本引号形态逐字一致（弯引号），禁止用直引号转写、禁止用"……"缩略引用**。《飞凤潜龙》终验发现 8 处引文写成 `"这——"` 直引号形态、1 处缩略成 `上午……下午……`——样本里全是弯引号全文。**"引文均逐字取出"是写进 SKILL.md 的承诺，回验要连引号形态一起比**（直引号版 `in 样本` 必 MISS，恰好能抓住）

4. **清洗后校验**：
   - 确认提取的内容为纯净章节正文
   - 每章正文不少于500字（低于此值视为不完整章节，跳过并从后续章节补取）
   - 总计不少于1章有效正文
   - 若清洗后无任何有效章节内容，回复：
     > 提取失败！无法从提供的内容中识别到有效的小说章节正文，请确认内容包含章节标记（如"第一章"）和正文内容。
   - 抽一段清洗后的正文通读，确认无站点广告、无目录、无重复段落

### Step 3: 十维文风萃取

**先跑量化统计，再下结论。** 20 章样本通常有 30–50 万字，无法整体读入上下文逐字通读，必须靠"量化统计 + 章首章末抽样 + 代表段落精读"三段式完成。

```bash
[PYTHON] scripts/analyze_style.py <Step 2 产出的清洗txt> [章数，默认全部]
```

脚本按维度输出可直接引用的数据：段落长度分布、平均句长、标点密度与零出现标点、对话占比与台词长度、对话标签频次、视角标记词频次、叙事过渡词频次、比喻与拟声词频次、高频词组 TOP60、环境描写占比、每章开篇与章末 120 字、禁忌词计数。

**古今用词对照必须另外跑一条命令 —— `analyze_style.py` 不跑这项，别以为跑完它就够了：**

```bash
[PYTHON] scripts/word_pairs.py <Step 2 产出的清洗txt> [额外对照词文件]
```

脚本内置约 45 组常用对照（`罢/吧`、`甚么/什么`、`登时/立刻`、`倘若/如果` 等），按比值自动分三类：

- **A 硬规则**（古体压倒 >10:1）→ 规范写作"只用 X，禁用 Y"
- **B 现代体压倒** → 提醒别为了古风硬拽文言
- **C 中性项**（0.1~10 倍）→ 标注"两者皆可，无需回避"
- **D 仅供参考**：单字虚词（便/即/均/皆），对手词在白话里本就超高频，比值受题材影响大于受文风影响，**不进硬规则**
- 末尾自动生成「现代词替换表」，可直接贴进 SKILL.md

已内置避坑：`么` 用负向后顾断言 `(?<![甚什怎这那多])么` 计数，否则会被 甚么/怎么/这么 污染成假的"古体压倒"（《侠客行》实测：污染后 18.4:1 判为硬规则，修正后 2.0:1 实为中性项，结论完全翻转）。补充自定义对照词时，写一个每行 `古体 现代体` 的 txt 作为第二参数即可。

拿到统计结果后，再抽取 3–6 段代表段落精读（开篇、对话密集段、动作/战斗段、情绪段、章末段），填入 `references/style_examples.md`。

**【必踩的坑】判断"版本缺陷 vs 作者风格"要跑全本对照，不能只看 20 章样本**：样本里某个标点或用法是"零出现/异常高频"，到底是 txt 版本归一化，还是作者本人习惯？只看 20 章无法判断。**做法**：直接对原始全本（几 MB 到几十 MB，`str.count()` 秒出）跑同样的计数，与样本比值对照——比值一致即为作者风格，可写成规范；样本独有而全本没有，才是版本缺陷。实例：《我不是戏神》20 章样本 `、` 0 次、`（）` 0 次、`【】` 42 次（2.1 次/章），全本 400 万字对照 `、` 124 次、`（）` 162 次、`【】` 4,326 次（2.2 次/章）——比值吻合，确认"少用顿号、不用圆括号、改用【】"是作者习惯，可安全写进规范；若只看样本，很可能误判成"txt 把顿号归一化掉了"而白白丢掉一条强特征。全本对照结果要写进 SKILL.md 的「样本说明」，注明"已通过全本校验，非版本缺陷"。
  - **例外：中篇/短篇书"样本即全本"，此项不适用**。若全书章数 ≤ 20（中篇小说、单行本短篇集），提取前 20 章就是全本，不存在"抽样 vs 全本"的落差，无需再跑一遍全本对照——但要**在「样本说明」里写明"本书仅 N 章，样本即全本，所有结论基于全书统计"**，否则读者会误以为结论只来自 20 章抽样（实例：温瑞安《杀人者唐斩》仅 15 章、6.4 万字，若照抄模板里"基于前 20 章样本"的措辞就是错的，readme 与 SKILL.md 都须改成"全部 15 章"）。同时中篇的统计基数小（数千到数万字符），**凡计数 < 10 次/事项的对照项（如 word_pairs 里"良久 2 : 很久 0"）都不能立为硬规则**，只能在 SKILL.md 里作"偏好参考"或中性项处理

校验通过后，逐条分析样本，客观总结，禁止主观脑补风格。分析过程中加载 `references/extraction_framework.md` 获取每个维度的详细分析指引。

**十个强制萃取维度：**

1. **叙事视角**：人称类型、全知/限知、内心独白频率、视角切换习惯
2. **句式特征**：段落长度、长短句比例、换行习惯、标点节奏
3. **对话体系**：说话口吻、动作神态搭配、对话长度、对话占比
4. **叙事节奏**：冲突推进速度、铺垫方式、日常描写占比、时间跨度
5. **词汇与修辞**：惯用比喻、专属名词、高频形容词、修辞分布
6. **情绪基调**：整体调性、情绪曲线、幽默类型、爽感来源
7. **章节钩子写法**：末尾悬念类型、钩子位置、句式特征
8. **环境描写**：描写密度、手法、位置、占比
9. **行文禁忌**：样本中不存在的叙事方式全部列为禁止项
10. **开篇习惯**：开篇方式、切入速度、前奏有无、衔接方式

**萃取原则：**
- 所有结论必须基于提供的正文，禁止凭空想象
- 描述具象化，拒绝空洞词汇——不写"文笔简洁"，改为"多用短句，单段控制在3行以内，高频换行"
- 引用样本中的具体用词、句式作为证据支撑
- 若某维度在样本中表现不明显，如实标注"样本中该维度表现不突出"
- **量化支撑**：每个维度的结论尽量带上脚本测出的数字（"平均每段 101.9 字""对话占比 28%""环境描写占比 2.1%"）。数字比形容词更能锁住语感，也更能防止 AI 回退到通用文笔
- **【必踩的坑】标点被归一化的 txt 版本**：不少网抓 txt 会把 `？！` 全部替换成 `。`，删掉 `……` 和 `——`。脚本会提示"零出现标点"，此时必须在 SKILL.md 里如实注明"该样本版本无问号/感叹号，疑问与感叹按标准标点书写"，**不得把版本缺陷写成作者风格**，也**不得据此禁止使用问号感叹号**
- **【必踩的坑】双字符标点要按"标点单位"计数，别被逐字符统计误导**（《诡舍》实测）：`analyze_style.py` 原先用 `for ch in '……——，。'` 逐字符遍历，`……` 与 `——` 是**双字符**，会被拆成两个单字符各打印一遍——输出里 `…` 1245 打印两行、`—` 82 打印两行，而同一份报告的"零出现标点"又只按双字符检测，两处自相矛盾。若直接引用 1245 当省略号次数，密度会算成 22.7/千字（**真实值 613 处 / 11.2 每千字，差一倍**）。已改为按 `punct_units` 列表遍历，并从单字符计数中扣除被双字符消耗的部分（`'—'` 减 `2×count('——')`）。**现版本输出已是真实值，可直接引用**
- **【必踩的坑】标点归一化有两种做法，判定方法不同，别只认"章末多余冒号"这一种**：
  - **替换型**（实例：《笑傲江湖》8080txt）：把 `？` 换成 `：`。**判定**：20 章末句结尾字符高度一致（全为 `：` 或 `”：`）。处理：剥掉冒号后再归类钩子，并在 SKILL.md 点名"禁止模仿章末多余冒号"。
  - **删除型**（实例：《连城诀》GBK 网抓版）：`？！……` 直接删掉，什么都不留。**判定**：看脚本输出的「段落末字符 TOP5」里是否混入**非标点字符**（如 `么:7  里:4`，对应 `你小命还在么` 这类被删掉问号的句子）。混入即说明该版本是删除型，**此时不存在章末多余冒号，切忌套用上一本的结论去写"禁止章末冒号"**。
  - 两种都要在 SKILL.md 注明"段末必须有终止标点（`。`或`”`）"，并要求仿写时 `？！……` 按标准用法书写。
  - **副作用**：删除型会**人为抬高平均句长**（本该断成两句的合并成一句，《连城诀》实测 40.9 字/句）。**不要把这个虚高值当成作者的句长目标写进规范**，应在 SKILL.md 注明"该数字被版本缺陷抬高，真实句长约 30–35 字"。
- **【必踩的坑】古今/雅俗用词必须逐本实测，绝不套用上一本的结论**：同一作者的不同作品、不同版本，古今用词比例可能截然相反。实测反例——《倚天》《射雕》样本"甚么 vs 什么"是 659:7 级压倒性偏古，而《天龙八部》样本是 535:586 近乎 1:1 混用（台词内 280/310、叙述中 255/276）。照抄前一本的结论会写出错误规范。构建时**必须**另跑一组古今对照词频：`罢/吧`、`登时/立刻`、`倘若/如果`、`须得/必须`、`甚么/什么`、`知晓/知道`、`兀自/仍然`、`便即/马上`、`如何/怎么`、`端的/究竟`。结果做成对照表写进 SKILL.md 的「词汇与修辞」与「词汇修辞规范」，并明确区分两类：
  - **硬规则**（悬殊 >10:1）：如"罢 328 vs 吧 4"→ 规范写作"只用'罢'，禁用'吧'"
  - **中性项**（接近 1:1）：如"甚么 535 vs 什么 586"→ 规范写作"两者皆可，无需回避"
  同时给出现代词替换表（吧→罢、立刻→登时、如果→倘若、必须→须得、马上→便即、这时候→此刻）。这项数据比形容词更能锁住时代语感，也是防止 AI 写出"古皮 modern 骨"的关键。
  - **子坑：修订版会彻底现代化，"甚么"可能直接归零**。《雪山飞狐》实测 `甚么 0 : 什么 179`——不是"混用"也不是"分工"，而是**古语被完全替换**，连选择性都没有。旁证在该书后记里：作者自述"原书十分之六七的句子都已改写过了"。同时《雪山飞狐》保留了一批与《倚天》《射雕》一致的硬项（登时 27:1、若 373:0、只是 103:2、何等 11:1），说明**现代化是分层的：虚词层改干净了，动作与评断层还留着古语**。写规范时按层分开写，不要一句"本书偏古"或"本书偏今"笼统带过。
  - **子坑：频次接近的对照词必须查上下文，不能只看计数**。`罢/吧` 是最容易翻车的一组：《倚天》《射雕》是"罢 328 vs 吧 4"（只用罢，禁用吧），但《碧血剑》实测是 **吧 368 : 罢 84**，光看计数会得出"用吧不用罢"的结论——**这是错的**。逐条查上下文后可见二者**语义完全分工**：`吧` 全部是句末语气词（别去吧、请进来吧、算了吧、明天再说吧），`罢` 全部是实词（饭罢、说罢、也罢、罢了、罢手）。正确规范是"语气词一律用**吧**，**罢**只作实词"，与《倚天》《射雕》恰好相反。**凡比值在 1:5 ~ 5:1 之间的对照词，都要抽 5–10 条上下文确认是"混用"还是"分工"**，再写规范。
  - **子坑：多义词要拆开算**。`马上` 32 次里 31 次是"骑在马上"，作副词的只有 1 次，与 `便即` 30 次相比不是"混用"而是"便即压倒"；`端的` 8 次里 6 次是"无端端/好端端"，作"究竟"义仅 2 次。计数时要把同形异义的用法剥掉，否则会写出错误规范
- **【必踩的坑】章末抽样要剔除非正文噪音**：部分 txt 会在章末混入排印校注（如《天龙八部》第 15 章末的"注：繁体字乾杯的乾……"）、章节字数统计、站点水印。这类内容会被脚本当成"章末 120 字"采进钩子统计，导致把一条校注误判成一种钩子句式。统计章末钩子时先肉眼过一遍 20 条末句，剔除非正文再归类。
  - **子坑：问号被替换成冒号，章末残留一个多余"："**。标点归一化不止"删掉"一种做法，有的版本是把 `？` 替换成 `：`（实例：《笑傲江湖》8080txt 版本 **20 章末句末尾全部残留一个多余冒号**，如"我既已认输，还比甚么暗器”："）。后果是脚本按 `。` 切句时末句取不到终止符，20 条钩子全被截成冒号结尾，无法归类。**判定方法**：若 20 章末句结尾字符高度一致（全为 `：` 或 `”：`），即可确认是版本残留，剥掉后再归类；同时在 SKILL.md 标点说明里点名"禁止模仿章末多余冒号"
- **【必踩的坑】别把"古/现"差异当成风格**：若样本是传统武侠等长段白描文体，切勿套用"网文短句流"的默认判断。先信数据——平均段长 100 字就是 100 字，不要写成"多用短句"
- **【建议量化项】维度10「开篇习惯」要统计"章首是否泛陈述句"，不要只写"以格言开场"这类形容词**。做法：取每章首段，人工/规则判定它是否**脱离了本故事人物与场景的泛论**（人生论断、呼告、二分法定义）。实例：温瑞安《少年追命》**19/20 章**首段是泛论——"失败是不会死人的，可是失望会。""在哪里跌倒，就在那里爬起来。""交友要讲缘份，可是成敌更讲究缘份。"——仅第 1 章以画面开场。这条一量化就变成可执行规范（"每章首段必挂一句人生论断，第二段起才落地到人物"），而"以格言开场"这种写法等于没说。同法的还有：统计"段首破折号（`^——`）密度"——它是温瑞安分期最灵敏的一把尺（实测：白衣方振眉 1 处 / 四大名捕会京师 5 处 / 神相李布衣 11 处 / 杀人者唐斩 24 处 / 爱上她的和尚 8 处 / 说英雄谁是英雄 165 处 / **少年追命 1,128 处 = 3.71‰**），每千字算一次即可判断样本落在"克制/中等/贯穿/招牌"哪一档，比"爱用破折号"精确得多。**追加一个数据点**：温瑞安《游侠纳兰》全书 535 处 = **3.25‰**（落在"贯穿"档，接近《少年追命》），但**分部差异高达 20 倍**——部二《纳兰一敌》（13–20 章）段首「——」2.30–4.97‰，部一《古之伤心人》0.24–2.91‰，部三《此情可待成追忆》0–1.64‰ 几乎归零、改用长句排比抒情。**所以这个尺子要在"部"这一级算，只算全书均值会把三档笔法抹平成一档**；写 SKILL.md 时应把分部密度如实标出，并提示使用者按目标调性对档（另一个可用同法的量是"段首（括号）段数"，本书仅 54 段 = 1.2%，但一旦出现可达一整个自然段的体量）。
- **【建议量化项】写 SKILL.md 前先算一次"段长直方图"，用它排除"硬断行"伪特征**。某些 txt 的个别段落是**排版截断**而非作者短句（如《少年追命》第 04 章"真的有自信的人是不需要信心 ⏎ 的。"）。判定办法：统计**不以终止标点（`。！？…：”`）结尾的段**占比——本书仅 164/11,443 = 1.43%，且多为作者本意的悬尾（"他决意先试试看，"），说明硬断行只是局部缺陷；同时看行长直方图**有没有在某一长度上出现尖峰**（硬断行会在 14/15/20 字处堆出孤峰，本书 5–30 字平滑衰减，故 15 字中位是真碎句流）。**两者都通过才敢把"碎句流"写进规范**，否则要把该维度标注为"版本缺陷"。
- **【必踩的坑】同一作者的不同作品，古今用词结论也可能完全相反，且方向未必是"越后期越古"**：实测《鹿鼎记》样本 `甚么 90 vs 什么 1303`（**白话反压古语 14:1**）、`何处 18 vs 哪里 138`、`知晓 3 vs 知道 409`、`忽然 81 vs 突然 165`（"突然"更多），与《倚天》《射雕》"甚么 659 : 什么 7"的古语压倒性优势方向完全相反。原因：金庸最后一部作品刻意口语化、市井化。**所以古今对照表必须逐本重跑，哪怕作者是同一个人**
- **【必踩的坑】第一回/楔子可能是"另一本书"**：长篇的开头常是历史楔子或背景铺陈，视角、人物、语域都与主线不同（实例：《鹿鼎记》第一回是明史案考据 + 顾黄吕三人，全回无主角），会显著拉高"考据叙述"权重。写 SKILL.md 时要在"样本说明"里点名，并注明"仿写主线请以第 N 回起为准"
- **【必踩的坑】繁体样本会让「维度9 行文禁忌」整表失效，输出的全 0 一个都不可信**：`analyze_style.py` 的禁忌词表是**简体硬编码**（系统/宿主/任务/面板/升级/境界/内心深处/仿佛整个世界/与此同时/就在此刻/然而…），在繁体样本里全部返回 0 —— 不是"作者没用"，是**压根搜不到**。实例：《时空浪族》脚本报 `系统 0 / 宿主 0 / 境界 0 / 内心深处 0 / 然而 0 / 因此 0`，看似可以写进"禁止清单"；实际把词表转繁重跑后，真实值是 `總之 4 / 只見 6 / 眼中的閃過 4 / 所以 51 / 覺醒 2`，**"所以"高达 51 次**——而简表搜"所以"也是 0（繁体作"所以"两字形同，但"系统/宿主"这类就完全不同）。**正确做法**：繁体样本必须把禁忌词表**整体转繁**（只映射 CJK，正则元字符不动）后重跑，再据结果写禁止清单；`word_pairs.py` 已有 `to_trad()`，可直接复用。同理，任何"样本零出现"的结论在繁体样本下都必须先确认是不是字形问题
- **【必踩的坑】古典／章回体／武侠样本会让「维度9 行文禁忌」出现**错检**（不是漏检，是搜到了但判错了），且方向是"把作者风格当成网文水词禁掉"**：`analyze_style.py` 的禁忌词表是按**当代网文**设计的，遇到章回体样本会连报好几个非零值，看着像"这本书混了网文词"，实际全是**正当用法甚至作者招牌**。实例：梁羽生《龙虎斗京华》报 `境界 4 / 丹田 4 / 任务 2 / 读者 2 / 列位看官 6 / 不由自主 2 / 他不知道 4`，逐条查上下文后结论完全反转——`境界`是"尚未达心如境界"（武侠修为义）、`丹田`是"气纳丹田""丹田穴"（内功术语）、`任务`是"另有任务"（普通词义）、`读者`是"读者诸君也许还会记得"、`列位看官`是"列位看官，这首踏莎行词…"——**后两个是说书人呼告，恰恰是本书必须保留的文体骨架**。同一本书里 `且看下回分解` 出现 9 次、`欲知` 10 次，而脚本按 `要知后事|且听下回` 的写法去搜**全是 0**——于是脚本同时犯了两个方向的错：把必守特征报成 0，又把正当用词报成禁忌。
  - **判定方法**：拿到非零值**先看题材**。若样本是章回体／话本／古典白话／旧派武侠，则 `列位看官／看官／读者诸君／且看下回分解／欲知后事／话说／书接前文` 这类全部是**作者的文体标识，要从"禁忌"移进"必须保留"清单**；`境界／丹田／经脉／真气` 在武侠里是**行内术语**不是系统流词；而 `且听下回／要知后事／读者` 这些"网文水词"标签**根本抓不到本书实际用的 `且看下回／欲知／列位看官` 写法**，需要自己重新 grep 统计。
  - **做法**：逐条打上下文（`re.finditer(r'.{20}词.{20}', s)`）再决定归禁还是归"必守"，**不要照抄非零值写禁止清单**。同一次构建里，把"脚本报的词"和"实际 grep 出的词"两张表都过一遍，才能发现上面这种"该报没报、不该报报了"的双向失真
- **【必踩的坑】现代都市题材下，`word_pairs.py` 的 A 类「硬规则」会整批误判，不可直接写进规范**：该脚本的对照词表是按古装／武侠设计的，遇到**现代都市题材**时，A 类会把"古体压倒"判到一批**其实只是现代书面语**的词上。实例：《时空浪族》A 类三条 —— `說話 39 : 講話 0`、`何不 14 : 為什麼不 0`、`喝道 8 : 喊道 0`，脚本判"只用 X 禁用 Y"，但**三条全是误判**：`說話` 在这本现代小说里是名词（"沒有說話"），`何不` 是标准现代书面语，`喝道` 是通俗小说通用说法，与古风无关。**判定方法**：先确认题材。若样本是现代都市／职场／科幻，A 类必须逐条人工复核后再决定是否采用；此时真正有指导价值的是 **B 类「现代体压倒」**（该书 `什麼 148 : 甚麼 0`、`知道 104 : 知曉 0`、`沒有 200 : 未曾 0`、`我們 203 : 咱們 0`），它才说明本书是**纯现代白话骨架**。同时要在 SKILL.md「样本说明」里写明"古今对照表对本样本不适用，A 类三条经人工复核为误判，不得据此禁止白话用词"，否则使用者会照抄出一份自相矛盾的禁用清单
  - **子坑：脚本的 B/C 类边界会与人工结论打架，`罢/吧` 是最典型的翻车项**。《风雷震九州》实测 `罢 37 : 吧 264`（0.14:1，落在"现代体压倒"档），脚本会提示"用吧不用罢"——**这是错的**：逐条查上下文可见 `吧` 264 处基本上是句末语气词、`罢` 37 处基本上是实词（罢了／说罢／也罢／罢手），正确规范是"**语气词一律写吧，罢只作实词**"，与脚本的分类语义无关。**做法**：凡是比值落在 0.1:1 ~ 10:1 之间的对照词（B 类下沿到 C 类全段），**一律抽 5–10 条上下文确认是"混用"还是"分工"再写规范**；`罢/吧`、`马上`（31/32 是"骑在马上"）、`端的`（8 处里 6 处是"无端端/好端端"）这类同形异义词，计数必须先把非目标义剥掉。
- **【必踩的坑】10% 的"引号不配对段"不等于 10% 的版本缺陷——必须先做状态机分类**。《风雷震九州》`“` 3,117 / `”` 3,104（全局只差 13，0.4%），但**段级不配对段高达 259 / 2,556 = 10.13%**。若直接写成"引号错位严重"，就把原书特征误判成了缺陷。**正确做法**：按段统计"多开引号段 : 多收引号段"，再看两者是否对称——本书 **起始型 137 : 终止型 122 基本对称**，说明主体是**原书的跨段台词排版**（一段开引、次段收引，全书 390 段处于"引号未闭"状态，且说话人标签段常以 `：` 收尾、台词另起一段，本书段末字符 TOP5 里 `：` 占 135 段）。**只有全局差额**（本书 13 处）**才是真漏**，形态如 `心中想道，“看这情形……`（逗号带引号）、`涵虚道：”还有一个客人呢！”`（左引号写成右引号）、段末以 `“` 结尾。**写 SKILL.md 时两句话分开**：① 跨段台词属原书特征、仿写可照用（并给一条实例）② 真错位约 N 处、仿写按标准配对。**别把两者混成一句"引号错位严重"**，也别把跨段排版当缺陷"修"掉——修掉就丢了梁羽生对白的呼吸感。
- **【建议量化项】同作者多本横向对照时，用"回末定式"和"含引号段占比"这两把尺，比看文笔描述可靠得多**。梁羽生四本实测：**回末定式是分期的硬指标**——1954《龙虎斗京华》纯说书套语「欲知后事如何？请看下回分解」9/13 回 → 1959《还剑奇情录》套语为主 11/12 回、已见「正是：」11 处 → 1965《风雷震九州》**三层齐全**（正是：＋对仗诗＋请听下回分解）20/20 回 → 1975《弹指惊雷》**砍掉套语只剩两层**（正是：＋对仗诗）20/20 回。**注意「请听」vs「请看」的用字**：1965 本统一"请听"（全本 55/55），1954–60 两本统一"请看"——这是脚本词表（`要知后事|且听下回`）抓不到、必须自己 grep 的差异。另一把尺是**含引号段占比**：四本横跨 1954–1975 稳定落在 **74.3–74.8%**（段首台词 5.4–6.1%、纯对话独立成段 1.9–3.3%），"对话织进叙述、不独占成段"是同作者最稳定的指纹，比反复摆动 5 倍的"段长中位"（91→30→69→43）更可靠。**横向对照表至少要含这几列**：年份、段长中位、含引号段%、纯对话段%、`道:`／`说道`、`原来`/回、回末定式；并在表注里写明各行的"量法口径一致"（汉字中位 or 字符中位）——口径不同会让读者误以为段长真的变了。

### Step 4: 生成文风锁定Skill

将萃取结果填入 `assets/skill_template.md` 中的标准模板，生成最终的Skill文件。

**生成流程：**
1. 加载 `assets/skill_template.md` 模板
2. 将模板中的`{SKILL_NAME}`替换为最终确定的Skill名称
3. 将模板中的`{NOVEL_TITLE}`替换为小说标题（如能识别）
4. 将十维萃取结果填入模板对应位置
5. 根据`{NOVEL_TITLE}`撰写description字段，包含触发词
5.5 **若样本为繁体（港台初版）**，先决定"保留繁体"还是"整体转简"，两条路径的产出不同：
   - **路径 A（保留繁体）**：在 SKILL.md「样本说明」里点明"样本为繁体，仿写输出用简体——只对齐词汇与句式，不转繁体"，并在写作执行要求里写死输出语言。`references/style_examples.md` 的引文保留繁体原貌并加一句说明（**不要手工把大段引文转简体**，长文本手转必出错字，且会破坏原书用字习惯）
   - **路径 B（整体转简，推荐给大陆网文向用户）**：用 `zhconv` 把清洗后的样本**整体**繁转简，再跑 `analyze_style.py` / `word_pairs.py` 与段落摘录。这样 SKILL.md 的词汇规范、替换表、引文全部落在简体上，用户照抄即可用，不必再做心智转换。
     ```bash
     pip install zhconv --no-cache-dir     # 【坑】沙箱下不加 --no-cache-dir 会报 safe-delete FAIL_CLOSED
     python -c "import zhconv,sys; sys.stdout.reconfigure(encoding='utf-8'); \
       s=open('样本.txt',encoding='utf-8').read(); \
       open('样本_cn.txt','w',encoding='utf-8').write(zhconv.convert(s,'zh-cn'))"
     ```
     **转简后必须补一刀**：zhconv 不处理"繁体助词 `著` 当 `着` 用"（实例：《大剑师传奇》182 处，"支撑著""挥散著"）。先用保护词表占住 `著名/著作/显著/名著/巨著/编著` 等实词，再把剩下的 `著` 全换成 `着`，否则同一本书里 著/着 混用会污染高频词与引文。
     **还要补一刀「沈→沉」**：港台版把「沈」当「沉」用（沈声/沈吟/沈静/下沈/昏沈/沈默），而 zhconv 不转——因为「沈」在简体里是常见姓氏。实例：《四大名捕会京师》367 个「沈」中 157 个该作「沉」。**做法：先保护人名、再全局替换**——占位保护 `沈云山/沈错骨/沈统领/沈四/沈三/沈兄/沈大/姓沈/沈…`（本书人名占 210 个），再把剩余「沈」全换「沉」，替换后复核残留「沈」是否全部后接人名用字（`沈错/沈云/沈四/沈统…`）。不处理会把「沈声道」当成作者标签写进 SKILL.md。
     **再补一刀「著→着」的坑：保护词表用子串匹配会误保护**。上一段说的"先保护实词再全替换"做法本身对，但**保护词一旦按子串命中，就会把正常用「着」的词一起保住**。实例：《龙虎斗京华》保护词表里有 `著有`，结果正文 `但他碰著有较强的…` 里的 `著有` 子串被命中，`碰着` 就没转成简体「着」，留了个「碰著有」的错字（全书只此 1 处，靠 `re.finditer(r'.{4}著.{4}')` 全量扫残留才发现）。**做法**：①保护词**宁少勿滥**，只留真正的实词；②**替换后必须全量打印残留的「著」及上下文**（应为个位数），逐条确认每个都是 zhù 义——`不著书`（不写书，正确）与 `碰著有`（应作"碰着有"，错误）字形相同，只能靠上下文判；③同理，做「沈→沉」时把**人名保护词表也按同样标准复核**，并打印残留「沈」的全部上下文确认剩的都是姓氏
     - **词表边界的实测修正（2026-09-19，梁羽生《冰魄寒光剑》）**：保护词表放错方向会**反向制造错字**，比漏转更糟。本次第一版把 `著眼／著手／著力／著落／著文／著地` 也放进了白名单（理由是"这看着像 zhù 义的词"），结果它们**在简体里本来就该写「着」**——`闭著眼`、`不著力`、`便著落`、`一著地`、`瞒著文` 五个错字当场被造出来，是第二轮全量打印残留「著」时才发现的。同时**反向的错误也存在**：先前条目里建议"去掉 `著称／显著`"，但本书实测 `博著称`（渊博著称）、`武著称`（文武著称）、`显著` 共 4 处**全是正确的，必须保留**，按旧建议会被漏转成「着称」。**可用的定版白名单（按 zhù 义严格筛）**：`著作／著名／显著／著者／原著／名著／著述／著书／论著／编著／著录／昭著／卓著／著称／译著／新著／巨著／遗著／拙著`，另加题材专有的正确误字（本书 `土著` 4 处实为"站着"的形近误字，**仍须留在白名单**——放进去保留原样、拿出来则会变成更错的「土着」）。**排除清单**：`着眼／着手／着力／着落／着地／着文／着墨`（简体均作「着」）。**校验口径**：替换后残留「著」应只剩白名单词，把它按"后接 2 字"聚合成 `Counter`（如 `[(土著一,3),(显著。,2),(拙著《,2),(博著称,1)]`），逐条读一遍——凡读不通的就是白名单放错了。
    **还要补一刀「己→已」**（同属 zhconv 不覆盖，而「己」在简体里是正字）：港台／网抓本大量把「已」误作「己」，本书《冰河洗剑录》样本 214 个「己」里 **33 个应作「已」**（己然／计议己定／本己／亦己／都己／己是／己知／己经／悔己无及）。**做法**：先占位保护真正的「己」字词——`自己、知己、己见、一己、异己、克己、己方、己任、身不由己、因己及人`，再把剩余「己」全换「已」，最后还原。**保护后残留必须全部打印复核**（本次 180 个残留全部落在保护词内，方可执行）。注意：个别地方「已」被误成别的字（本书有 1 处"灵验己比"应作"灵验无比"），这类要单独按上下文处理，不能指望一条替换规则通吃
    **第三刀：人名／地名的形近异写，用"姓氏 + 下一字"bigram 聚合一次捞出（本次最有效的新方法）**。逐个猜异写很低效，正确做法是：对全部主要人名取首字去重，再用 `re.compile(首字 + r'[\u4e00-\u9fff]')` 统计该姓氏后接的**所有二字组合及频次**，一眼就能看出哪一撮是异写。实例：《冰河洗剑录》一次抓出 **华无风 36（正作华天风 263）、江海夭 8（江海天 779）、和砷 24（和珅）、姬晓凤 3（姬晓风 374）、冀仲牟 1 / 翼忡牟 1（翼仲牟 48）、厉复牛 1（厉复生 49）**，另有 华大风／华夭风／半天风 各 3。**判据：异写频次通常只有正写的百分之几到十几，且该二字组合在本题材里讲不通**。
      - **子坑：bigram 会有大量假象，绝不可据 bigram 直接改字**。同一份样本里 `华道 45`、`华听 14`、`华山 14`、`华的 36` 看着都像"华天风"的异写，实际全是**「谷之华」+ 道/听/山/的**被切出来的尾字组合；`林寺 44` 是「少林寺」的假象；`云亮 69` 是「崔云亮」的假象。**必须对每个可疑组合打 20 字上下文再判**，否则会把正确的人名改坏。
      - **地名同理，且同一地名常有两种写法并存，按占比定正字**：本书 `氓山 138 : 邙山 12`，而「邙山派」是梁羽生的既定门派名（「氓山」不是山），故判「氓山」为误、全部回改为「邙山」。注意这一步要**先确认题材里的正字**，拿不准就保留原样并在「样本说明」里记一条，**不要硬改**（本书的「组来山」30 处疑为「徂徕山」，因无法确证而原样保留）。
      - **配套的一步：引文回验必须逐行做**。写完 `style_examples.md` 后，把引文里每一行非标题行拿去 `if 行 not in 样本: 报错`，全书比对。本次靠这一条又抓出 3 处不一致（样本作「丁方不到一尺／用时锤撞中／当作：“魔头”」），并据此回头订正了样本的版本错字——**这个"引文→样本"反向校验是唯一能兜住这类残余错字的手段，务必每本都跑**。
      - **引文回验还要覆盖 SKILL.md 里的引文，且"截断引用"是最常见的未命中原因**。《冰魄寒光剑》首轮回验 `style_examples.md` 25 命中 / 3 未命中（3 处全是我自己写的说明行，被 `> ` 前缀误捕，无害），但 **`SKILL.md` 里 12 命中 / 3 未命中，其中 2 处是我把段落截断后改了标点**——原文是 `…废墟和高耸的士塔……显然这是一座古城的遗址，奇怪的是…`，我引成 `…士塔。`（把省略号换成句号）；另一处原文接 `，据传古印度有一位圣人叫玛清勒…`，我引成 `……` 收尾。**两者都读起来毫无破绽，只有反向 `in 样本` 会露馅**。做法：SKILL.md 里的引文**要么引完整的句子直到原书标点，要么保留原书的 `……` 原样**，不要自己改写收尾标点。回验脚本要同时扫两个文件（`> ` 开头的行），未命中的逐条打印，再判断是"引文错"还是"说明行被误捕"。

  - **【必踩的坑】UTF-8 BOM 会让"文件头/首行"逻辑静默失效**：部分 txt（尤其站方重新打包过的）带 UTF-8 BOM（`EF BB BF`），解码后首字符是 `\ufeff`。两个后果：① 若脚本按"第 1 行是不是书名/水印"来判断文件头块，`\ufeff《冰魄寒光剑》` 与 `《冰魄寒光剑》` 不相等，判断落空；② 更常见的是"以行首匹配"的清洗正则（`^TXT原文地址：`、`^第[一二三四五六七八九十]+章`）在该行恰好是**第一行**时失配。实例：《冰魄寒光剑》源本 `raw[:3] == b'\xef\xbb\xbf'` 为真，同时 **CRLF 行尾**（`\r\n` 838 处）——这一批「武侠书库」本里前面几本都是无 BOM + LF，属于同源不同批次。**处理**：读入后立刻 `body = raw.lstrip('\ufeff')`，并在清洗报告里打出 `BOM True/False` 与 `CRLF N` 两行备查。**校验方法**：`open(样本).read()[0] == '\ufeff'` 必须为 False，`sample.count('\r')` 应为 0（输出统一成 LF）。
    - **顺带记一条"同源 txt 不等于同规格"**：同一站点、同一批下载的 txt，BOM／行尾／水印形态／碎片标记都可能不同。**每本都要重新实测一次**，不要拿上一本的规格直接跑。

  - **【必踩的坑】外来词条碎片的"右端标记"因书而异，不能照抄上一本**：已记录的标记有「连续两个及以上半角空格」（《时空浪族》《龙虎斗京华》《侠骨丹心》《冰河洗剑录》），但**同一批「武侠书库」本里还有 `双空格 + 全角逗号` 这一变体**。实例：《冰魄寒光剑》全书 **66 处，双空格后紧接的字符 100% 是「，」**（`re.findall(r' {2,}', t)` 与 `re.findall(r' {2,}，', t)` 均为 66，零偏差）——因为原句被切开后逗号被挤到碎片右侧，删掉碎片、留下那个逗号，前后文自动拼回。**做法**：拿到新书先跑 `collections.Counter(m.group(1) for m in re.finditer(r' {2,}(.)', t))`，看双空格后继字符的分布——**分布单一（全为同一字符）才可直接按该字符定位**；若分散就要按"连续半角空格"定位右端、再逐处读语义定左端。
    - **切点仍须逐处人工定，但可写成锚点清单批处理**：66 处的做法是先导出"双空格前 60 字 + `␣␣` + 后 50 字"清单，通读一遍逐条写下"碎片起点前的原文锚点"，交脚本按 `body.rfind(锚点, 0, 双空格位置)` 定位、整段删除。**脚本必须加两道断言**：① `rfind` 返回 -1（锚点不存在）时报错；② 锚点末端到双空格的间距 > 200 字时报错（说明锚点选错位置或匹配到了远处的同名文字）。本书 66 处一次通过、残留双空格归零。
    - **为什么不能"从右往左按固定字数回退"**：碎片长度毫无规律（本书 2–40 字，最短的一处只有 `性”。` 三个字符、最长的一处 40 字含人名与书名号），固定回退必然切错。

  - **【必踩的坑】回目会"掉进正文里"——章名残片混入正文首段**：老电子书排版常把章名放在页边／页眉，转码时整块并入正文段落中部，形成"回目残片 + 正文"连写。实例：《冰魄寒光剑》第 11 回源本作 `第十一章` 独占一行（回目丢失），紧接着的正文首段却是 `　　十一华堂武士拼生死桂华生仍住在巴勒家中，第二天便参加初试…`——`十一华堂武士拼生死` 正是第 11 回的回目（联网核对公开书目：**第十一回 华堂武士拼生死**），被并进了正文首段。**危害**：①正文首段凭空多出 9 个字，污染"开篇 120 字"与段长统计；②若不做剥离，摘引文时会把 `十一华堂武士拼生死` 当成正文抄进去；③它**不是站点水印**（不含域名/站点名），所有水印关键词一路都不命中。**识别办法**：逐章打印首段前 60 字肉眼扫一遍（本书 12 章全部打印后一眼看出第 11 章异常）；程序化辅助可搜 `^[　 ]{2}[一二三四五六七八九十]+[^，。！？：；、]{6,8}(?=[\u4e00-\u9fa5]{2,})`。**处理**：残片剥离（本书 1 处），**回目行本身保持缺失**，并在清洗报告与 `style_examples.md` 里点明"第 11 回回目在源本中缺失"。**不要凭联网结果把回目补回标题行**——那等于往样本里注入外部数据，会污染"回目形制"统计。

  - **【经验】章末套语"确实没有"和"被水印吃掉"要分开判，判错一头整个维度都错**：已有条目讲的是"水印侵蚀导致套语缺失，别写成作者风格"。但**反过来也成立**：有些书本来就没有套语，别硬按老武侠习惯补。实例：《冰魄寒光剑》（1961）实测 `欲知后事` 0 / `下回分解` 0 / `正是：` 0 / `且听下回` 0，`按下不表` 2（章内插话，非章末）、`这是后话` 2。**判定方法**：看每章末段是否为**完整的叙事句**——本书 11/12 章的末段是完整悬念句（`桂华生怎样也料想不到，这一去也，他几乎不能回来。`／`那么，是谁，是谁暗助他一臂之力？`／`心中上下的跳。`），第 12 章以作者自注收尾（`读者欲知详情请续看拙著《冰川天女传》。这里不再写了。`）。**末段完整、语义自足 → 作者本无套语；末段被切断或整段可疑 → 水印侵蚀**。本书站点水印全是"独立成行"型（`（武俠書庫 wuxiashuku.com 免費武俠小說下載）` 每回末一行），**没有覆盖末段正文**，所以是前者。
    - **同作者同期不同形制，横向对照表要按"本"建，不能按"作者"建**：同为 1961 年前后——**冰魄寒光剑**（段长中位 117、无套语）、**云海玉弓缘**（108、`正是：`对句 + 套语并存）、**冰河洗剑录**（85、`正是：`三件套）。三本三种形制，说明这一时期正是梁羽生章末定式最不稳定的阶段。**仿写时只取指定那一本的实测值**，绝不可拿同作者另一本的章末形制来补。

  - **【经验】梁羽生的"章"字本：用 `第X章` 而非 `第X回`，回目是七言单句不作对仗**：`extract_chapters.py` 的 `CHAPTER_PAT` 本就覆盖 `第[CN]+[章节回节]`，能直接命中，**不需要额外预处理**；但写 SKILL.md 时必须把形制如实写明——本书 12 章、`第X章 + 七言单句回目`（`横跨昆仑来绝域`／`藏身冰谷遇奇人`／…／`洞房红烛结鸳鸯`，全 7 字、**无上下联对仗**），与《云海玉弓缘》的 `7+7 对仗回目` 是两种东西。**回前诗只在第 1 回有**（四句七言、以全角空格分两行排：`针迷舵失怕昆仑　穴处巢居何足论` ⏎ `手把黑纹藤竹枝　灵山顶上叩天门`），其余 11 回不设——这条也要写进 SKILL.md 的"开篇规范"，**明说"不要每回都补回前诗"**，否则仿写时会好心地每章加一首。**联网核对回目是划算的**：用公开书目核一遍 12 个回目，既确认了第 11 回缺失的是「华堂武士拼生死」，又确认了全书章数（12 章）与字数（公开书目作 11.20 万字，样本 11.19 万字 → **样本即全本，无删节**），一句话同时解决两个结论的可靠性问题。

  - **【经验】同一批源、同一类外来碎片，量级可以差一个数量级——别按上一本预估**：已记录的哲学／思想史碎片量为《时空浪族》6 处、《侠骨丹心》38 处（约 1.9 处/回）、《冰魄寒光剑》66 处，而**《江湖三女侠》高达 197 处（约 9.9 处/回）**。方法不变（双空格定位右端、逐处读语义定左端、写成锚点清单交脚本批量切），但**预算不能按上一本估**：跑 `len(re.findall(r'  +', t))` 是多少就是多少，然后**必须逐处导出"锚点 + 前后 50 字"清单人工通读**，197 处绝不能手改。附带规律：本书 197 处里 **180 处的碎片所在行间距恰为 3 行**，说明是同一批拼接批处理的产物，"行距 3"可作同源的二次验证。

  - **【必踩的坑】段长中位会被"源本排版粒度"污染，不是作者笔法硬指标——分析段长时必须同时打印源文件的行长中位**：实例：《江湖三女侠》样本段长中位 **148 汉字**，是同作者七本样本里的最高值（还剑奇情录 30 / 弹指惊雷 43 / 侠骨丹心 67 / 风雷震九州 69 / 冰河洗剑录 73 / 龙虎斗京华 91），单看会得出"梁羽生 1957 年突然改成长段"的假结论。但**源文件原始行长中位：本书 179 vs《风雷震九州》83**——差在版式粒度（源本一段就是一行，越后期的本子分段越碎），不在笔法。**做法**：分析段长时并行打印 `statistics.median([len(l) for l in raw.split('\n') if l.strip()])`，若该值远大于同作者其他本，就在 SKILL.md 的段长条目里加一句"中位受源本排版粒度影响，仿写按 X–Y 汉字控制"，**不要让使用者照抄这个中位数**。**交叉验证**：超长段若"段内引号对 ≤21 且相邻段无粘连"，可进一步确认是源本合并段落所致，而非作者写长段。

  - **【必踩的坑】回末公式除"请听／请看"外还有第三个变量——"第三行是不是通用句"，且末回常不设公式**：《江湖三女侠》全本 47 处回末公式里，**40 处是通用句"欲知后事如何"，7 处（约 15%）改成"欲知 + 本回具体悬念"**（`欲知来者是谁？请听下回分解。`／`欲知冯琳能否逃脱虎口，请看下回分解。`／`欲知唐晓澜性命如何？请看下回分解。`／`欲知唐金峰性命如何？请听下回分解。`），且这 7 处明显比通用句抓人。另外**全书 48 回、公式只有 47 处，末回以 `——调寄踏莎行` 加 `（全书完）` 收尾、不用公式**。**做法**：把全部回末行 `Counter()` 一遍逐条读，同时统计"变体率"与"缺公式的回"，这两条都是仿写时能拉开档次的细节。**统计套语还要防同音错字少计**：本书 2 处源本误作「**清**听下回分解」，不 grep 变体就会把 15 处报成 13 处。

  - **【经验】单引号 `‘’` 可能是"人物回忆中的旧话"专用层——先统计再决定，别当成全角／半角混排错误**：《江湖三女侠》样本有 **55 组单引号**，全部出现在转述／回忆语境（`他听了唐晓澜的话，惨笑道：‘孩子，难为你还记得我，我来迟了！’`），与当前场景的双引号严格分层，是作者有意为之的标点体系。**做法**：先 `count('‘')`，若非 0，抽 15–20 处看上下文——若**全部落在回忆／转述语境**，就要在 SKILL.md 里立成规范（"当前对白用双引号、回忆旧话用单引号，两者不可混"），并**把单引号内容一并纳入引文回验**；若散落各处无规律，才按错排处理。

  - **【必踩的坑】高频人名被"批量写错"时，引文回验永远抓不到——必须拿真实人名／其他版本对照**：《江湖三女侠》源本把岳飞之后 **岳钟琪** 写成「岳钟淇」**24 处**、**甘凤池** 写成「甘风池」**18 处**，另有 唐晓澜→唐浇澜 2、冯瑛→冯玻 3、王陵→王凌 2／玉陵 1、邝练霞→邝涟 1。**关键在于这是"一致的错"**——样本里从头到尾都这么写，所以"引文 `in` 样本"的断言条条命中，**引文回验抓不到任何一个**。只有把高频人名逐个拿真名（历史人物务必核史实写法）或公开书目对照才能发现。**做法**：①清洗后对每个高频人名取首字，用 `首字 + [\u4e00-\u9fff]` 聚合所有二字组合（同"姓氏 bigram"法），异写频次通常是正写的百分之几；②**同一人物可能有多种错写并存**（王陵 → 王凌／玉陵），一次扫全、一并登记；③错字写进 SKILL.md 的「样本录入错字清单」，**仿写一律写正字**。

  - **【经验】作者自注笔法与该自注里的录入错字要分开处理**：《江湖三女侠》的说书人式夹注有四种形态——人名代称 `（按即后来的雍正皇帝）`、`（即陈子龙）`、`（没用的废物）`、`（不是正式收徒）`，跨书互文 `（按：详见拙著《七剑下天山》）`，实名自注 `（羽生按：近人龙榆生编《近三百年名家词选》，即以陈子龙词冠其首）`。样本 45 处 `（）` **全是作者夹注、没有一处是剧情内容**（可作括号配平的旁证）。**但**其中一条跨书自注本身带录入错字：`（事迹详见拙著《七剑下大山》）`（应作《七剑下天山》）。**处理原则**：整句夹注是**必须模仿的笔法**，保留；夹注里的错字照常登记进错字清单。**别把"作者笔法"当污染删掉，也别把"错字"当笔法保留。**

  - **【经验】回内转场词与回末套语一样，本本实测、不能照抄**：《江湖三女侠》转场用 `这晚`（6）／`当晚`（7）／`第二天`（5）／`再说`（31）／`原来`（165），**"次日"0 次、"翌日"0 次**——若照上一本模板写"用`次日一早`过渡"就是凭空发明。做法：上一本模板里的**每一个"示例词"进 SKILL.md 前都要回新样本 `count()` 一遍，非 0 才留**。这与"回末套语一个字之差就是分本标记"属同一类错误，只是发生在回内衔接处，更容易漏。

  - **【必踩的坑】保护词表用"包裹占位"写法会整体失效——被包裹的关键字还在字符串里，全局替换照样吃掉**。正确思路是"先把白名单词整词换掉，替换完再还原"，但实现若写成 `S.replace(w, '\x00'+w+'\x00')`（包裹式），词里的目标字**仍在串中**，后面的全局 `著→着`/`己→已` 会把白名单词一起转掉，还原循环又按原词找占位符、必然失配。实例：梁羽生《瀚海雄风》`著名`×7 被转成「着名」、`自己` 成批变「自已」，直到复检 `S.count('着名')` 才暴露。**正确写法**：白名单词换成**不含关键字的无害占位符**（如 `S.replace(w, '\x00Z%d\x00' % k)` 记下索引），全局替换完成后再按索引逐个还原。**校验口径**：替换后 `count('错写')`（如 `着名/自已`）必须为 0，同时打印白名单命中数确认 >0（命中 0 组而错写 0 组 = 白名单词本身在样本中不存在，属正常，但要能区分这两种情况）。
  - **【必踩的坑】回末定式区夹着"孤立单横线 `-`"残留行，现有分隔符正则抓不到**：《瀚海雄风》全书 2 处，形如 `……正是：`⏎`-`⏎`言者无心听有意，……`——单个半角 `-` 不匹配 `[—\-─]{2,}`（要求 ≥3 个符号），会作为独立段落混进样本，并把"章末 120 字"统计污染出一条 `-` 假钩子（analyze_style.py 输出可见 `正是： / - / 对句` 三段结构）。**处理**：清洗后扫 `l.strip() == '-'` 的孤行，全书应只有个位数且都紧邻回末定式，确认为排版残留后整行删除。**校验**：删除后 grep `^-$/` 应为 0。
  - **【经验】同一作者不同本的"单引号"功能可以完全不同，先抽 15 处再定性**：已实测两种体系——《江湖三女侠》单引号 `‘’` 专用于**人物回忆里的旧话**（当前对白双引号、回忆旧话单引号，两层按时间分层）；《瀚海雄风》单引号却是**双引号台词/夹注内层引用的专名、术语、成句**（‘瀚海’、‘金弓十八打’、‘神翼营’，引号嵌套的第二层）。判定方法：抽 15–20 处看上下文——若全部在 `“……‘X’……”` 结构内即内层引用；若独立出现在转述/回忆语境即回忆层。写错方向，仿写出来的标点体系整个是反的。
  - **【经验】`正是：`"独占一行"还是"挂正文段尾"是梁羽生分期硬指标，横向对照表要加"独/挂"两列**：1957《江湖三女侠》`正是：` 独占一段（20/20）；1965 以后（风雷震九州/侠骨丹心/瀚海雄风）一律挂正文段尾（`……那又另当别论！”正是：`，对句与套语另起段）。统计口径：`re.findall(r'^正是：\s*$', s, re.M)` 计"独"，`re.findall(r'正是：$', s, re.M)` 计"挂"。注意挂尾型要确认对句确实另起段（第 3 回变体：对句前不带"正是："，直接由正文转对句）。
  - **【必踩的坑】高频人名定罪前先联网核名——凭语感"纠正"会把正字改坏**：《瀚海雄风》`杨滔` 98 处、`杜雄` 103 处，看着都像形近错字，联网核对人物表后**全是正字**（杨滔是杨婉之兄、杜雄自报"木土杜，单名一个雄字"）；而 `盂少刚` 8 处才是真错（盂→孟）。做法：高频人名（TOP60 词表里的三字人名）逐个搜索"作者+书名+人名"，核过再进错字清单；书内自证（人物自报姓名、父子关系互证）与百科人物表都可以作依据。
  - **【必踩的坑】引文回验的"未命中"要按三类分流，不能一律当错改**：①真错（想当然引文、引号混用）——必须改；②**零出现引证**——SKILL.md 禁忌表里引用的 `甚么`、`次日`、`知晓` 等词，按定义在样本中为 0，回验永远不命中，属正常；③**全本引文**——末回收尾、回末套语变体等取自样本区之外的引用，标注"全本"后可豁免。回验脚本应支持"跳过含数字统计行/模板行"，最终报告要写明"未命中 N 条中 X 条为零出现引证、Y 条为全本引文、Z 条真错已修"，别让噪音淹没真错。
  - **【经验】"段末以逗号收"的段落是歌谣跨段行，不是排版截断**：《瀚海雄风》27 段以 `，` 结尾，全部是嵌入的蒙古民歌（`"大风卷起了黄沙，`／`哥呀，你就是天边的那只兀鹰，`）——每行独立成段、以 `"` 开头跨段不闭合，整首唱完才收 `"`。判定方法：这类段字数极短（≤15 字）、连续成片、内容为韵文。这是原书特征，写进 SKILL.md"允许清单"，**不要按"硬断行缺陷"修**；同时它天然解释了引号"开多段 > 收多段"的不对称（歌谣每段都开一次引）。
  - **【必踩的坑】"回末公式整个砍掉"也是一种分期状态，别默认每本都有某种回末定式**：《风云雷电》（1970）`欲知` 0、`下回分解` 0、`正是：` 样本 0——梁羽生系列九本里唯一把回末公式整个砍掉的（比《弹指惊雷》砍套语早五年）。统计出"请听:请看 = 0:0"时**先排除水印侵蚀**再下结论：判定方法同《冰魄寒光剑》条——抽 10 回回末末段通读，若全部是完整叙事句/对白且悬念自足，即为作者本意；此时 SKILL.md 要把"无套语"立成硬规范并**明令禁止替本书补公式**（使用者会好心补回"正是：+请听下回分解"）。回末套语被砍后，说书人议论功能会转移到回内（本书 `要知` 35 处、`可知` 16 处做补叙起手），这也是可萃取的真特征。
  - **【必踩的坑】HTML 实体残留 + OCR 错字 + 保护词表，会连环引爆**：《风云雷电》书名分隔点被转成 `&amp;；`（《狂侠&；天骄&；魔女》），同一条夹注里「拙」被 OCR 错录成「**抽**」——`抽著` 不在白名单里，著→着批量转换后变成"抽着"，三连坑一次全中。做法：①验证阶段的拉丁串扫描要保留 `&` 类符号（`re.findall(r'[A-Za-z\u00C0-\u024F\u1E00-\u1EFF&]{1,8}')`）；②发现 `&amp;` 按 HTML 实体还原（分隔点场景还原为 `·`）；③错字修正必须在**著→着批量转换之前**完成（先 `抽著→拙著` 再进保护流程），否则保护词永远罩不住错录字形。
  - **【必踩的坑】"们→门""住→注" 是比"士→土"更隐蔽的批量讹字组，用负向字符类扫**：《风云雷电》`他门`→他们 15 处、`禁不注／对不注／抓注／团团围注／稳注了／留他久注／既然注在` 住→注 系 9 处。扫描法：对 `X门`／`X注` 做 Counter 聚合（`re.finditer(r'(..)注(?![意目射定的])', s)`），正常组合（中间/注满/赌注/注视）过滤后剩下的逐条看上下文；`X门` 直接聚合即可（中文里"X门"合法组合多但上下文一读便知）。改完对该字重跑 Counter 复核。
  - **【必踩的坑】引号字符本身也可能是错字**：《风云雷电》`怔了一‘旺`／`怔了一‘证`——「怔」被错录成单引号 `‘`。状态机统计单引号嵌套之外，还要 grep 引号邻字组合（`怔了一‘`、`了‘[一二三四五六七八九十]`），命中即录入缺陷。
  - **【经验】卷首词/长诗被按固定行宽硬拆行时，提取时按"到词牌注前合并成一段"处理**：《风云雷电》源行长中位 49（全书行即段），唯独第 1 回卷首《念奴娇》被拆成 6 行（`……借得山`⏎`东烟寨，……`，断在词中间）。若不合并，词行会以"段末无标点"形态污染开篇 120 字统计与段长分布。判定：回目行之后、`——词牌` 行之前的连续短行，全部 join 成一段；`——词牌` 行保留独立。合并后 `grep` 校验段末无标点的段应只剩个位数真截断。
  - **【经验】噪音单字符与转场词三件套要逐本验**：《风云雷电》`好j几招`（j 为噪音字符）；转场词 `且说 13／再说 20／却说 8` 三件套全开（与《瀚海雄风》却说 0 相反）、`次日` 0 次——每个词进 SKILL.md 前 `count()` 一遍，0 就别写。
  - **【必踩的坑】词典碎片可能不止一种注入形态，右端标记会"换代"**：已实测三代——《冰魄寒光剑》右端标记 `双空格+全角逗号`（66/66 零偏差）；《联剑风云录》同一来源却有**两代并存**：带 `  ，` 标记的 355 处 + **无标记变体约 120 处**（碎片尾自带标点或直接接正文，如 `咱们快马奔驰赫斯（moseshess，1812—1875）德国小资产阶级政论，怎耐烦`）。无标记碎片的注入模型是**碎片替换了原文的逗号**：原文 `A，B` → `A碎片(尾标点)B`，修复 = 删碎片 + 补 `，`。**做法**：清完带标记批次后，用特征词（`主义|哲学家|马克思|恩格斯|参见|编入|出版|书局` + **`着作|着名|着书`**）反复扫描，直到清零；锚点+碎片全文唯一性断言后删除。**关键教训：诊断输出被 `head` 截断会漏判规模**——《联剑》第一轮特征词扫描输出被截断，以为清完了，实际还剩 4 批共 120 处，多跑 4 轮；扫描必须全量输出或按批次落盘再读。
  - **【必踩的坑】著→着 转换会把碎片里的「著作/著名/着名」也转掉，转换后碎片反而更好认**：《联剑风云录》清洗后期靠 `着作|着名|着书` 反向扫描抓到 40+ 处残余碎片（碎片里的「著作」全变成了「着作」，成了独一无二的特征词）。推论：**碎片清除放在著→着之后做，识别灵敏度更高**——但要记得最后把正文的 `着名→著名` 回正（本书 7 处，源本即混用）。同时这解释了为什么"特征词扫描到清零"必须含着字组。
  - **【必踩的坑】人名系统性形近错字与句子内偶发形近字要分开处理**：《联剑风云录》`乔北漠`×641（应为乔北溟）、`沐磷`×401（应为沐璘）、`霉天都`×4——**同一错误重复成百上千次 = 转码系统性损坏，联网核实正字后批量修复**（人名高频词会污染词频统计与 TOP60 表）；而句子内偶发形近字（豪恬/虎视眈耽/贡韧）不修只标注。判据：错误 ≥10 处且指向同一人名 → 修复；个位数散布 → 标注。修复前必须联网核对原书人名（本条与《瀚海雄风》"核名后再定罪"条配套：那边防"把正字改坏"，这边定"该修的必须修"）。
  - **【经验】引号开闭缺失成规模时（>1% 段落），按版本损伤标注而非逐处修**：《联剑风云录》约 2% 段落引号不闭合（104 段缺 118 个），多为一轮对话缺一个 `”`。逐处修复性价比低且易引新错——做三件事：①状态机修掉"开引号误植成右引号"的**孤儿右引号**（逐处人工判，本书 9 处）；②段末缺口按源本损伤标注进 SKILL.md 禁忌节；③统计口径注明"引号缺口约 2%，对话占比/段末引号占比误差 ≤1%"。这比硬修 100+ 处安全得多。
  - **【必踩的坑】回末公式会在同一本书内部"断代"——全书统计会算成"混用"，必须逐回扫回末结构**：《慧剑心魔》前 19 回是 `正是：`独占行＋对句独段（**无套语**），第 20 回起套语回归且与对句分家（对句挂正文段尾＋套语独段）。若只做全书级统计，两种形态混在一起既不能说"砍掉"也不能说"保留"。**做法**：对每回末 3 段做形态分类（独占行正是 / 挂段尾正是 / 套语有无 / 对句 7+7），打印逐回序列找断代点；断代点前后分开写进 SKILL.md。同款：回目缺失（第 30 回回目行整个没了，`第\d+回` 锚点数回数会差 1，必须 diff 回号序列找洞）。
  - **【必踩的坑】"情绪外化示例"引文会从上一本漂过来——跨书污染只有回验能抓，且 miss 后先查"书错了"再查"引号错了"**：《慧剑心魔》SKILL.md 里写了 `把头一扭`、`格格笑道："现在又不是小孩子！"`——《江湖三女侠》的真句，混进了本书的情绪外化节。这类引文是"上本书写顺手了顺手抄的"，肉眼自查 100% 漏。**规则**：SKILL.md 里**每一个**反引号引文（包括示例性短语）都要过回验；发现 miss 时排查顺序：①是否模板占位符 → ②弯直引号差异 → ③**是否上一本的句子**（拿 miss 文本去前几本的样本 grep）。例文也一样：说话人张冠李戴（褚遂笑道→实为褚葆龄笑道）只有逐条回验能抓。
  - **【经验】录入粘连区的判定与处理**：《慧剑心魔》第 20–23 回段数骤降到 33–54（其余回 111–188），段均 188–213 字 vs 前后 63–77。判定三件套：段均暴涨＋引号对数量正常＋相邻粘连（`”\s*“`）≈0 → 是**多段被并成一行**（录入损伤），不是作者写长段。行内无全角缩进残留时无法按缩进拆段，按源本保留、SKILL.md 标注"勿模仿该区段长"。附带：该源本还有段末 PUA 幽灵字符（U+E004×181，全部段末、行中 0）——直接删；`.{20}\ue004.{20}` 这类宽窗正则会因段尾太短不匹配，用 `re.S` 或短窗。
  - **【经验】复姓削部首是人名错字的固定变体**：《慧剑心魔》`字文虹霓`×56（宇→字）；与《风雷震九州》`沐磷`系同属"偏旁丢失"。扫描法：对百家姓复姓清单（宇文/慕容/司徒/司马/长孙/呼延/独孤/淳于/皇甫/尉迟…）逐个查"削部首形态"（字文/幕容/可徒…），命中率远高于盲扫 bigram。

6. 保存为生成的Skill目录下的`SKILL.md`
7. 加载 `assets/readme_template.md` 模板，将`{SKILL_NAME}`、`{NOVEL_TITLE}`替换为实际值，保存为输出目录（`output/`）下、与zip包同级的 **`readme-[skill-name].md`**，**不打进zip**
   - **文件名必须带 skill 名后缀**。`output/readme.md` 是共享文件名，多次构建会互相覆盖（A 技能的说明会被 B 技能顶掉），务必用 `readme-[skill-name].md`

```

├── SKILL.md          # 文风锁定Skill主文件（含完整十维分析）
└── references/
    └── style_examples.md  # 从样本中摘录的代表性段落片段（可选）
```

**输出目录结构（zip与readme同级）：**
```
output/
├── [skill-name].zip         # 可导入的Skill安装包（仅含Skill目录，不含readme）
└── readme-[skill-name].md   # 使用与仿写说明（500字以内，由模板生成；带名后缀防覆盖）
```

**frontmatter 硬性规则（校验器逐条拦，不合格不能交付）：**

1. **引号只能用 ASCII 的 `"` 或 `'`**。中文弯引号 `“”‘’` 一律禁止——YAML 不认，解析时会把整篇正文吞进 frontmatter。description 里要引书名就用书名号 `《》`，不要用引号。
2. **`---` 必须成对出现，且各自独占一行**。第一行 `---` 开头，frontmatter 结束后再一行 `---`。漏了闭合的那个 `---`，正文全部变成 frontmatter 的值。
3. **`description` 必须是单行**，不能换行、不能用 `|` 或 `>` 块，长度 ≤400 字（本系列技能集用 ≤80 字）。
4. **`name` 必须等于目录名**，只能由小写字母、数字、连字符组成，不能以连字符开头或结尾。
5. **只允许这些顶层键**：`name`、`description`、`agent_created`、`keywords`、`display_name`、`version`、`type`、`author`、`source`、`tags`、`read_when`、`license`。
   **触发词必须写进 description**（`触发词：A、B、C`），不能另起一个 `触发词:` 键——那是模型自作主张加键的典型症状。
6. 每个键只能出现一次。


## 已知坑与避坑清单（实操固化）

文风构建跑过多本后，以下坑反复出现，列为硬性避坑项：

1. **制表横线破折号（`──` U+2500）冒充 em-dash**：温瑞安多本 txt（尤其《说英雄谁是英雄》）破折号是早期编码转换留下的制表横线 `──`（U+2500 两个），不是标准 `——`（U+2014）。量化时若只统计 `(?<!—)——(?!—)` 会漏计，破折号密度误算极低（曾出现 0.19/千字 假象，真实约 2.6/千字）。**修正：同时统计 `(?<!─)──(?!─)`（box）与 `(?<!—)——(?!—)`（em），合计为真破折号**；段首破折号（内心补白/镜头跳接招牌）同样用 `──` 起头，须用转义字符 `'\u2500'` 识别，不能用字面量误判。**仿写输出一律写标准全角破折号 `——`（U+2014），严禁输出 box 横线 `──`**。
2. **段落切分按行而非空行**：温瑞安 txt（说英雄等）无空行分段，整章是连续换行。若用 `\n\s*\n` 切段会得到"整章一段"假象（段长数千字、段数仅章节数）。**修正：段落 = 按换行切，每行即一段（strip 后非空才计入）**。
3. **中篇样本即全本**：不足 20 章的中篇，样本即全本，不强行按"前20章"立硬规则，计数 <10 的指标不立硬规则。
4. **章节分隔符 `────` 污染破折号计数**：部分 txt 用 4 连/6 连制表横线作章间分隔符，须用负向环视 `(?<!─)──(?!─)` / `(?<!—)——(?!—)` 排除 4 连及以上，只数真破折号。
5. **末章"后记"带冒号标题吞内容**：部分书末章标题形如"后记：天下难容"（独占行→带冒号短标题），提取脚本若只匹配独占行的"后X"会漏吞末章。正则须允许"后[:：]记[:：]标题"形式，自动截断。
6. **逐字拉开间距水印**：水印有时写成"(重 要 提 示：…t x t 8 0. c o m…)"逐字插空格，须剥空格后再匹配剔除。
7. **繁体 `沈` 作 `沉` 用 zhconv 不转**：港台繁体转简时 `沈`（姓氏/人名，如沈云山、沈错骨）会被误转成 `沉`；须保护人名，把 `沈` 转 `沉` 仅用于 `沈声/沈吟/沈静/下沈` 等非人名语境；另 `著`→`着` 须保护"著名/著作/显著"等实词。
8. **同作者勿串味（温瑞安六本对照）**：同出温瑞安的六本骨架一致但分期/文体特征截然不同——
   - **早期《白衣方振眉/龙虎风云》**：中长段铺陈（中位 30 字、最长 697 字）、段首破折号仅 1 处（几乎绝迹）、box 横线破折号 0.89/千字、**全角引号""**包绰号、一个"道"字、约 9.4 次/章"忽然"。
   - **中期《神相李布衣》**：中长段铺陈（中位 30 字）、em 破折号 0.85/千字、段首破折号 11 处（克制）、**直角引号「」**（全角""为 0）、相术江湖气、现代疑问词+少量文白（如何/为何）。是温瑞安中期最硬标识：**用直角引号，区别于另五本的全角引号**。
   - **中期偏后《四大名捕》**：段首破折号 5 处、长段铺陈、高频率"忽然"（18.5/章）、全角引号""。
   - **中期《唐斩》**：拉字距嘶吼、段首清单体 24 处、全角引号""。
   - **后期《说英雄》**：极致碎句流（中位 20 字）、段首破折号蒙太奇 165 处、em 破折号 2.6/千字、全角引号""。
   - **1989 现代短篇《爱上她的和尚》**：碎中带铺陈（中位 19 字）、段首破折号 8 处、全角引号""、**极简对话标签（"说"22 > "道"15，含引号段 77% 为裸对话）**、现代都市武侠+抒情心理独白、零系统流。最隐蔽标识是**对话标签极简且"说"多于"道"、裸对话为主**——与另五本密集"道："截然不同。
   仿写某本时，禁止把另五本的特征安上去（尤其**不要给中期书套后期的段首破折号蒙太奇**；**李布衣必须用直角「」引号**；**别把方振眉/李布衣的密集"道："标签套进《爱上她的和尚》——那篇标签极简、裸对话为主**）。
9. **合集"前20章"可能只覆盖首篇（分期偏差）**：《白衣方振眉》是方振眉系列合集（龙虎风云/长安一战/落日大旗/小雪初晴），首篇《龙虎风云》自身有 22 章，故"前 20 章"恰好=首篇早期风格，不覆盖后期篇章（落日大旗段首破折号 40 处、小雪初晴碎句增多，是后期转型）。若用户要后期风格，应取对应单篇或《说英雄》包。提取时章标记常带篇名前缀（如"龙虎风云 第一章 血河图"），正则须允许前缀：`^\s*(?:\S{1,6}\s+)?第[0-9一二三四五六七八九十百千零]+[章回卷]`。
10. **EPUB 源文件解包陷阱**：温瑞安《神相李布衣》等 EPUB 是 zip+xhtml，正文在 `<p class="calibre2">` 标签之间、且**段落缩进后的正文是游离文本节点**（`<h3>标题</h3><p>空格</p>天空布满了密云…<p>空格</p>`），不在任何 `<p>` 块内。用 `html.parser` 时**必须捕获所有文本节点**（handle_data 无条件 append，块结束标签触发 flush），否则只抓到章标题、漏掉全部正文（初版即因此只提出 110 段）。清洗：去 `\u00a0`（nbsp spacer 段）、去前置 `\u3000`（全角缩进）；章节标题在 `<h3>`；引号体系常是直角「」而非全角""。EPUB 多为干净出版本，无 scraping 水印、作者按一般在全本靠后段（若落在前20章内须剔除）。
11. **短篇/非章回体 txt 的章标记与"前20章"退化**：温瑞安《爱上她的和尚》等短篇用**中文数字+顿号**（"一、二、三、"）而非"第X章"分章；整书可能仅三章、不足20章。此时"前20章"流程**退化为全本取样**（计数基于全书，非前20章抽样），须在 SKILL.md 注明。章标记识别正则须兼容：`^\s*[一二三四五六七八九十百千零]+\s*[、.．]\s*`。
12. **txt "内容简介"梗概段 + 附言行前导引号剔除**：温瑞安短篇 txt 常在标题/作者后紧跟一段"内容简介"（全书浓缩梗概，非正文，会污染段长统计为长段）——须**按位置剔除**（记录上一行是否为"内容简介"标识，是则跳过紧随段）。文末附言（"完稿于……""武侠世界刊完（六分半堂）"）常带前导引号（如 `"武侠世界"刊完`），`tail_pat` 须允许前导引号：`^(["\']?)(完稿于|武侠世界|刊完|——完|注[:：]|作者按)`，否则漏剔。
13. **OCR 错字不继承**：温瑞安部分 txt 有扫描/OCR 错字，仿写规范须标注"不继承"并给出正字，例如：《爱上她的和尚》"为虎作怅"→伥、"如火如茶"→荼、"越来加白"→越来越白、"内虞"→内院、"斩轻堂"→斩经堂、"一俩套"→一两套、"轻归圣洁"→轻移圣洁、"不值一屑"→不值一顾；若不确定正字，仿写时直接用合理现代写法，不要照搬错字。
14. **作者错配识别（文件夹名/命名 ≠ 真实作者，最隐蔽的数据源污染）**：用户给的文件可能放在错误的下载文件夹、且命名含误导词。实例：《七杀碑》被放在"温瑞安"文件夹、用户命名 `xin-wenruian-style-qishabei`，但文件头 `作者：朱贞木`——朱贞木是**民国北派五大家之一、"新派武侠之祖"**，与温瑞安毫无关系，序/自序也确认。构建前**必须先核验 `作者：` 行 + 序/自序/出版说明**，绝不盲信文件夹名或用户给的命名；若真实作者与命名不符，**按真实作者构建**并在 SKILL.md 首部明确更正，同时建议改名（如 `xin-wenruian-*` → `xin-zhuzhenmu-*`，用户确认后照做），否则会把非某作者的书污染进该作者的同作者演进轴。**朱贞木《七杀碑》跨作者对照（与温瑞安六本全面相反）**：中位段长 **355 字（极长段，最长逾 2300）** vs 温瑞安 20–30 字；破折号全书 **0.08/千字（几乎不用，前 20 章为 0）** vs 说英雄 2.6；引号**全角""**；语体**半文半白**（便 833/之 511/其 190 + 现代"什么"266 压倒"甚么"2）；对白**从不独立成段**（嵌入叙述长段）；章末**完整句收束·语义悬停**（落在担心/威胁/诡异意象/伏笔约定，不靠断句截断）。仿写朱贞木时严禁套温瑞安任何特征（尤其碎句流、段首破折号蒙太奇、直角引号）。**章末钩子提取 bug 修正**：取每章末段**结尾 40 字**做悬停/断句证据（`ch[-1][-40:]`），早期误用 `ch[-1][:40]` 取的是**段首**，会把开头误判为断句/悬停，导致假结论——务必取结尾。

15. **zhconv 无效 locale 静默不转换（最隐蔽的数据污染，可让全书统计全错）**：港台/梁羽生繁体 txt 用 `zhconv.convert(text, 'zht2zhs')` 时，**`zht2zhs` 不是合法 locale，函数直接原样返回、不做任何转换**。表现为：所有"简繁同形"的字（中/知/道/突/然/如/何/便/就/都…）照常命中，而真正的繁体字（沒有/原來/說道/只見/這麼/馬上/必須…）全被数成 0——肉眼极易误判"作者不用某词"。**正确 locale 是 `zh-cn`**（走"什么"）或 `zh-hans`（走"甚么"）；梁羽生包统一用 `zh-cn` 与既有包对齐。**转换前必自检**：`convert('甚麼','zh-cn')` 应得 `什么`，若仍得 `甚麼` 即 locale 无效。转简后须复算：什么/没有/原来/说道/只见 等应在百级或千级，绝不应为 0；若为 0 必是转换失败，重来，不要将错就错写进 SKILL。

16. **同作者跨年代风格不可套用（梁羽生 1954 vs 1972 实证）**：同一作者不同年代作品语感可能天差地别，不能把某本的特征安到同作者另一本。梁羽生实证：1954《龙虎斗京华》= 章回体说书白话（列位看官/欲知后事/下回分解/单说 全套语、章末"正是："诗谶、逗号:句号 4.6:1、中位段长 105、说道仅 116）；1972《牧野流星》= 现代章回小说（说书人套语全灭、章末完整句情境钩子、正是 122 处全为"这/那正是"强调义 0 处引诗、逗号:句号 2.64:1、中位段长 59、说道 1102 主导、怎么>如何 更口语）。仿写指定某本时只取该书自身统计，严禁把早期书的说书人套语/章末诗谶搬进成熟期书。
17. **源文件注入非小说正文碎片（最隐蔽的"假原文"污染，可污染词频/段长/对白统计）**：部分 wuxiashuku 下载版不止有水印，还会把**哲学/百科条目整段 spliced 进小说句子中间**（实例《塞外奇侠传》：全本 95 处、前 20 回 75 处，把马克思/恩格斯/黑格尔/青年黑格尔/朱熹理气论/郭象独化论/王阳明心学/施蒂纳/杜威实用主义/王国维美学/列宁/空想社会主义"新村"等塞进"杨云聪道：…"句子里，以"双空格+逗号"（`  ，`，即两个 ASCII 空格后接 U+FF0C）作拼接痕迹）。危害：污染词频（马克思/阶级等被数成有）、破坏句子完整、段长虚高。**识别与清洗**：① 先扫全书找哲学/学者专有词（马克思/黑格尔/唯物论/辩证/玄学/理也者/施蒂纳/实用主义/新村/列宁/无产/神灭…），凡命中且语境非武侠的即垃圾；② 每条垃圾用"(垃圾起点短语 → 真实续接短语)"精确正则删除（`re.escape(start)+'.*?'+re.escape(resume)`，非贪婪，删起点到第一个真实续接之间的全部）；③ `  ，` 双空格逗号是**拼接痕迹但不是垃圾边界**——72/495 真实段也含它，不能拿它当删除边界，否则会误删真小说；④ 删完做残留扫描（哲学词频须归零）迭代补齐，直到 0 残留。清洗后再转简、取回、统计。切勿把任何哲学/百科议论当作者原文特征写进 SKILL。

18. **"第N回合"假阳性章标（叙述句污染章切分，最易误判"内嵌目录"）**：章标正则 `第[一二三四五六七八九十]+回` 会把叙述句里的"第一回合/第二回合/第三回合"（谈判、比武按回合推进）误判成回目章标——实例《说英雄谁是英雄·温柔一刀》第 16–17 章间连出"第一回合的谈判/第二回合的谈判/第三回合谈判"，肉眼看像"内嵌目录/TOC 污染"，实为正文。**修正：中文数字回目正则排除后接"合"字（`第[一二三四五六七八九十]+回(?!合)`），章标判定行首锚定（独占行+全角空格标题格式）；numeric 章（第01章）与中文回目分别建索引、不混排**。**同文本两种字数统计口径勿混**：全字符数（含标点空白）与纯汉字数差约 25%（说英雄同一样本 98,276 vs 74,235）——不同会话/不同脚本交叉验证数字时先对齐口径；**绝对计数（段首破折号处数、`道：` 次数、逗号总数）不受口径影响，是首选锚点**（说英雄包双会话复核实证：165 处、603 次、逗号 5,244 vs 5,227，三锚点全部吻合，即判定为同一文本无误）。

19. **网文盗版 txt 的三栏章标 + 站点自动提要 + 敏感词规避（JJWXC 类下载站特有，污染回目与词频）**：实例《东厂观察笔记》（作者她与灯，晋江在版书）。三个坑必须一起处理：
   - **① 章标不是「第X章」**，而是站点导出的 **`序号.  标题   章节提要`** 三栏格式（如 `2.  伤鹤芙蓉（一）   这被重刑之下完美的破……`），正则必须兼容 `^\s*\d{1,4}\s*[.．、]\s*(\S.*)$`；**标题与提要之间是两个以上空格，提要是站点自动抓取的正文首句（末尾截断加省略号）**，须整体剥离，否则回目统计被污染、首句被截成假"……"。
   - **② 敏感词规避替换，三种形态并存**：拼音/英文替换（`X京`←北京、`一Si不Gua`←一丝不挂、`JJ`←晋江）、**插入式屏蔽**（`妓（和谐）女身`、`禁（和谐）忌`、`政（Hexie）府`）。这类词**必须从词频统计中剔除并单列"仿写不继承"**，不能当作者用词特征。
   - **③ 悬空脚注注码**：正文保留全角 `（1）（2）（3）` 注码，但**注释正文未随文下载**（全书 `注：`／`注释` 计数为 0）。统计全角括号前须先区分"脚注注码"与"正文括注"，否则括注密度虚高；仿写时要么不写注码，要么把解释写进正文。
   - **附带结论**：同书 `  ，` 注入碎片 0、无水印（与 wuxiashuku 版不同源），但**盗版站之间污染形态完全不同，换一个站就要重新扫一遍**，不能靠"上次这本没有"就跳过勘察。

20. **现代在版网络小说（非公版）的版权红线**：公版武侠（金庸／梁羽生／温瑞安等）与本类书处理方式必须区分。构建网文在版书（晋江／起点连载中的作品）时，**必须在 SKILL.md 与 readme 里明写三层声明**：① 本技能只提炼写作技法（视角／句式／节奏／标签习惯）；② 严禁复制、改写、传播原作任何具体情节、台词、段落，输出必须原创；③ 版权归原作者与首发平台，二次创作须尊重原作者。`style_examples.md` 的引文须**控制在短句量级**（以句为单位，不做整段长引），并逐条标注出处性质。这既是合规底线，也与用户"尊重原作者、反拿来主义"的立场一致。

21. **注入碎片的精确删除法：删到 `  ，` 之前，**保留那个逗号**（第17条的最佳实践升级）**：第17条最早的做法是"删 `[垃圾起点 → '  ，']`"，把双空格逗号一起删掉——**会丢标点**。实测（《还剑奇情录》106 处）发现：`  ，` 的本质是**原文标点被推到了碎片之后**，所以正确做法是 `re.sub(re.escape(start) + r'[\s\S]*?(?=  ，)', '', text)`，**只删碎片、把 `  ，` 归一为 `，`**。验证：`將他的兒子搶救出來【碎片】  ，石天鐸的軍中舊侶` → `……搶救出來，石天鐸的軍中舊侶` ✓ 通顺；若连标点一起删会是"搶救出來石天鐸"，不成句。**例外**：碎片后紧跟的是动词续接时（`大樹【碎片】  ，竟被長鞭掃斷`），保留逗号也通顺，无需特判——统一保留即可。
22. **碎片会"藏在 `  ，` 更前方"，宽上下文不能只看尾部**：导出的宽上下文（前 260 字 + `<<<SPLICE>>>` + 后 45 字）里，垃圾**未必紧贴 `  ，`**。实例《还剑奇情录》#105：`……还要重百倍千倍！。  ，陈雪梅怔了一怔……`，肉眼只看到"！。"以为是纯标点污染，**实际碎片在更早处**——`陈雪梅叫道："什么【蒙塔古（williampepperellmontague，1873—1953）美】  ，玄机他在这儿！"`。**教训：判定"该处是否含碎片"必须通读整个 pre 窗口（至少 175 字），不能只看 `  ，` 前那几十字**；且**垃圾里可能夹带站点水印**（本书 #21、#93 的碎片内就嵌着 `［ｗｕｘｉａｓｈｕｋｕ．ｃｏｍ］`），须先删碎片再扫水印（或两遍都跑）。
23. **锚点数量必须与碎片数交叉核对（否则静默漏删）**：写清洗脚本时手工誊抄锚点极易漏项——本次《还剑奇情录》106 处碎片（103 处需锚点、3 处纯标点污染），誊抄时漏了 1 个（金岳霖处），脚本却**不报错**（`subn` 对未列出的碎片毫无感知），只表现为"碎片总数对不上、哲学词残留 1 处"。**强制三查**：① 打印 `unique anchors` / `deleted fragments` 两个数，比对"碎片总数 − 无需锚点数"；② 逐条 `subn` 返回 0 的锚点须逐个人工复核（可能是引号字符写错，见第17条）；③ 清洗后跑**加宽版哲学词表**残留扫描，归零才收工。**只信词频扫描，不信脚本的"成功"回显。**
24. **同作者、同期、甚至前传关系，文体也可能截然不同（第16条的最强例证）**：《还剑奇情录》（1959.11–1960.05）是《萍踪侠影录》（1959.1–1960.2）的**前传、连载期重叠**，但两书文体在六项上**全面相反**：回目 四字题 vs 九言对句；回末 无套语·情境悬停 vs 三段式（正是：＋对句＋请看下回分解）；心理引语 想道 53 : 心道 16 vs 心道 113 : 心想 16；段长中位 96 vs 165（汉字）；纯景物段 16.6% vs 2.7%；落点 情与孽 vs 家国大义。**结论：同作者的分本对照必须以"每一本各自跑一遍量化"为准，绝不能拿同期/同系列的另一本做外推**；SKILL.md 里必须给这类"内部反例"单列对照表，否则仿写必然串味。
25. **异体字不在 zhconv 表内，须手动规范化；拼音混入属编码损坏**：zhconv 会处理绝大部分繁体，但**异体字（非繁简关系）会原样留下**。实例《还剑奇情录》：`擡`（抬）31 处、`沈`（沉）64 处、`著`（着）74 处。检测法极简：**对样本中每个唯一汉字逐个跑 `convert(ch,'zh-cn')`，返回 0 类变化即说明没有遗漏的繁体，但异体字仍需另行人工扫（用候选异体字对表 `擡/沈/著/妳/喫/敎/羣/牀/隂…` 统计频次）**。转换规则：`沈`→`沉` **必须先确认全书无姓氏"沈"**（本书无，故全转）；`著`→`着` **须保护"著名/著作/显著"**（先占位再还原）；`擡`→`抬` 直接全转。另有一类**编码损坏而非 OCR 讹字**：拉丁拼音混进汉字（`嘴chún`→唇 4 处、`rǔ臭未干`/`rǔ突穴`/`石钟rǔ`/`吃rǔ之力`→乳），这类**要还原**（不是"标注不继承"），因为它是字形损坏、会让仿写照搬洋泾浜。
26. **引文逐字回验必查引号字形与杂语残留；同字异义规则不跨书移植**：① 生成 SKILL.md/style_examples.md 后**必须逐段回验引文与样本逐字一致**——生成环节会把中文弯引号系统性写成 ASCII 直引号（《十二年，故人戏》8 段、《有匪》16 段两次复现），必须批量修复：双引号按"行内奇开偶闭"转 `“”`，**嵌套单引号同理要转 `'`（U+2018/2019），《有匪》实测 14 处嵌套单引号需单独修**；直引号→弯引号按"行内奇开偶闭"规则批量转换）。② 生成文本要跑**非中文字符残留扫描**（西里尔/日文假名等），本次曾在 SKILL.md 里混入俄语单词"голову"，靠 `\u0400-\u04FF` 扫描抓出。③ 异体字修正规则**严禁跨书移植**：还剑包的 `沈→沉`（姓氏不存在才可全转）在故人戏里完全不适用——女主姓沈（2,143 处），`著`（著作）、`藉`（狼藉）也是正确用字。每本书的用字规则必须从本书自己勘察得出，禁止复制上一本的替换表。
27. **用户指定技能名含下划线时，校验会拒包（hyphen-case），用 `--allow-name` 显式放行**：构建脚本强制 name 为小写字母+数字+连字符，但用户点名 `novel-style-12years_gurenxi` 这类下划线名（WorkBuddy 系统层实际支持下划线目录名，如 `tomato-novel-opening__skillhub`）。处理顺序：① **先劝用户改成连字符**（跨工具最稳，Agent Skills 规范只认 `[a-z0-9-]`）；② 用户坚持保留下划线，就给 `build_skill.py` 加 `--allow-name` 显式放行（仍然强制 name 与目录名一致）。**不要用 zipfile 手工打包绕过校验**。
28. **水印不止"站方声明行"一种字形：星花/空格花/下划线花三变体（坤宁实证）**：网文转载站会把域名按字符拆开夹在分隔符里刷存在感——`八*零*电*子`（星花夹字）、`宝 书 网`（空格花）、`八_零_电_子_书`（下划线花），三种变体在同一本书内混用，且**行内含汉字**，导致"无汉字且含拉丁才删"的首版过滤条件跑出 0 命中。**识别模式**：`(('*' in s and re.search(r'[a-z]' + BS + '*[a-z]', s)) or (len(re.findall(r'[A-Za-z]', s)) >= 6 and len(re.findall(r'[一-鿿]', s)) <= 6))`——星花夹字母 OR 汉字≤6 且拉丁≥6；坤宁实测删 4 行、三变体全灭。清洗后必须重扫半角标点残留（坤宁第 18–20 章拼接段残留 39 处半角逗号+空格，系不同来源片段转换不彻底），`', '` 一并归一为全角。
29. **Bash 内联 `python -c "..."` 会吃反斜杠，校验逻辑必须写成脚本文件执行**：在 Bash 工具的双引号内联命令里写正则（`^name:\s*(\S+)`），传输层会把 `\s`/`\S` 的反斜杠静默吃掉变成 `s`/`S`——正则照样"成功执行"但永远失配（坤宁包 frontmatter 校验两次返回 None，文本明明存在），极易误判为"文件坏了"。**对策**：① 一切校验/打包/清洗逻辑写进 `.py` 脚本文件（Write 工具写文件不经过转义层）再执行；② 临时内联验证用 `chr(92)` 构造反斜杠（`BS = chr(92); pat = '^name:' + BS + 's*(...)'`）。诊断口诀：文本肉眼可见、正则却 None，先怀疑转义层，再怀疑数据。
30. **修复类替换必须用 `\1` 反向引用保住匹配边界，且逐处打印 diff 复核（折腰实证，静默丢字）**：半角标点归一时写了 `re.sub(f'({HAN}){half}', full, s)`——第二个参数是字符串 `full`，把"汉字+半角标点"**整个匹配**替换成了单个全角标点，**前面的汉字被静默吃掉**（"攻石邑,杀无赦"→"攻石，杀无赦"，5 行各丢 1 字，汉字总数 64,516 vs 64,521 恰差 5）。正确写法 `re.sub(f'({HAN}){half}', r'\1' + full, s)`。**防线**：① 修复脚本对每处改动逐点打印前后上下文（`before[...]→l[...]` diff）；② 修复前后汉字总数比对，差额必须恰好等于预期替换处数；③ 章末钩子/章首段打印是免费的全文抽查（本次"攻石"缺字就是章末打印暴露的）——量化脚本里的章末列表不要省。
31. **转载站敏感词拼音替代与"屏蔽星花"（与第 25 条注音混入同源不同因）**：网文转载站会自我审查敏感词，把字替换成拼音或星号——折腰全书后段 `shu妇`（熟）、`yao他`（药）、`du药`（毒）、`幸逊*的`（星花屏蔽）。**与第 25 条"OCR/注音字形损坏要还原"同属字形破坏，但语义不同**：这些是站点审查产物，样本范围内没有就不管（记录在案即可），样本范围内有则按上下文还原（`shu妇`→`熟妇` 等）并严禁在 SKILL.md 里把残缺写法当作者特征。检测：`[A-Za-z]{1,3}` 夹在汉字间扫描 + 星花行逐条看上下文（区分"水印"还是"屏蔽"——屏蔽星花左右是正常汉字，水印是整行花）。
32. **零宽字符防复制水印（U+200C，攻玉 8,753 处）+ 晋江感言块的 `*` 不是场景分节符**：① 部分转载站把 **U+200C（ZWNJ）零宽字符**随机撒进正文防复制（攻玉全书 8,753 处，平均每行一个）——肉眼不可见、常规"0 拉丁/0 水印"扫描全部放行，但文本已被污染且可能干扰逐字回验。**必须专门扫描不可见字符族：U+200B/200C/200D/FEFF/00AD**（`Counter(ch for ch in text if ord(ch) in (0x200b,0x200c,0x200d,0xfeff,0xad))`），命中即全局删除并做"删前删后汉字总数一致"无损校验。② 晋江文本每章末格式是 `正文 → * → 作者有话要说：` ——这个 `*` 是**感言分隔符**，不是场景分节符，**判断标准：`*` 的下一行是否为"作者有话要说"**；删感言块时连它一起删，否则残留悬空分节符误导量化（攻玉 8 个 `*` 全是感言分隔，删后场景分节为 0）。③ 感言块内的 `[1]` 式注释标记对应正文引诗处，删标记、留诗句（引诗是正文特征）。
33. **全角标点后的半角空格残留，半角标点扫描不覆盖，须专扫（橄榄树 45 处）**：清洗脚本通常只扫"半角标点紧邻汉字"（`HAN[,;:!?]`），但转载源还有**全角标点后跟半角空格**的污染（"， 眼泪""。军绿色的"），多为 txt 转换断行/排版产物，视觉上几乎无感，却会让逐字回验 MISS。**检测**：`re.compile('([，。！？；：、…—]) +')` 全文扫描；**修复**：`pat.sub(r'\1', s)` 删空格保标点——全角标点 U+3002 不在汉字区 `\u4e00-\u9fff`，删后汉字总数应**完全不变**（差 0 断言，勿写成"差等于处数"）。橄榄树实证 32 行 45 处。
34. **敏感词句号拆字损坏（"步。枪""炸。弹"），修复前必须逐处上下文甄别（橄榄树 2 真 5 伪）**：转载站自我审查会把敏感词（枪/弹/毒/军）**用句号拆开**（"一把步。枪""放有炸。弹的车"）。**同形模式大量误报**：`X。Y` 里 Y 恰好接续正常下一句（"迷彩服。军人们维持秩序""后门涌。军队分成两拨""上下铺。军绿色的被子""飘荡。军人和医生""有救的人。死去的"——5 处全是正常句号）。**判定标准**：去掉句号后 `XY` 是一个真实词且前后文读得通（步。枪→步枪 ✓）；X。 各自成句则保留。检测入口：`[。]枪|[。]弹|[。]毒` 等敏感字前句号扫描，命中后逐处打印 ±18 字上下文人工判定，**严禁批量自动替换**。④ **连字符拆字**（`汉字-汉字`，北城有雪 19 处：裸-模/缠-绵/避-孕-套）是姊妹变体，可全局自动替换（中文正文无合法 汉字-汉字 连字符），但**连续拆字（避-孕-套、擦-枪-走-火）单次 `re.subn` 非重叠匹配会留尾巴**（"避-孕"消费后"孕-套"不再匹配）——必须 `while True: subn` 循环替换至命中 0。
35. **混合换行灾难：孤立 `\r`（旧 Mac 换行）与 `\r\n` 混用，raw.decode 与 open() 行号体系不同（北城有雪实证）**：同一文件 `raw.decode('gb18030')` 后 `split('\n')` 得 10,329 行，`open(encoding='gb18030')`（universal newlines）得 20,328 行——**孤立 `\r` 有 9,999 个**，raw 路径把它们当普通字符、open 路径转成换行。两次勘察行号对不上、切片错位都是它。**对策**：解码后立即 `t.replace('\r\n','\n').replace('\r','\n')` 统一换行，之后所有行号、切片、章标统计都在统一后的文本上做；勘察脚本第一步就打印 `\r\n` 与孤立 `\r` 计数。另：卷标型章标（`NN(卷名...)`）可能同章重复插入（每 100+ 行一次，正文被切断如"依然是那/盏朱红的屏风"）——**每章标第一次出现为真章标，重复出现直接删除行、正文自然缝合**。
36. **转载站污染分段不均，先探污染起点再选样本区（权宦心头朱砂痣实证）**：txt80 源本 84 万字全书污染惨烈——半角 `?` 丢字占位符 19,039 处、分号占位符 `zp;nj;` 3,807 处、HTML 残行 `lt;h1...gt;` 1,416 处、`『』`敏感字夹字 85 处——但**污染起点在 L8867，前 20 章样本区（L9~L3534）零污染**。**对策**：① 勘察时对每类污染输出"10% 桶分布"（`Counter(i*10//n for i in poll_lines)`），一眼看出污染起止；② 样本区若落在纯净段，只做章标规范与微瑕修复，不必全量清洗；③ `?` 占位符（汉字上下文）删后即复原原文（"感?激"→"感激"——占位符是插入而非替换），与 `zp;nj;`（真丢字，删除后句子缺字）机制不同，后者只能删除并在样本说明声明；④ 章标双行格式（复合行"第N章 第 N 章"+ 孤立行"第N章"成对出现）规范化为单一章标，成对孤立章标删除。⑤ **转载站质量分层**（月明千里/宝书网本对照）：宝书网本可以近乎零污染（零宽/占位/夹字/连字符全零，仅段首全角缩进待去）——勘察清单照跑但预期放宽，不要被 txt80 的经验吓出过度清洗；另注意宝书网本头部自带完整署名+文案+搜索关键字（作者/主角名可直接取用，省一次联网核实）。
37. **作者署名禁止猜测，必须源本核实→联网核实（权宦心头朱砂痣教训）**：txt80 源本头尾只有书名无署名，AI 凭语感猜了一个作者名差点写进交付物。**对策**：① 先全文搜"作者：/作者:"（注意区分推文里的别家作者署名，如"推文：《XX》 作者：XX"是感言推文不是本书作者）；② 源本无署名立即 WebSearch"晋江《书名》 作者"核实，以晋江官方页/百科为准；③ 正文 269+番外 10 的章数、完结时间、主角名单等元信息一并核实，写入 SKILL.md 的都是查证过的。**交付物里的人名、书名、数据，一个都不许编。**
38. **感言块位置变体 + 晋江连载痕迹章名（凶案现场直播实证）**："作者有话要说："不总在章末——**存在章标后置型**（`第7章 贫困` → 感言行 → 感言内容 → 正文开始），此时"删至下一章标"的通用规则会误删正文开头。**对策**：① 每处感言块打印前后 ±6 行逐处人工定界（样本区感言通常仅几处，别怕手工）；② 章标后置型只删感言行+感言内容行（正文第一行往往是单行人名/短句如"项清溪。"，靠语义连贯判断）；③ 晋江连载痕迹章名（"入V公告""一更""二更""三更"）是**原作特征不是污染**，照录并在样本说明声明；④ utf-8 无 BOM 本判码时注意：BOM 检测读到 `e3 80 8a`（"《"的 UTF-8 首字节）会误判，应直接按头两字节区分——`efbbbf` 才是真 BOM。
39. **书名与内容交叉核验：转载站会张冠李戴，文件名/标题页书名不可信（庶女攻略实证）**：某"八零电子书"本文件名与标题页均为《庶女攻略》，但 L3 署名"作者:雪舞1987"与常识矛盾（知名《庶女攻略》作者是吱吱），且感言自曝"《步步惊心：庶女皇后》终于上架了"、正文主角（窦漪房×夏桀）与吱吱版（罗十一娘×徐令宜）完全不同——**转载站把 A 书内容标成了 B 书书名**。**对策**：① 勘察第一步做"三对交叉"：书名 ↔ 署名 ↔ 正文主角名，任两者矛盾立即 WebSearch 核实（搜署名+正文主角名，别只搜书名）；② 章标异常也是信号——正常连载本章标连续，若独立章标寥寥而"第N章"大量粘在感言行尾（"多收藏，多留第十二章恨"），说明该本来源可疑或拼接，先怀疑源本再想清洗对策；③ 核实确认内容与目标书名不符时**立即停下问用户**（弃用另找 / 按实际内容改名做 / 保留包名做内容三选），严禁闷头把错书内容做成目标书名的技能包；④ 内容确认后，SKILL.md 必须声明实际书名、真实作者、发表平台与本次源本错标情况。

40. **多卷长篇的章号卷内重置：章标计数会在卷边界归一（娇娘医经实证）**：希行《娇娘医经》671 章 7 卷，章标格式 `第N章 章名` 但**每卷从第一章重新计数**（第一卷第七章之后紧跟第二卷"第一章 路雨"，卷标行 `第一卷 初来` 在前）。后果：按"前 20 章"取样的直觉会取到第一卷前 7 章＋第二卷前 13 章（章标单元 20 个但只有 42k 字，本书单章短）；且"章号连续性校验"会误报跳章。**对策**：① 勘察时同时扫描卷标（`第N卷`）与章标，发现章号回卷立即识别为卷内重置，不是章标缺失；② 取样按**章标出现顺序的前 N 个单元**计数（跨卷），以汉字量（≈60k）而非章数（20）为可比口径，SKILL.md 里声明"前 N 个章标单元（跨卷）"；③ 卷标行保留在样本中（它是原作结构），量化统计章数时把卷标与章标分开计数；④ 章号连续性校验必须按卷内分组做，或对这种结构直接豁免。
41. **标点损伤会伪装成"作者风格"——问叹比异常必须甄别（盛华实证）**：某八零本全书 52k 汉字**问号 0、叹号 0**，大量疑问句以句号收尾（"阿夏没发热吧"。），乍看是"作者禁用问叹号"的签名级文风指纹——实为**转载站批量删除标点的损伤**。**甄别法**：① 统计语气词（吗/吧/啊/呢）后**直接接汉字**的比例（先剔除什么/这么/怎么等复合词内连用），该本"吧"26%、"啊"55%、"吗"50% 丢失——风格性省略是全有或全无，**三到五成随机丢=损伤**；② 找语义矛盾："您不是说江宁城是古都吗我长这么大"（吗后连标点都没有）绝非有意为之；③ 交叉验证：查作者其他作品正版片段是否正常使用问叹号。**处置**：问叹比等标点语气层指标从指纹体系中剔除或降级为"声明项"；SKILL.md 必须写"源本标点损伤声明"（损伤范围+不可作仿写参照）；引文照录原样并逐处声明。同类：章末半角 `:` 截断（正文被切+冒号收尾后接 4 空行+下章标）也是本源本的批量损伤（30/30 章每章末一处），复原为句号并声明截去内容不可考；修复时注意段尾可能已有句号（"郑重。:"），须先删冒号再判句末标点，否则产生"。。"双句号。

42. **敏感词屏蔽的方括号拼音变体 + 全行 tab 缩进（重生之女将星实证）**：言情888 本把敏感词整词替换为**带声调拼音+方括号**（`昨[rì]`→昨日、`[shēn yín]`→呻吟、`赤[luǒ]裸`→裸），与第 31 条拼音夹字（shu妇）同源不同形；还有**星花+夹字混合变体**：成语"翻云覆雨"变成 `翻[*]覆[雨]`（云被星花、雨被方括号夹字——同一短语两种水印机制同框）。**对策**：① 通用扫描 `\[[^\]]{1,20}\]` 列出全部方括号内容，逐处打印上下文判定还原词（还原后必须通读验证语义通顺）；② 保留原作外语/语言细节（azan、救命.jpg）与站点屏蔽的区分判据不变——屏蔽词是正常中文词（日/呻吟/裸），原作网感词不是；③ 部分转载本**全文章标与正文行均带行首 `\t` 前缀**（本书 1,562 行），统一 `lstrip('\t')` 处理，勿与全角空格缩进混淆；④ 转载本可能**只含前 N 章**（尾部版权声明自曝"只提供前面N章"）——章标总数远小于全书章数时先查尾部声明，样本说明必须写明覆盖率（"前 30 章/章均 1,800 字连载格式"），SKILL.md 声明未覆盖的后期主线，禁止冒充全书语感。

43. **章末无标头感言污染量化与章末钩（九重紫实证）**：某连载期抓取本（2012 年晋江）除常规 `ps:` 感言外，大量**无标头感言直接挂在章末正文之后**——"谢谢！""祝大家新年愉快。""﹏b汗""姊妹们、兄弟们，开新坑了！"，甚至**插在正文中间**（"语气半是感慨，半是欣慰。→多谢大家！→应该可以支撑一些日子了！"）；另有大段设定讨论/剧情解释型感言（"关于罪臣流放的问题……"140 字）。**危害**：章末钩子量化全部被污染（钩子列表变成"谢谢！"合集），问叹比/省略号统计失真（本书问叹从 1:1 被人为拉高的叹号全是"谢谢！""抱歉！"）。**对策**：① 清洗后必须打印**每章末尾 3 段逐条人工甄别**（只看尾部三段，工作量小）；② 互动词（谢谢/抱歉/祝大家/姊妹们/大家/汗/榜单/pk/订阅/支持）命中段先标疑，再区分：对白里的"谢谢母亲"是正文，独立成段的"谢谢！"是感言；③ 删除用**整句精确匹配或前缀匹配**，严禁"道歉/断网"这类宽关键词（会把"六伯父既然没有句道歉的话"这种正文删掉）；④ 像素级验证：删除后重跑量化，章末钩子列表应全部是叙事/对白文本。
44. **无方括号拼音屏蔽四层机制并存（媚公卿实证）**：言情888 本（2011 起点连载期）屏蔽不套方括号，四层机制混用——①全音节（娇xiao→娇小、xing格→性格）②数字前缀（凌1uan→凌乱、1ang费→浪费、1u出→露出）③叠音节（xiaoxiao→小小、dangdang→荡荡、yanyan→艳艳）④**拼音尾字母单字母**（灰门g门g→灰蒙蒙、卧g不起→卧床不起、g塌→床塌、g漾→荡漾、门g纱→蒙纱）。共 419 处 39 种 token。**对策**：① 逐 token 导出上下文清单人工定字，同音多字（ji→激/鸡/机、yu→玉/欲、rou→肉/揉、yin→吟/淫）必须按 bigram 消歧（呆若木ji→鸡、目眦yu裂→欲、rou了rou→揉）；② **替换顺序按长度降序**，防 ji 抢 jiao（"结交"被啃成"结激ao"）；③ 专用串先行（dang漾→荡漾），兜底串后置（g漾→荡漾），防占位匹配误伤内部子串；④ 终检 `re.findall(r'[a-zA-Z]+')` 必须为空；⑤ **官方章节目录反向钉死映射**：百科/平台的章节列表若含被屏蔽字（"第二章 小人"），可直接验证 token 映射（xiao人→小人），比猜可靠。

46. **章首无标头求票感言（媚公卿实证）**：与九重紫章末感言（条目 43）镜像——求票块挂在**汉字章标后第一行**（"pk期间，需要各种粉红票推荐票pk票。""求粉红票推荐票pk票。本书可能下月一号上架"），ch8/9/24/28 共 4 处。**对策**：锚词（求粉红票|求推荐票|pk票|冲到pk榜）命中且**上一非空行是章标**才删，双条件防误删正文（"pk"两字在删块后必须消失，进终检）。
47. **引文誊写直引号手误自动回转（媚公卿实证）**：手写 style_examples.md 时极易把源本弯引号敲成 ASCII 直引号（本次 18/59 行中招）。**对策**：① 引文行（`> ` 开头）逐行检测 `"` 计数，奇数报错、偶数按开闭交替回转为弯引号后再跑逐字回验；② 解说行同扫，含字面 token（如半角道:“）时先占位保护再交替转换，防 token 内引号被打乱方向；③ 打包脚本直引号扫描为最后一道闸，零容忍。
48. **哨兵垃圾顶替闭引号 + 剥离残字（长嫡实证）**：某宝书网本每章挂两种哨兵——段尾 `otbnkotgt` ×661、章尾 `160420oshow7` ×658。前者不是纯追加：**157 处顶替了段尾闭引号"**（`：“起吧。otbnkotgt` 应为 `：“起吧。”`），直接删 token 会留下全册 158 处引号不配对。**对策**：① 剥离 token 后按段级引号平衡（`count('“')-count('”')==1`）自动回补闭引号，残留不平衡段人工定案；② **残缺垃圾行剥离陷阱**：`t160420oshow7` 这类截断行在哨兵剥离后会留下孤立字母 `t`，`totbnkotgt` 同理——孤立单字母行过滤必须在**所有剥离步骤之后**再跑一遍，不能只在开头跑；③ 哨兵数量 ≈ 章数是这类连载抓取本的特征签名，勘察时先对齐这两个计数。

49. **章中拼接更新块：多更连载本的感言不在章末（长嫡实证）**：起点女生网多更连载（第一更/第二更/第三更）被上传源按"更"拼接后，**作者感言挂在章内部各更的拼接缝上**，章末走回删除（条目 43/46）只删得掉最后一块，实测残留 120 行散布 55 章。**对策**：① 感言关键词分两级：**硬标记**（月票/求票/求订/首订/么么/乃们/伦家/撸字/点娘/红领巾/妹纸/第X更/。。。）经叙事零冲突验证后可**全局清扫**；软标记（更新/今天/感谢/求）只允许在章尾走回语境用；② **更新语义词陷阱**：正文有合法的"二更天/三更天"（打更计时），硬标记必须写成 `第[一二三四五]更` 而非裸"三更"；"上架"在"车上架了四枝竹竿"里也合法，全局清扫禁用；③ 硬标记覆盖不到的无标记感言段（"被出租车撞趴了""啊哈哈哈哈哈哈"）按章号+前缀精确清单人工定删；④ 清洗终检：`。。。`、`。。`、`月票` 全册计数必须为 0。

50. **空格拆散型站标广告行（长嫡实证）**：站标广告把每个字符用空格隔开逃避扫描——`宝 书 网  w w w . b  a o s h u 2 .  c o  m`、`奇 书 网  w w w . q i s u w a n g .  c o m`、`八零电子书www.txt80.la`，以及全角+希腊字母+注音假名伪装（`寶 書 網 ω w Ｗ . Ｂ  à o Ｓ Ｈ μ 2 .  c ò  Ｍ`、`寳_ 書_蛧_ω_w _w_._β_Α_ǒ_Ｓ _Η_ǔ_②_. ℃_o_Μ`），单本 11 种变体，对 `[a-zA-Z0-9_]{3,}` 式 token 扫描完全隐形。**对策**：① 先去空白（`re.sub(r'[\s_.。_]','',l)`）再匹配：CJK 站名三元组（宝/寶/宀/寳/寚/奇/八 + 书/書 + 网/網/蛧）或域名子串（baoshu/qisuwang/txt80，NFKC 折叠+lower）；② 兜底启发：去空白后长度<40 且含 ≥2 个特殊字符（℃②βμωＷ）即判广告行；③ 头尾 frame 行（声明/----用户上传----）先剥再扫，防声明行误中站名规则。

51. **"全有全无=风格"的失效边界：结构性必需标点整册消失仍是损伤（长嫡实证，第 41 条精化）**：某本 118 万字**问号叹号双双为 0**，疑问结构却大量存在（怎 853/什么 1,700/如何 420），对白普遍以闭引号裸收（"您怎么说的"）——按第 41 条"全有或全无=风格"会误判为作者签名。**精化判定**：全有全无只是必要条件，还需过**语义结构必需性**检验——问句/感叹的语义结构大量存在而终结标点全册为零，属转载源批量抹除（作者不可能写问句全不打标）；第 41 条的"语气词后随机丢字"检验适用于随机损伤，本类整册抹除要靠结构必需性检验。**处置**：同 41——问叹维度降级为声明项，SKILL.md 写明"？！整册抹除（损伤），引文逐字保留，仿写时按语气自行补回"，并明令禁止把无问号写法当风格模仿。
