# {NOVEL_TITLE}文风锁定 Skill 使用说明

## 这是什么

基于《{NOVEL_TITLE}》前 20 章正文样本，从叙事视角、句式、对话、节奏、词汇修辞、情绪基调、章节钩子、环境描写、行文禁忌、开篇习惯十个维度萃取写作规范，把原书"语感"锁定为可执行规则，指导 AI 以该小说语感创作。

## 怎么用

1. **安装**：解压 `{SKILL_NAME}.zip`，把文件夹放入技能目录（`~/.workbuddy/skills/` 或项目级 `.workbuddy/skills/`），重启生效。
2. **触发**：说"按 {NOVEL_TITLE} 文风写……"，或使用触发词"{NOVEL_TITLE}文风、模仿{NOVEL_TITLE}写法"。
3. **使用**：给剧情大纲或续写指令，AI 按十维规范输出纯净正文。

## 仿写示例（效果）

输入"用 {NOVEL_TITLE} 文风写主角初入陌生门派"。输出片段在叙事视角、长短句节奏、换行频率、对话口吻上与样本一致，章末按习惯埋悬念钩子。读者对比原书几乎分辨不出语感差异，剧情则为全新创作，不涉及原书情节。

## 注意事项

- 只模仿文笔、节奏、语感，严禁抄袭或复述原书剧情
- 输出纯净正文，不附带解释
- 文风漂移时回看 SKILL.md"行文禁忌"校准
